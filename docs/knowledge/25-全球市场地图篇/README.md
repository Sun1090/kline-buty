# 25 · 全球市场地图篇

> 你的交易世界里不应该只有 A 股和加密。日经、KOSPI、DAX、Nifty、VN 指数……这些名字每天在同一个地球转动，它们和你的持仓隔着一条流动性传导链：美联储降息 → 美元走弱 → 新兴市场流入 → 北向资金 → A 股。本篇按「日韩 → 欧洲 → 新兴市场 → 跨境实操」的顺序，把全球市场地图展开给你看：每个市场长什么样、有什么性格、怎么参与、和 A 股到底有多大关系。

---

## 各篇简介

### 01 · 日本与韩国市场

日韩是全球离我们最近的成熟市场：日本有负利率时代遗留下来的特殊生态（零利率存款、躺平的估值、被企业回购推着走的「日特估」），韩国有散户浓度极高的「西学蚂蚁」和一条把 KOSPI 焊死在半导体上的产业链。先读这篇，你会重新理解「成熟市场」四个字——它不代表不波动，只代表波动的理由不同。

### 02 · 欧洲市场

欧洲不是一个市场，是几十个国家市场的拼接：欧元区内部还有「强德国、弱南欧」的温差。本篇讲清三大块——欧元区（DAX/CAC/斯托克 50 与负利率遗产）、英国（富时 100 的高分红与脱欧后的折价）、北欧与瑞士（避险货币与奢侈品股的避风港气质），最后落到最实用的一环：欧元兑美元是如何通过美元指数传导到全球风险资产的。

### 03 · 新兴市场

印度、越南、印尼、巴西、墨西哥——这些市场的故事像「10 年前的 A 股」一样性感，也像 1997 年的亚洲金融危机一样危险。本篇给你一张新兴市场地图：各国的代表指数、一句话性格、以及所有新兴市场的共同命运——资本大进大出。看懂了这一点，你就看懂了新兴市场的大多数涨跌。

### 04 · 全球市场对比总览

把全球主要指数的「性格」放进一张表对比：日经与 A 股低相关、纳斯达克与 A 股成长股中相关、恒生与 A 股高相关——相关性不同，配置价值就不同。本篇还回答三个实操问题：全球配置到底能分散多少风险（数字例子）、汇率怎么吃掉你的收益、以及普通人到底走哪条渠道落地。

### 05 · 跨境投资实操

前四篇回答「外面有什么」，这一篇回答「我怎么合规地参与」。5 万美元便利化额度的真相、港股通为什么不用换汇、QDII 为什么最省心但有溢价、境外券商怎么选（牌照/资金安全/费用）、CRS 交换的是什么——最后给你一句总结：多数人 QDII + 港股通就够，少数人再考虑正规境外券商。

## 「我是 A 股玩家，还需要看这些吗？」

一句话回答：**不看也能交易，看了才知道自己交易的市场只是全球的一小块拼图。**

| 你的状态 | 本篇对你的价值 |
|---|---|
| 只做 A 股 | 北向资金、人民币汇率、美股隔夜情绪都在影响你的开盘价；看懂「美联储 → 美元 → 新兴市场 → A 股」这条链，比盯 99 个指标更有用 |
| 只做加密 | 加密本质上是全球流动性的「投机化身」：美联储放水与美元指数、美股科技股的风险偏好，都与币价强相关；全球市场是你判断币市的外围环境 |
| 已有港美股账户 | 本篇的日韩/欧洲/新兴市场内容直接补足你的选品地图，04 的配置部分帮你决定要不要把组合扩展到这些市场 |
| 只有国内账户（场外基金） | QDII 基金就是普通人参与全球市场的合规入口，02/03 的参与渠道部分可直接照抄 |

## 本篇学习顺序

```
① 01 日本与韩国（离我们最近、也最能刷新认知的成熟市场）
   ↓
② 02 欧洲（理解欧元 → 美元指数 → 全球风险资产这条链）
   ↓
③ 03 新兴市场（理解资本大进大出与「高波动高想象」）
   ↓
④ 04 对比总览（把前三篇放进同一张相关性表格）
   ↓
⑤ 05 跨境实操（想真正参与时，再看合规路径）
```

- 只想快速建立「全球视野」的读者，可以只看 01、02 与 04 的流动性传导部分。
- 有真实出海打算的读者，**先读 05 的合规路径再动手**——路径选错比标的选错更贵。
- 05 与 [14-理财配置篇/06-海外资产配置实操.md](../14-理财配置篇/06-海外资产配置实操.md) 互为补充：那篇讲「要不要配、怎么配」，本篇讲「每个市场长什么样、具体怎么落地」。
