## 一、单根 K 线：价格的四要素

一根 K 线记录一个周期内的价格波动，由**四个价格**构成：

| 要素 | 英文 | 含义 |
|---|---|---|
| 开盘价 | Open | 周期开始时的第一笔成交价 |
| 最高价 | High | 周期内成交的最高价 |
| 最低价 | Low | 周期内成交的最低价 |
| 收盘价 | Close | 周期结束时的最后一笔成交价 |

### 1.1 K 线的画法

- **实体**：开盘价与收盘价之间的矩形，代表该周期多空博弈的最终结果区间。
- **影线**：实体上下的细线（上影线/下影线），代表盘中曾触及的最高/最低价。
- **上影线** = 最高价 − max（开、收）；**下影线** = min（开、收）− 最低价。

```
        ┌─────┐
        │ 上影线（最高价）     ← 最高价
        │  │
   ┌────┤────┐
   │    │实体│ │
   └────┤────┘ │
        │  │   ← 最低价
        │下影线
        └─────┘
```

### 1.2 阳线与阴线

| 类型 | 条件 | 视觉 | 含义 |
|---|---|---|---|
| 阳线 | 收盘 > 开盘 | 实体空心/红色（中外惯例不同） | 该周期多头占优 |
| 阴线 | 收盘 < 开盘 | 实体实心/绿色 | 该周期空头占优 |

> 国内软件惯例**红涨绿跌**，国际软件（TradingView 等）**绿涨红跌**，只看习惯、无对错。Kline Buty 默认跟随你所选主题。

### 1.3 从一根 K 线能读出什么

- **实体越长**：该周期内多/空一方越强势。
- **上影线越长**：上方卖压越重，冲高被砸下来。
- **下影线越长**：下方买盘越强，杀跌被接住。
- **十字星（开≈收）**：多空拉锯，方向不明，常是变盘信号。

**一句话例子**：一根下影线很长的小阴线 = 盘中大跌但收盘被拉回，说明低位有承接，后续可能转强。

## 二、常见周期与时间结构

### 2.1 周期（Interval）是什么

周期 = 每根 K 线代表的时间长度。1m 表示每根 K 线含 1 分钟的数据，1d 表示每根含 1 天的数据。

| 周期 | 名称 | 常见用途 |
|---|---|---|
| 1m / 5m | 分钟级 | 超短线、抢反弹、盯盘交易 |
| 15m / 30m | 短周期 | 日内波段交易 |
| 1h / 4h | 小时级 | 短线到波段交易，加密市场最常用 |
| 1d（日线） | 天级 | 波段与趋势判断，最主流 |
| 1w（周线） | 周级 | 中期趋势过滤 |

> 💡 **Kline Buty 使用提示**：移动端顶部周期条会**自动换行展示全部 14 个周期**（1s~月），不做横向滚动——所有周期一键直达，窄屏也不怕漏看；桌面端则保持单行紧凑，低频功能收进「更多」面板。

### 2.2 周期的关系

- 一根 1h K 线 = 60 根 1m K 线的**汇总**（开=第 1 根的开、收=第 60 根的收、高/低取区间极值）。
- **大周期定方向，小周期找点位**：日线趋势向上时，用 1h/15m 找回调买点，胜率远高于逆着日线抢反弹。
- **周期越小，噪音越多**：1m 图上的「突破」八成是假突破；日线/周线信号更可靠但更迟钝。

### 2.3 多周期联看（时间框架嵌套）

标准做法是「**三周期看图**」，例如：

```
周线：定大趋势（过滤，只做顺势方向）
  ↓
日线：定交易区间与关键位置
  ↓
1h/15m：精确定位入场与止损点
```

**一句话例子**：周线上升趋势中，日线回调到支撑、1h 出现企稳阳线 → 入场胜率与盈亏比俱佳；如果周线是下跌趋势，日线的反弹一律观望。

## 三、均线：MA 与 EMA

### 3.1 均线的本质

均线 = **一定周期内收盘价的平均值连线**，用来平滑价格噪音、观察趋势方向。

### 3.2 MA（简单移动平均线，SMA）

```
MA(n) = （最近 n 根 K 线收盘价之和）÷ n
```

**数字例子**：最近 5 日收盘价为 10、11、12、13、14 → MA(5) = (10+11+12+13+14) ÷ 5 = **12**

### 3.3 EMA（指数移动平均线）

- 对**近期价格给予更高权重**，反应比 MA 更快，拐点出现得更早。
- 公式逐日递归（含平滑系数），不需要手工算，只需知道：**行情软件默认指标多为 EMA，参数越大越平滑、越迟钝**。

### 3.4 均线的常见用法

| 用法 | 说明 |
|---|---|
| 方向过滤 | 价格在均线上方且均线向上 → 多头趋势；反之空头趋势 |
| 支撑/压力 | 价格回踩上升中的均线常获支撑，反弹到下降中的均线常遇压 |
| 金叉/死叉 | 快线上穿慢线 = 金叉（偏多），下穿 = 死叉（偏空） |
| 常用组合 | MA(5,10,20)、MA(50,200)，以及加密圈常用的 EMA(20,50) |

> 均线是**滞后指标**：它描述过去，不是预测未来。金叉发生在上涨已经走了一段之后，单纯追金叉常常买在短期高点。均线更适合做「趋势过滤器」而非「买卖信号发生器」。

## 四、成交量副图

### 4.1 成交量（Volume）是什么

成交量 = 该周期内成交的**数量总和**（股票为股数，加密为币数）。副图中每根 K 线下方对应一根柱状图，**柱高 = 成交活跃度**。

### 4.2 怎么看量价配合

| 现象 | 含义 |
|---|---|
| 上涨 + 放量 | 多头力量真实，趋势更可信 |
| 上涨 + 缩量 | 追涨意愿不足，反弹可能乏力 |
| 下跌 + 放量 | 恐慌抛售，可能还有低点 |
| 下跌 + 缩量 | 抛压衰竭，接近止跌 |
| 放量滞涨 | 多空分歧巨大，警惕见顶 |

### 4.3 进阶观察点

- **量价背离**：价格创新高、成交量没跟上 → 上涨动能衰减。
- **关键位放量**：突破/跌破关键价位时放量更可靠；缩量突破常是假突破。
- **放量下影线**：暴跌中巨量承接，往往是恐慌底部的特征。

> 一句话记住：**量是价格的「燃料」**，没有量的涨跌走不远。量价分析的完整体系见 [06-技术分析篇](../06-技术分析篇/03-量价分析.md)。

## 五、如何选择图表周期

选择周期取决于**交易风格与持仓时间**，而不是「哪个更好」：

| 你的风格 | 建议主周期 | 辅助周期 | 持仓时间 |
|---|---|---|---|
| 超短线/抢反弹 | 1m / 5m | 15m | 分钟～小时 |
| 日内波段 | 15m / 1h | 4h | 数小时～1天 |
| 短线波段 | 1h / 4h | 1d | 1～5天 |
| 中长线 | 1d / 1w | 4h | 数周～数月 |

**选择原则：**

1. 周期要和你的**生活节奏**匹配——上班没法盯盘的人不要用 1m 图。
2. 入场看小周期，但**方向永远先问大周期**。
3. 一个周期上的信号，至少等一个更大周期的确认再动手。
4. 别频繁换周期：同一时间在不同周期上反复横跳，只会看到互相矛盾的信号。

## 六、常见图表类型

| 类型 | 画法 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|---|
| 蜡烛图（K线图） | 实体+影线 | 信息最全（开高低收） | 信息密集，新手易懵 | **默认主力，绝大多数场景** |
| 折线图 | 只连收盘价 | 极简，看趋势干净 | 丢失最高/最低信息 | 快速看长期趋势 |
| 面积图 | 折线+下方填充 | 视觉直观 | 同折线图 | 展示/演讲用 |
| 条形图（美式） | 横线开收盘+竖线高低 | 信息同K线 | 不如蜡烛直观 | 欧美老牌软件 |
| 砖形图（Renko） | 固定幅度砖块 | 滤除噪音，只画趋势 | 无时间轴，无法看时段 | 趋势追踪玩家 |
| 点数图（Point&Figure） | X/O 记价格反转 | 专注价格行为 | 学习成本高 | 专业价格行为分析 |
| 山形图/谷形图 | 收盘+高低点连缀 | 便于看区间 | 细节较少 | 区间判断辅助 |

> 新手建议：**90% 的时间用蜡烛图**，其余类型先了解即可。砖形图等高级图表在 [06-技术分析篇](../06-技术分析篇/) 中另有展开。

## 七、本篇速查

- 一根 K 线 = 开、高、低、收四个价格；实体看多空结果，影线看盘中攻防。
- 周期是「时间颗粒度」：**大周期定方向，小周期找点位**。
- MA 是简单平均、EMA 偏重近期；均线是滞后指标，适合当过滤器。
- 量价配合看：放量上涨可信、缩量上涨警惕、放量下跌恐慌、缩量下跌接近尾声。
- 周期选择服从交易风格，先选方向周期、再选入场周期。
- 蜡烛图是默认主力图表，其余类型各有用武之地、按需切换。
