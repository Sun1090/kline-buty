# 08 · 江恩箱与角度线实战

> 江恩（W.D. Gann）留给交易者的最大遗产，不是「预测点位」，而是一套**用角度与正方形把时间-价格关系画出来**的思考工具。本篇站在 [05-波浪与江恩与缠论](05-波浪与江恩与缠论.md) 的批判性立场上，聚焦**江恩箱 / 江恩角度线在图表软件里怎么画、怎么读、怎么用**——把它们当「结构描述语言」而非「圣杯」。
>
> **先记住一个总原则：江恩工具的价值在「提醒你关注特定的时间/价格交叉点」，不在「告诉你市场必然去哪」。** 任何角度线或箱体给出的位置，都必须配合**<mark>止损</mark>**与失效条件才可执行。

---

## 1. 江恩角度线：从「1×1」开始理解

### 1.1 角度线是什么

江恩认为价格与时间之间存在固定比率关系，他把这种关系画成从某个显著高低点出发的射线：

```text
        ┌────────────────────────────────────┐
        │                                     │
        │                     8×1 ↗          │
        │                  4×1 ↗             │
        │               2×1 ↗                │
        │            1×1 ↗ (45°)             │
        │         1×2 ↗                      │
        │      1×8 ↗                         │
  A ────┴────────────────────────────────────┘
  原点   （价格轴向上，时间轴向右）
```

- **1×1 线**：价格每走 1 个单位、时间走 1 个单位，即 45°（在等刻度坐标下）。这是江恩体系的「中轴线」，代表最平衡的趋势速度。
- **2×1 / 4×1 / 8×1**：更陡，代表强趋势（价格走得比时间快）。
- **1×2 / 1×4 / 1×8**：更缓，代表弱趋势或震荡（时间走得比价格快）。

> ⚠️ 关键提醒：**角度值依赖坐标刻度**。不同价格区间、不同时间周期下，同一根 1×1 线的物理角度会变。所以不要死记「45°」，而要理解「1×1 = 一个单位价格对应一个单位时间」这个比率本身。

### 1.2 正确画法：锚点取自显著结构

在本项目的画线工具里，江恩角度线的交互是 **A（原点）→ B（方向点）**：

- A 取**显著高点或低点**（一波推动的起点、历史大顶/大底）；
- B 决定「1×1 的比率」——软件以 A→B 的竖直摆幅作为 1 个价格单位，再按 1/8、1/4、1/2、1、2、4、8 倍率向两侧发散 9 条线。

**实战要点**：

| 场景 | 画法 | 读法 |
|---|---|---|
| 上升趋势 | A 取低点，B 取后续高点 | 价格站上 1×1 = 趋势健康；回踩 1×1 不破 = 支撑 |
| 下降趋势 | A 取高点，B 取后续低点 | 价格跌破 1×1 = 弱势确认；反抽 1×1 受阻 = 压力 |
| 趋势加速 | 观察价格从 1×1 切换到 2×1 | 斜率抬升 = 主升/主跌段，警惕末端加速 |

### 1.3 失效条件（必须提前写下来）

- 收盘价明确跌破当前依托的角度线（如 1×1 线），且**次日不收回** → 该线的支撑/压力角色失效；
- 角度线被**大幅放量**穿透 → 趋势速度本身变了，旧的比率不再适用，应重画；
- 震荡行情中角度线会反复穿越，**在震荡区里不要用角度线做单**。

## 2. 江恩箱：把「角度」装进「时间-价格方框」

### 2.1 江恩箱是什么

江恩箱（Gann Box / Gann Square）是角度线的「区域化」版本：用 **A→B 两点框出一个矩形**，矩形内部自动画出：

```text
  TL ──────────┬────────── TR
   │ ╲         │         ╱ │
   │   ╲    2×1│1×2     ╱   │
   │     ╲     │       ╱     │
   │ 1×2   ╲   │     ╱   1×2 │
   │         ╲ │   ╱         │
   │           │ ╱           │
  BL ──────────┴────────── BR
   （1×1 双对角 + 四角 1×2/2×1 共 10 条线）
```

- **1×1 主对角线**（两条，加粗）：从矩形一角连到对角，是箱体的「骨架」；
- **1×2 线**：四角 → 对边中点（半速）；
- **2×1 线**：四角 → 邻边中点（双速）。

### 2.2 为什么用「箱」而不是单根角度线

| 对比 | 单根角度线 | 江恩箱 |
|---|---|---|
| 覆盖 | 只覆盖一个角度的射线 | 覆盖整个时间-价格区域 |
| 用途 | 判断单条趋势速度线 | 框定一段行情的「角度场」，找多空转换区 |
| 典型场景 | 趋势中的支撑/压力 | 突破回踩、箱体内部节奏、目标测算 |

### 2.3 实战用法（结合本项目工具）

**用法 A：突破回踩确认**

1. 用江恩箱框住启动前的整理区间（A = 区间低点，B = 区间高点）；
2. 价格放量突破箱体上沿后，回踩 **1×1 对角线**（或 2×1 线）不破 → 回踩有效；
3. 跌破 1×1 且收回无望 → 突破失败，离场。

**用法 B：箱体内的节奏切换**

- 价格贴着 1×1 上行 = 均衡上涨；一旦跌破 1×1 转由 2×1 承托 = 趋势降速，进入「慢牛/整理」；
- 价格沿 2×1 陡峭拉升 = 加速段，**加速段末端往往对应情绪高潮**，配合量价背离减仓。

**用法 C：目标测算（弱参考）**

- 矩形的高（价格幅度 H）与宽（时间跨度 T）形成比率；H 大致等于 T 时是「正方形」箱体，江恩强调时间与价格平衡点常产生变盘——**仅作为「到点警惕」的提醒，不作为精确卖点**。

### 2.4 命中与编辑（本项目实现细节）

- **区域命中**：江恩箱像矩形一样，点击箱体内部任意位置即可选中，方便拖动整箱；
- **锚点编辑**：选中后 A/B 两个角显示锚点，可分别拖拽调整箱体；
- **删除**：选中后点「删除」或按 Delete。

## 3. 江恩角度线 / 江恩箱的常见误区

| 误区 | 真相 |
|---|---|
| 「1×1 线就是 45°，永远不变」 | 角度随坐标刻度变化，比率才是本质 |
| 「箱体上沿/对角线是精确买卖点」 | 它们是**参考区**，不是精确触发点，必须等收盘确认 |
| 「江恩能算出时间拐点」 | 时间周期事后看很准，事前很难唯一确定，属「事后解释」 |
| 「角度线越多越准」 | 画得越多越容易「总有一条命中」，这是过拟合 |
| 「江恩箱适合所有行情」 | 只适合**有明显趋势节奏**的行情；纯震荡里全是假突破 |

## 5. 三条纪律（与 07-画线工具实战 一致）

1. **锚点取自显著结构**：A/B 必须是可被第三方认可的高低点，而不是随手一画；
2. **每条线都要有失效条件**：画完就写「收盘跌破 1×1 且不收回 = 失效」，否则等于没画；
3. **画线是思考的可视化，不是预测的圣杯**：江恩箱帮助你「看见」节奏与共振区，真正的优势来自画线前的观点与画线后的风控。

---

## 小结

- **江恩角度线** = 从显著点发出的 9 条比率射线（1/8 … 8×1），1×1 是核心；
- **江恩箱** = 用两点框出矩形 + 箱内 10 条角度线（1×1 双对角 + 四角 1×2/2×1），把角度从「线」升级为「场」；
- 两者都是**描述趋势速度与共振区的语言**：配合斐波那契、通道、量能交叉验证，并永远预设失效条件；
- 在震荡行情、无显著结构、无成交量配合时，江恩工具的可靠性显著下降——**不要迷信，要验证**。
