# 01 · K 线形态

> K 线形态是技术分析里最「形象」的语言：一根 K 线有多长、影线往哪伸、几根 K 线组成什么形状，都被人为赋予了含义。本篇把常见形态按「单根 → 组合反转 → 组合持续 → 缺口」四个层级讲清楚，每个形态都配示意图和确认/失败条件。
>
> **先记住一个总原则：形态只是「描述」，不是「预言」。** 一个形态的看涨含义，只在它被后续价格与成交量确认之后才成立。

---

## 1. 单根 K 线形态

### 1.1 锤子线（Hammer）

**形态描述**：实体很小，位于整根 K 线的顶部；下影线极长（通常 ≥ 实体 2 倍）；上影线几乎没有或很短。阴线阳线皆可，阳线（收盘 > 开盘）更可靠。

```
   ┌─────────┐    ← 小实体位于顶部（阳线更佳）
   │  实 体  │
   └────┬────┘
        │
        │      ← 下影线 ≥ 实体 2 倍
        │
        └────  ← 最低点
```

**出现位置**：下跌趋势的末端（关键：低位出现）。

**含义**：看涨反转信号。长下影代表盘中空方把价格打压到很低的价位，但收盘前多方将价格拉回——空方进攻失败，抛压枯竭的迹象。

**确认信号**：下一根 K 线收阳线，且收盘价站上锤子线实体；同时成交量相比前期放量。

**失败场景**：
- 出现在上涨途中或高位，不叫锤子线（见下一条「上吊线」）。
- 下影线不够长（< 实体 2 倍）只是普通 K 线，无意义。
- 次日继续放量下跌，锤子线失效——说明盘中那根下影只是空头回补，不是反转。
- 左侧猜底：看到锤子线就立刻满仓抄底，是最常见的死法。单根 K 线在趋势里被直接吞没的概率很高，必须等确认。

### 1.2 上吊线（Hanging Man）

**形态描述**：与锤子线完全相同的形状（小实体在上、长下影在下），但**位置相反**——出现在上涨趋势的高位。

```
   ┌─────────┐
   │  实 体  │
   └────┬────┘
        │
        │      ← 同样的形状
        │
        └────
```

**出现位置**：上涨趋势末端。

**含义**：看跌反转信号。长下影说明盘中曾经发生过剧烈的抛售，只是暂时被拉回——这是多头力竭、抛压初现的信号。

**确认信号**：下一根 K 线收阴线并跌破上吊线实体；或次日大幅低开。

**失败场景**：
- 高位出现但次日继续收阳创新高，说明只是洗盘，上吊线失效。
- 「上吊线 + 缩量」时假信号尤其多：缩量说明抛压本来就不大。

### 1.3 吞没形态（Engulfing）

**形态描述**：两根 K 线组成。第二根 K 线的实体**完全覆盖**第一根 K 线的实体（影线可不管）。看涨吞没 = 第二根为大阳线、包住前面的阴线；看跌吞没 = 第二根为大阴线、包住前面的阳线。

```
看涨吞没（低位）          看跌吞没（高位）
  前1根  后1根              前1根    后1根
┌────────┐  ┌───────────┐   ┌───────┐   ┌────────────┐
│  阴线  │  │ ┌──────┐  │   │ 阳线  │   │ ┌────────┐  │
│（短小）│  │ │ 阴线 │  │   │（短小）│   │ │  阳线  │  │
└────────┘  │ └──────┘  │   └───────┘   │ └────────┘  │
            └───────────┘               └────────────┘
  第2根阳线实体完全包住第1根阴线          第2根阴线实体完全包住第1根阳线
```

**出现位置**：看涨吞没出现在下跌末端；看跌吞没出现在上涨末端。

**含义**：多空力量的「突然易手」。看涨吞没代表多方一改弱势，一天之内吃掉前一天的全部跌幅；看跌吞没反之。

**确认信号**：
- 吞没时**成交量显著放大**（尤其看涨吞没，放量更可信）；
- 看涨吞没后一根 K 线继续收阳；
- 吞没形态出现在关键位置（如支撑位、前低附近）更有效。

**失败场景**：
- 小阴线被大阳线「吞没」若发生在上涨途中，可能是正常的加速赶顶。
- 横盘震荡区内的吞没形态大量出现（高抛低吸都被吞），信号严重失真。
- 没有放量配合的吞没，在趋势中部就是噪音。

### 1.4 十字星（Doji）

**形态描述**：开盘价与收盘价几乎相同（实体极短甚至没有），只有上下影线。影线越长，十字星越有「犹豫」的含义。

```
       │
   ────┼────     ← 开盘 ≈ 收盘
       │
```

**出现位置**：任何位置都有，但**趋势末端（高位或低位）的十字星最有价值**。

**含义**：中性偏反转。十字星代表多空双方在收盘时打成平手——趋势过程中这叫「停顿」，趋势末端这叫「力竭」。低位十字星（黎明之星）看涨，高位十字星（黄昏之星）看跌。

**确认信号**：十字星本身几乎没有任何方向性，**必须等下一根 K 线给出方向**。上下影线越长、放量越明显，作为顶/底信号的可信度越高。

**失败场景**：
- 把趋势中部的十字星当反转信号——趋势中十字星很常见，很多只是中继。
- 十字星后一根 K 线没有明显方向，形态作废，不要强行解读。

### 1.5 长上影 / 长下影

**形态描述**：实体不大，但一侧影线异常长。长上影 = 上影线 ≥ 实体 2 倍；长下影 = 下影线 ≥ 实体 2 倍。

```
长上影（射击形态）        长下影（吊锤形态）
      │                       ┌────────┐
      │   ← 上影线长           │ 实体   │
   ┌──┴──┐                    └───┬────┘
   │ 实体 │                        │
   └─────┘                         │ ← 下影线长
```

**出现位置**：长上影常出现在上涨末端；长下影常出现在下跌末端（但形态本身不决定位置，位置决定含义）。

**含义**：
- 高位长上影：上方抛压沉重，多方冲高被砸回（俗称「仙人指路」的失败版），看跌。
- 低位长下影：下方承接有力，看涨（即锤子线）。
- 与锤子线/射击之星的区别：影线比例和实体位置更极端一些，含义相同。

**确认信号**：次日 K 线的方向 + 成交量。长上影配合放量 = 真实抛压；缩量长上影可能是诱空。

**失败场景**：
- 影线是「插针」行情制造的（如极端行情中瞬间的价格刺穿），会留下假信号。
- 趋势强势中长上影常被次日阳线直接覆盖，追空被套。

### 1.6 射击之星 / 流星（Shooting Star）

**形态描述**：实体很小且位于 K 线底部，上影线极长（≥ 实体 2 倍），几乎无下影。与锤子线互为镜像。

```
      │
      │      ← 上影线 ≥ 实体 2 倍
      │
   ┌──┴────┐
   │ 实体   │    ← 小实体在底部（阴线更佳）
   └───────┘
```

**出现位置**：上涨趋势末端（高位）。

**含义**：看跌反转。盘中多方将价格推得很高，但收盘跌回起点附近——上方卖压巨大，多头力竭。**射击之星与流星是同一形态的两种叫法**（英文均为 Shooting Star），行情软件里有时也叫「扫把星」。

**确认信号**：次日收阴且跌破射击之星实体；放量更佳。

**失败场景**：
- 高位出现但股价横盘数日不跌，形态失败（横盘消化卖压后可能继续涨）。
- 在强势主升浪中频繁出现长上影但价格仍在创新高，是「逼空」特征而非见顶，此时做空容易被轧。

## 2. 常见反转形态

> 反转形态的共同逻辑：**趋势末端的「动能耗尽 + 结构破坏」**。识别时先看整体结构（头部/双顶），再看颈线突破，最后看成交量。**唯一能确认反转的是「颈线被有效突破」，形态本身永远只是警报。**

### 2.1 头肩顶 / 头肩底

**形态描述**：由三个峰组成——中间的最高（头），两侧稍低（左肩、右肩）。连接两个肩部低点的水平线叫**颈线**。头肩顶：颈线被向下有效跌破，确认顶部反转；头肩底（倒头肩）：颈线被向上有效突破，确认底部反转。

```
头肩顶：                         头肩底（倒头肩）：
      头
     ┌──┐
 左肩 ┘  └┐     右肩             │  左肩     头     右肩
 ┌┐       └┐   ┌┐               │  ┌┐      ┌──┐     ┌┐
┌┘└┐       └┐ ┌┘└┐             │ ┌┘└┐    ┌┘  └┐   ┌┘└┐
│   │        └─┘   │            │┌┘   └──┐┘    └───┘   └┐
┴───┴──────────────┴── 颈线      │┘      └──────────────┘ 颈线
```

**出现位置**：长时间上涨/下跌趋势之后。

**含义**：头肩顶看跌（多头行情终结），头肩底看涨（空头行情终结）。量度目标：从头部到颈线的垂直距离，跌破/突破颈线后大概率再走同样距离。

**确认信号**：
- 头肩顶：跌破颈线时**放量**；跌破后常有一次回抽颈线的反抽（回抽不收复颈线 = 二次确认）。
- 头肩底：突破颈线必须**明显放量**（缩量突破可信度低），突破后回踩颈线获支撑。
- 右肩成交量通常小于左肩（多头/空头动能衰减）。

**失败场景**：
- 颈线未被有效突破前，头肩形态随时可能「演化」失败——形态是事后才完全成立的结构。
- 假突破：跌破颈线 3% 以内又拉回（或突破颈线后 3 日内收回），属假突破，形态作废。
- 左侧交易者在「疑似头部」就做空，往往死在头肩顶的最后一涨里——**必须等颈线破位**。
- 三角形或宽幅震荡区内会出现大量「缩水版头肩」，多数是噪音。

### 2.2 双顶（M 顶）/ 双底（W 底）

**形态描述**：价格两次冲高到相近的高点（双顶），中间有低点；或两次探底到相近的低点（双底）。两峰/两谷之间的最低/最高点为颈线。

```
双顶（M）：                双底（W）：
    ┌──┐      ┌──┐            │   ┌──┐      ┌──┐
   ┌┘  └┐    ┌┘  └┐           │  ┌┘  └┐    ┌┘  └┐
  ┌┘    └────┘    └┐          │ ┌┘    └────┘    └┐
 ─┴─────────────────┴─ 颈线   ─┴──────────────────┴─ 颈线
```

**出现位置**：长期上涨/下跌后。

**含义**：双顶看跌、双底看涨。第二个顶/底若成交量明显小于第一个（动能衰竭），反转概率更高。量度目标 ≈ 顶底到颈线的垂直距离。

**确认信号**：颈线有效突破/跌破 + 放量；突破后的回踩/回抽确认。

**失败场景**：
- 两峰间距太近、形状太小，只是短线震荡，不是形态。
- 双底突破时**缩量**，极易演化为「假突破回踩再跌」，甚至变成多重顶。
- 右侧颈线未破前下结论，属于左侧猜顶猜底——**双顶可能变三顶，双底可能变三底**，形态没有走完前都不要预设。

### 2.3 三重顶 / 三重底

**形态描述**：三个相近的高点/低点，颈线连接中间的回调/反弹点。本质是双顶双底的强化版，更少见但更可靠。

```
三重顶：                        三重底：
  ┌──┐  ┌──┐  ┌──┐               ┌──┐  ┌──┐  ┌──┐
 ┌┘  └┐┌┘  └┐┌┘  └┐             ┌┘  └┐┌┘  └┐┌┘  └┐
┌┘    └┘    └┘    └┐           ┌┘    └┘    └┘    └┐
┴─────┴─────┴──────┴ 颈线      ┴─────┴─────┴──────┴ 颈线
```

**出现位置**：大级别趋势末端。

**含义**：与双顶双底一致，但三次冲击同一价位都失败，说明该价位是多空争夺的「战场」，突破/跌破后动能释放更彻底。

**确认信号**：同双顶双底——颈线突破 + 放量 + 回抽确认。第三次顶/底常伴随成交量最小。

**失败场景**：
- 三次冲击后仍未破颈线，形态变成宽幅箱体震荡——此时应放弃形态交易，改按区间高抛低吸或观望。
- 震荡市中「三重顶」常被第四次冲击直接突破，做空者被套。

### 2.4 圆弧顶 / 圆弧底

**形态描述**：价格缓慢、平滑地走出圆弧状的高位/低位结构，像锅盖或锅底。顶部常伴随成交量逐步萎缩、底部则逐步放大。

```
圆弧顶（锅盖）：               圆弧底（锅底）：
    ┌────────┐                   │
 ┌──┘        └──┐               ┌┴────────────┴┐
┌┘              └┐             ┌┘              └┐
│                │            ┌┘                └┐
└──────────────  └           ─┴──────────────────┴──
```

**出现位置**：长期慢牛/慢熊行情后。

**含义**：圆弧底看涨（缓慢吸筹的形态学表达），圆弧顶看跌（缓慢出货）。因为是「慢」形态，通常对应大级别行情。

**确认信号**：
- 圆弧底：右侧上升段**成交量明显放大**（左侧下降段缩量）；放量突破圆弧左侧起点的高点 = 确认。
- 圆弧顶：左侧放量、右侧缩量，跌破右侧低点确认。

**失败场景**：
- 圆弧形态耗时极长（数周至数月），中途任何一次放量急跌/急涨都可能直接破坏形态。
- 圆弧底右侧一旦缩量滞涨，容易变成「圆弧-箱体」混合结构，突破遥遥无期，持币等待的时间成本极高。
- 圆弧形态在事后看非常漂亮，但在「弧顶/弧底」未走出来之前，你看到的只是一段普通横盘。

### 2.5 V 型反转

**形态描述**：价格急跌（或急涨）后未经整理，立即反向急涨（或急跌），走出尖锐的 V 形。V 型顶（倒 V）同理。

```
V 型底（左侧暴跌，右侧急涨）：
     │      ╱
     │     ╱
     │    ╱
     │   ╱    ← 拐点（常伴随放量长下影）
     │  ╱
     ╲ ╱
      ╲   ← 急跌
```

**出现位置**：恐慌性急跌/狂热性急涨之后（如黑天鹅、流动性危机、极端情绪行情）。

**含义**：反转。拐点处通常伴随天量成交与剧烈影线（长下影/长上影）。

**确认信号**：
- 拐点放量（恐慌盘出尽 = 抛压枯竭）；
- 反转后价格快速收复前几日跌幅，且回调不创新低/新高；
- V 型反转在现货与加密市场更常见（无涨跌停或限制少）。

**失败场景**：
- V 型反转是**最难提前识别**的形态——拐点之前你看到的只有一路下跌，任何「抄底」都是猜。
- 左侧猜底死在 V 里：急跌中连续接飞刀，最后一跌的跌幅可能远超想象（杠杆市场直接爆仓）。
- V 型反转后的反弹若量能快速萎缩，大概率只是「死猫跳」，会二次探底。

## 3. 持续形态

> 持续形态出现在趋势中段，含义是「趋势歇口气，然后继续」。识别持续形态的意义：**它告诉你不要急着把趋势单平掉，也不要逆着趋势抢反弹。**

### 3.1 旗形（Flag）/ 三角旗（Pennant）

**形态描述**：旗形 = 一段陡峭的旗杆（趋势急速拉升/下跌）之后，价格进入一个与旗杆方向相反的窄幅平行通道（旗面）。三角旗 = 旗面为快速收窄的小三角形。

```
上升旗形（旗杆陡涨，旗面略向下斜）：
        ╱╱╱
      ╱╱╱ ╱─────────╱   ← 旗面（小幅回调通道）
    ╱╱╱ ╱─────────╱
  ╱╱╱     ← 旗杆
```

**出现位置**：强趋势中段（急涨/急跌之后）。

**含义**：趋势延续。旗面是对超买/超卖的技术性修复，修复完成后大概率沿原方向继续。

**确认信号**：旗面突破方向 = 原趋势方向；突破时放量；旗面内量能通常递减。

**失败场景**：
- 旗面整理时间过长（超过旗杆时间），形态可能失效，演变成箱体或反转。
- 旗面向下突破（上升旗形）且放量 = 趋势反转警报，持多必须离场——不要执着于「应该继续涨」。

### 3.2 三角形（对称 / 上升 / 下降）

**形态描述**：价格波幅逐步收窄形成的三角区域。对称三角形（两条边向中间收敛）、上升三角形（上边水平、下边抬高）、下降三角形（下边水平、上边降低）。

```
对称三角形：           上升三角形：           下降三角形：
     ╱╲                  ┌──────┐               ╲
    ╱  ╲             ╱──┘      └──╱          ╱──┘ └──╱
   ╱    ╲           ╱              ╱        ╱      ╱
  ╱      ╲        ╱← 下沿抬高     ╱      ╱── 下沿水平 ╱
 ╱────────╲     （突破上沿看涨）        （跌破下沿看跌）
```

**出现位置**：任何位置，但形态本身不决定方向——**突破方向才是方向**。

**含义**：三角形是「多空分歧收敛、蓄势待发」的形态。对称三角形无方向偏好，上升三角形偏多（上沿是明确卖压位，多次突破未果后一旦放量突破动能大），下降三角形偏空。

**确认信号**：
- 突破方向由放量的那一边决定，量能是关键；
- 三角形内越靠尖端的突破越不靠谱（波幅已耗尽），约 2/3 位置前的突破更有价值。

**失败场景**：
- 三角形持续横太久（过度收敛），突破后往往走不远——「横有多长竖有多高」只在量能配合时成立。
- 在三角形中部猜方向：50% 概率，和抛硬币一样，还没有手续费优势。
- 假突破后在三角形内部继续震荡，随后朝反方向突破（「双突破陷阱」）——这就是为什么必须等收盘确认。

### 3.3 矩形（箱体）

**形态描述**：价格在两条近似水平的平行线之间来回震荡，像一个箱子。多空在该区间反复换手。

```
矩形（箱体）：
┌──────────────────────────────┐   ← 上沿（阻力）
│   ╱╲  ╱╲  ╱╲  ╱╲           │
│  ╱  ╲╱  ╲╱  ╲╱  ╲          │
│                             │
└──────────────────────────────┘   ← 下沿（支撑）
```

**出现位置**：趋势中段（中继箱）或行情末端（反转箱）。

**含义**：中继矩形 = 整理后沿原方向突破；反转矩形 = 长时间箱体后突破方向即真正方向。突破前，矩形内是高抛低吸的战场。

**确认信号**：箱体边界的放量突破 + 回踩确认；箱体内震荡时间越长、量能越均匀，突破的意义越大。

**失败场景**：
- 矩形内频繁「上下沿都假突破」，是震荡市的经典特征——此时止损单会被反复收割。
- 突破箱体后 2~3 日跌回箱内 = 假突破，追单者被套。
- 大箱体边缘的「突破」若量能不济，大概率是诱多/诱空。

### 3.4 楔形（上升楔形 / 下降楔形）

**形态描述**：两条同方向倾斜但逐步收敛的边界。上升楔形（两条边都向上倾斜）通常看跌（牛市中后段的动能衰竭）；下降楔形（两条边都向下）通常看涨。

```
上升楔形（看跌）：        下降楔形（看涨）：
      ╱      ╱               ╲      ╲
     ╱    ╱                 ╲    ╲
    ╱  ╱                   ╲  ╲
   ╱╱                     ╲╲
```

**出现位置**：上升楔形常见于长期上涨末端（假突破式的末端加速）；下降楔形常见于长期下跌末端。

**含义**：上升楔形看跌（价格不断创小新高但斜率衰竭，空方逐步控场）；下降楔形看涨（反之）。

**确认信号**：跌破/突破下/上沿时放量；楔形内量能递减。

**失败场景**：
- 楔形边界被反复触碰后滑出边界的情况很常见，形态判断困难，需结合量能。
- 下降楔形在下跌趋势中途也可能只是「下跌中继」的缓跌段，突破失败后继续暴跌——下降楔形看涨的前提是它出现在大级别下跌的末端。
- 上升楔形在强势币种/股票上可以被「圆弧加速」演化，直接向上突破并逼空。

### 3.5 菱形（Diamond）

**形态描述**：前半段像扩大的喇叭形（宽幅震荡扩大），后半段像收窄的三角形，整体像菱形。通常出现在大级别顶部，是**看跌反转-持续混合形态**（多数情况看跌）。

```
菱形：
     ╱  ╲
    ╱      ╲
   ╱          ╲
  ╱  ╱    ╲   ╲
     ╲      ╱
```

**出现位置**：长期上涨后的高位宽幅震荡。

**含义**：宽幅扩张代表分歧剧烈（喇叭口），收敛代表一方最终胜出；跌破菱形下沿确认看跌，理论上也可向上突破但概率较低。

**确认信号**：向下突破时放量；菱形内成交量通常先放大后萎缩。

**失败场景**：
- 菱形在图表上很难精确画出，不同人画的菱形形状都不一样——主观性极强的形态，易被事后诸葛亮化。
- 突破后回踩不破下沿即回到菱形内部，形态作废。

## 4. 缺口理论

> 缺口 = 相邻两根 K 线之间出现一段「跳空」的价格空白区（没有任何成交）。缺口理论主要适用于股票（尤其 A 股，因涨跌停和隔夜制度缺口更常见）；期货/加密市场接近 24 小时连续交易，缺口较少、持续时间短，参考意义打折。

### 4.1 缺口的四种类型

| 缺口类型 | 出现位置 | 含义 | 是否回补 |
|---|---|---|---|
| 普通缺口 | 震荡区间内 | 无意义，纯噪音 | 很快回补（几乎必补） |
| 突破缺口 | 长期横盘/形态末端 | 趋势正式启动的标志 | 回补则说明突破失败 |
| 持续缺口（中继缺口） | 趋势中段 | 趋势加速进行中 | 通常不回补 |
| 衰竭缺口 | 趋势末端 | 最后一冲，动能即将耗尽 | 快速回补（顶部常见） |

```
突破缺口 → 持续缺口 → 衰竭缺口
      ↓            ↓           ↓
╱                        ╱
╱  ╱                 ╱  ╱
╱ ╱  ╱  ╱    ╱  ╱  ←── 衰竭缺口（随后暴跌回补）
╱╱╱╱
↑突破缺口（放量跳空） ↑持续缺口（趋势中继）
```

### 4.2 各缺口的要点

- **普通缺口**：出现在箱体/窄幅震荡内，成交量平淡，几天内就会被回补。看到普通缺口无需任何操作。
- **突破缺口**：配合放量 + 突破关键位（颈线、箱体上沿），是「有效突破」的最强确认之一。突破缺口 3 日内不回补 = 有效；快速回补 = 假突破，信号作废。
- **持续缺口**：趋势中段跳空，代表买/卖盘接力，缺口通常成为后续行情的支撑/压力位。出现持续缺口说明趋势仍健康，不要提前离场。
- **衰竭缺口**：趋势末端出现加速跳空，随后很快回补缺口并反转——常见于最后一波主升/主跌浪。**衰竭缺口必须等回补确认，回补当日往往就是转折日。**

### 4.3 缺口交易的失败场景

- 突破缺口被 2~3 日内回补，追突破者被套在假突破里——必须结合量能与收盘确认。
- 恐慌性缺口（暴跌跳空）虽属「衰竭性质」，但在杠杆市场会先爆掉追低者再反弹。
- 不要把 A 股缺口理论原样套用到加密市场：24 小时交易 + 高波动 + 无涨跌停，缺口经常是小时级甚至分钟级的，级别不对就失去意义。

## 局限与误区

1. **形态是事后才完整的**。当你「看见」一个头肩顶时，价格往往已经跌了一段。形态分析的天然缺陷是确认与滞后之间的两难：确认太晚没肉吃，确认太早是赌博。
2. **形态成功率远没有传说中高**。教科书上的经典形态（如头肩顶）在真实行情中的成功率普遍只有 50%~60% 左右，略好于抛硬币，且统计口径严重依赖主观识别。
3. **同一张图可以画出多种形态**。不同人看到的是不同的三角形/头肩，形态识别的主观性意味着「形态」本身就能自我实现或自我否定。
4. **震荡市是形态绞肉机**。趋势市里形态好用，震荡市里所有形态都会失效（假突破比例极高）。先判断市场状态，再使用形态。
5. **成交量确认不可或缺**。没有量能配合的形态，在流动性差的品种/时段上经常直接失效。
6. **形态必须服从交易系统**。一个 55% 胜率的头肩底形态，如果没有止损、没有仓位控制，照样让你亏光。形态只回答「可能是机会」，[07-交易系统篇](../07-交易系统篇/README.md) 才回答「怎么参与」。
