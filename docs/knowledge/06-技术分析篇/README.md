# 06 · 技术分析篇

> 前面几篇教你「看懂市场」，本篇教你「看懂图表」。K 线形态、技术指标、量价关系是技术分析的三大支柱，也是绝大多数行情软件的默认配置。读完本篇，你应该能独立判断一个图表上「正在发生什么」，以及「该不该相信图表上的信号」。
>
> **最重要的一句话：技术分析不是圣杯，它只是描述概率，不保证结果。** 本篇所有方法请配合 [07-交易系统篇](../07-交易系统篇/README.md) 的风险管理一起使用。

## 各篇简介

### 01 · K 线形态

从一根 K 线的实体与影线讲起，再到头肩顶、双顶双底、旗形、三角形等经典反转与持续形态，最后讲缺口理论。每个形态都附「形态描述、出现位置、多空含义、确认信号、失败场景」五件套，并配 ASCII 示意图。**核心是学会区分「形态本身」和「被确认的形态」——未确认前，一切都只是猜测。**

### 02 · 技术指标详解

按「趋势、动量、量能、波动、其他」五类逐一拆解 MA、EMA、BOLL、MACD、KDJ、RSI、CCI、WR、OBV、VWAP、ATR、SAR、Ichimoku 等常用指标：给出简洁计算公式、默认参数、核心用法与常见误区，最后给出「主图 + 副图」的指标搭配建议。**核心是理解指标是「价格的导数」，永远滞后于价格本身。**

### 03 · 量价分析

成交量是唯一不经过「加工」的原始数据，也是判断信号真假的最重要依据。本篇讲放量/缩量/堆量，八种量价关系的含义，突破时的量能确认，顶底背离，筹码分布（VPVR）与密集成交区，换手率与活跃度，以及「主力资金流向」为什么需要警惕。**核心是学会用成交量给价格信号做「背书」或「拆台」。**

## 本篇学习顺序

```
① K 线形态（认识图上的「形状」）
   ↓
② 技术指标（认识图上的「数值」，用指标给形态做交叉验证）
   ↓
③ 量价分析（用成交量给一切信号做最终确认）
```

- ①②③ 是层层递进的关系：没有形态，指标找不到参照物；没有成交量，形态和指标都可能被假信号骗。
- 本篇与前一篇 [03-K线与图表入门](../01-入门基础/03-K线与图表入门.md)（K 线构成与基础图表阅读）衔接，建议先复习该篇。
- 学完后按知识库路线图继续：[07-交易系统篇](../07-交易系统篇/README.md)（把本篇的技术信号变成有纪律的执行）。

## 内容约定

- 所有 K 线图中的「价格」仅作示意，不代表任何具体品种或行情。
- 指标公式与默认参数均为通用口径，不同软件存在差异，以你所使用软件的说明为准。
- 技术分析信号在震荡行情中可靠性显著下降，使用前请先判断行情状态（趋势 vs 震荡）。
- 涉及杠杆的用法（如根据 ATR 计算仓位）请务必先读完 [03-期货篇](../03-期货篇/README.md) 的保证金与强平部分。
