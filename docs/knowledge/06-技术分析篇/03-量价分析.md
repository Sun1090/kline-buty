# 03 · 量价分析

> 均线、MACD、KDJ 都是从「价格」里加工出来的，而**成交量是唯一未经任何数学加工、直接从市场里采集的原始数据**。这就是为什么技术分析界有句老话：「价格可以骗人，量能很难骗人。」量价分析的核心任务是：**用成交量判断当前价格的上涨/下跌是不是「真的」。**

---

## 1. 成交量基础

### 1.1 什么是成交量

成交量 = 某周期内成交的总数量（或总金额）。它是「参与度」的直接度量：

- 成交量放大的行情 = 参与的人多、分歧大、换手充分；
- 成交量萎缩的行情 = 参与的人少、观望多、分歧小。

### 1.2 放量 / 缩量 / 堆量

| 类型 | 定义（与近期均值比较） | 含义 |
|---|---|---|
| 放量 | 成交量明显高于近期平均（如 > 1.5~2 倍） | 市场参与度骤增，方向选择或动能爆发 |
| 缩量 | 成交量明显低于近期平均（如 < 0.5~0.7 倍） | 观望情绪浓，常见于横盘整理或趋势末端 |
| 堆量 | 连续多日阶梯式放量（量能「堆」起来） | 资金持续进场/离场，常伴随主升浪或主跌浪 |
| 天量 | 放量达到历史级别极值 | 往往是阶段性顶/底（分歧达到极限） |
| 地量 | 缩量到历史级别极值 | 抛压枯竭，变盘前奏（「地量见地价」但不绝对） |

```
堆量示意：
成交量│    █
      │   ██
      │  ███      ← 连续放量，像堆台阶
      │ ████
      │█████
      └──────────→ 时间
```

**核心认知**：
- 成交量永远需要「与谁比」：和近期均值比（放量/缩量），和历史极值比（天量/地量），孤立的绝对数字无意义。
- 放量本身不表明方向——**放量上涨和放量下跌都是放量**，方向由价格决定，量能决定「这次变动有多真实」。

## 2. 量价关系的八种基本形态

> 把「价格走向（涨/跌/平）」与「量能变化（增/减）」两两组合，得到八种基本量价形态。这是量价分析的核心工具表，建议背下来并对照行情复盘。

| # | 组合 | 形态 | 含义 | 操作倾向 |
|---|---|---|---|---|
| 1 | 价涨量增 | 健康的上涨 | 买盘主动、跟风盘足，趋势有望延续 | 持有/回踩买入 |
| 2 | 价涨量缩 | 上涨乏力 | 追高意愿不足，涨势存疑；高位出现警惕见顶 | 谨慎持有，勿追高 |
| 3 | 价跌量增 | 恐慌抛售 | 卖盘汹涌，跌势未止（下跌中继） | 不接飞刀 |
| 4 | 价跌量缩 | 抛压枯竭 | 卖的人少了，跌势放缓；缩量阴跌末端常接近底部 | 观察企稳信号 |
| 5 | 价平量增 | 分歧加剧 | 横盘中换手大增，多空激烈博弈，变盘临近 | 观望，等方向 |
| 6 | 价平量缩 | 交投清淡 | 无分歧也无方向，典型震荡市 | 观望 |
| 7 | 价涨量滞 | 放量滞涨 | 天量但价格涨不动 = 上方抛压极重，出货嫌疑 | 警惕见顶 |
| 8 | 价跌量止 | 放量不跌 | 天量但价格跌不动 = 下方承接极强，吸筹嫌疑 | 关注转强 |

**八种形态的三条铁律**：

1. **价涨必须有量陪跑**：放量上涨才真实，缩量上涨走不远。
2. **价跌放量要躲**：放量下跌说明卖盘没完，别急着抄底；放量下跌后的**第一次缩量企稳**才是观察点。
3. **一切以「突破放量」为反转前提**：底部和顶部的反转，几乎都伴随量能的剧烈变化——量能是反转的「血检报告」。

## 3. 突破时的量能确认

### 3.1 有效突破的三要素

```
有效突破 = 价格突破关键位（颈线/箱体/前高前低）
         + 放量（通常 ≥ 近期均量 1.5 倍以上）
         + 持续站稳（突破后 2~3 日不跌回关键位内）
```

- **放量突破**：大量真实买卖盘涌出，突破后回踩不破 = 有效突破，趋势启动。
- **缩量突破**：突破缺乏成交量支撑，大概率是假突破/诱多诱空，随后跌回原区间。
- **突破后缩量回踩**：回踩时缩量是好事（说明只是获利盘兑现、没有恐慌盘），回踩到关键位附近不破 = 二次上车机会。

### 3.2 假突破的典型识别

| 假突破特征 | 说明 |
|---|---|
| 突破无量 | 量能平平甚至萎缩，价格只是「滑过去」 |
| 突破后迅速收回 | 突破当日或次日就跌回关键位内 |
| 上影线长的突破 | 冲高被砸，收盘未能站稳关键位 |
| 大盘/板块不配合 | 个股突破但市场整体走弱，孤木难支 |

**一句话**：**突破看量，站稳看价。** 量确认「有人真的在买/卖」，价确认「买/卖的结果被守住了」。

## 4. 顶背离与底背离

> 背离 = 价格走势与量能走势方向不一致。价格和量能「意见不合」时，通常是价格在说谎。

### 4.1 顶背离（量价背离，看跌）

**形态**：价格创新高，但成交量（或 OBV）没有同步创新高，反而逐步萎缩。

```
价格     ↗  ↗
        ╱╲ ╱╲   ← 一峰比一峰高
成交量  ╱  ╲╱
      ╱╱╱╱    ← 一峰比一峰低（量跟不上）→ 顶背离
```

**含义**：越涨越没人跟，上涨是「空涨」，随时可能反水。常见于：连续大涨后的主升浪末端、利好兑现的冲高段。

### 4.2 底背离（看涨）

**形态**：价格创新低，但成交量（或 OBV）没有创新低，甚至放量。

```
价格    ╲  ╲
        ╲╲ ╲╲   ← 一谷比一谷低
成交量  ╲
       ╱╱╲      ← 底部放量/缩量到极限（跌不动了）→ 底背离
```

**含义**：越跌越有资金承接，下跌是「空跌」，随时可能反转。配合长下影线/十字星等底部形态更可靠。

### 4.3 背离使用的三条戒律

1. **背离不是点，是段**：背离只能说明「动能衰竭」，不能告诉你「具体哪天反转」——背离后价格继续创新高/新低是常态。
2. **周期越大越可靠**：日线背离 > 分钟线背离。分钟线背离一天出现十几次，毫无价值。
3. **背离要等确认**：价格趋势线/关键位被破坏才是背离生效的最终确认，否则按背离抄底摸顶，一样死。

## 5. 筹码分布（VPVR）与密集成交区

### 5.1 什么是筹码分布

**筹码分布（VPVR，Volume Profile Visible Range）**：把每个价位的成交量横着堆起来，形成「价格—成交量」横向分布图，用来回答**「市场大多数人的持仓成本在哪个价位」**。

```
价格
50 ┤█████████      ← 密集成交区（大量筹码在这里换手）
45 ┤███
40 ┤█████████████  ← 更密集（主密集区）
35 ┤█████
30 ┤██
    └────────── 成交量
```

### 5.2 密集成交区的作用

| 概念 | 含义 | 交易含义 |
|---|---|---|
| 密集成交区 | 大量筹码换手的价位区间 | 该区域上方 = 大量套牢盘（压力），下方 = 大量获利盘（支撑） |
| 筹码峰 | 分布图中最高的峰 | 市场成本中心：跌破后由支撑变压力，突破后由压力变支撑 |
| 筹码真空区 | 几乎无成交的价位段 | 无套牢盘，价格穿越极快（跳空/急拉的常见区域） |
| 筹码移动 | 峰从高位移到低位 | 高位套牢盘割肉换手完成，底部筹码集中 = 发动行情的基础 |

### 5.3 用法与误区

- **支撑/压力的确认**：价格跌到密集成交区上沿获支撑 = 可靠支撑；反之突破密集成交区需要放量（解放套牢盘需要真实买盘）。
- **底部吸筹形态**：长期下跌后，高位筹码峰逐渐下移、底部筹码集中 = 换手充分，底部坚实。
- **误区**：筹码分布是**用历史成交数据估算**的（不同软件的估算算法不同），不是真实持仓数据；主力对倒交易可以制造虚假筹码峰。它只适合当「相对参考」，不能当精确的持仓统计。

## 6. 换手率与活跃度

### 6.1 换手率

```
换手率 = 当日成交量 / 流通股本 × 100%
```

表示「一天内有多少比例的流通盘易手」，是衡量**活跃度**的核心指标。

| 换手率区间 | 活跃度 | 解读 |
|---|---|---|
| < 1% | 极清淡 | 无人关注，流动性差，买卖点差大 |
| 1% ~ 3% | 正常 | 日常水平（大盘蓝筹常态） |
| 3% ~ 7% | 活跃 | 题材/小盘股活跃期，短线机会多 |
| 7% ~ 15% | 高活跃 | 强庄/大资金博弈期，波动剧烈 |
| > 15% | 极度活跃 | 过热：天量换手 = 多空极端分歧，注意见顶风险（新股除外） |

### 6.2 换手率的使用要点

- **高换手 + 滞涨 = 出货**：换手率持续高位但价格涨不动，说明有人在大量派发。
- **低换手 + 阴跌 = 无人接盘**：想卖都卖不出去，阴跌绵绵。
- **横盘期换手骤增**：可能是建仓或变盘前兆，观察方向。
- **误区**：换手率的绝对值受流通盘大小影响（小盘股天然高换手），需与自身历史水平比，不要跨品种硬比。

## 7. 主力资金概念与真假

### 7.1 「主力资金流向」是什么

主流软件把成交单按金额大小分类（如大单 > 50 万、中单、小单），把大单净流入（买入额 − 卖出额）定义为「主力资金净流入/流出」，并渲染成「主力在买/卖」。

### 7.2 为什么必须警惕这个数据

1. **「大单」≠「主力」**：机构资金为了不暴露意图，会把大单拆成小单分批成交（冰山订单）；游资/量化也可以故意挂大单制造假象。按单子大小划分主力，本质上是在猜。
2. **方向性失真**：软件把主动买入的大单算「主力流入」、主动卖出的大单算「主力流出」。但一笔大单是「主动买」还是「主动卖」，取决于对手盘挂单的位置——同一笔交易在沪深交易所撮合规则下的归属判定并不精确。
3. **极易被对倒操纵**：同一资金自买自卖（对倒）可以制造「主力净流入 X 亿」的数据，配合拉升出货的剧本，数据变成诱多工具。
4. **统计口径各家不同**：同一天同一只股票，不同软件显示的「主力净流入」数字可能完全相反。

### 7.3 怎么用才不踩坑

- **当情绪指标用，不当真相用**：「主力净流入」只能反映「大单行为的统计」，别把它当「庄家的意图」。
- **交叉验证**：结合价格位置（低位净流入 vs 高位净流入含义完全不同）、换手率与真实成交量走势综合判断。
- **最可靠的「主力痕迹」其实是量价本身**：长时间低位堆量吸筹（放量不涨）、拉升前缩量洗盘（缩量回调），这些形态是资金行为的「指纹」，比任何资金流数据都硬。

## 8. 成交分布与多周期量能配合

### 8.1 成交分布的三个维度

| 维度 | 看什么 | 说明 |
|---|---|---|
| 时间分布 | 日内哪个时段放量 | 开盘/收盘时段通常放量（机构调仓）；午间缩量 |
| 价位分布 | 放量发生在哪个价位 | 放量在关键位（前高/颈线）= 真突破；放量在无关价位 = 噪音 |
| 方向分布 | 主动买 vs 主动卖 | 主动买占比高 = 买方主动追价，力量真实 |

### 8.2 多周期量能配合

```
多周期确认原则：大周期定方向，小周期找节奏

周线：量能是否支持大级别趋势（放量上涨 = 大趋势健康）
日线：本轮上涨/下跌的放量缩量节奏是否健康
60 分钟 / 15 分钟：短线突破与回踩的量能确认
```

**典型配合案例**：
- 周线放量 + 日线缩量回调 + 分钟线放量突破 = 三级共振，可靠性最高。
- 周线缩量 + 日线放量滞涨 = 大级别动能不足，日内放量只是反弹，不追。

### 8.3 多周期量能的误区

- 各周期信号矛盾时（日线缩量上涨但周线天量），以**更大周期**为准——小周期量能只是大周期的一个片段。
- 不要把小周期（15 分钟）的天量当「天量」：级别不对，结论全错。

## 局限与误区

1. **成交量也可能骗人**：对倒、对敲、假挂单、量化拆单可以让成交量失真。「价格骗人，量很难骗人」在机构与量化主导的市场里要打折扣——量能数据本身也会被操纵。
2. **「放量必涨/缩量必跌」是外行话**：放量既可以向上突破，也可以向下破位；缩量既可以是洗盘，也可以是无人接盘。量能必须结合价格位置解读。
3. **背离与量价形态都滞后于拐点**：你看到「顶背离」时，主力通常已经出完第一批货。量价分析的价值在于「减少被骗」，不在于「提前一步」。
4. **换手率与筹码分布依赖估算**：流通股本口径、筹码估算算法都会导致偏差；质押、锁定盘等因素让「流通」的定义模糊。
5. **低流动性品种一切量价信号都失真**：成交量本身太小（如垃圾币、冷门股），几笔单子就能制造天量/地量假象，量价关系在这些品种上完全不可靠。
6. **量价分析同样只描述价格行为**：利好/利空、基本面变化可以瞬间让量价规律失效（利好刺激的缩量涨停照样连板）。量价是「观察工具」，不是「原因」——一切信号最终都要服从风险控制与交易纪律（见 [07-交易系统篇](../07-交易系统篇/)）。
