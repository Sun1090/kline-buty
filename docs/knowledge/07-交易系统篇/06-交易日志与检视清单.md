# 06 · 交易日志与检视清单

> 交易计划篇给了你「进场前」的规则，复盘进阶篇给了你「平仓后」的统计，本篇补上中间那段最容易被跳过、却最能稳定执行的部分：**每天写什么、每周查什么、每月审什么**。日志记录「发生了什么」，检视清单确保「该做的都做了」——两者合起来，才构成一个可迭代的交易系统闭环。

---

## 一、日志与检视清单的分工

| | 交易日志 | 检视清单 |
|---|---|---|
| 回答 | 「我做了什么」 | 「我该做的做了没有」 |
| 形式 | 叙述 + 数据（模板化记录） | 打勾列表（检查项） |
| 频率 | 每笔 / 每日 | 每日 / 每周 / 每月 |
| 目的 | 留下可追溯的事实 | 防止遗忘与侥幸 |

**为什么清单比意志力可靠**：交易中最贵的错误不是「判断错」，而是「流程漏」——忘了看隔夜消息、忘了挂**<mark>止损</mark>**、情绪上头直接重仓。清单把「应该做」变成「勾选」，把纪律从记忆负担里解放出来。

> **核心认知：日志回答「事实是什么」，清单回答「纪律在不在」。** 先记录事实，再按清单核对纪律，最后才谈判断对错——顺序反了，复盘就变成了给自己找理由。

---

## 二、每日日志结构：三段式

### 2.1 开盘前（5-10 分钟）

开盘前不是「猜涨跌」，是「核对状态」：

```markdown
## 开盘前检查（日期 / 品种 / 周期）
- [ ] 隔夜消息面：是否有财报/数据/政策/大事件（____）
- [ ] 当前持仓：____ 笔，方向 ____，止损 ____，目标 ____
- [ ] 今日计划触发位：突破 ____ / 回踩 ____ / 失效位 ____
- [ ] 仓位上限：今日最大风险 = 账户 × ____%（固定比例，见风险管理篇）
- [ ] 情绪状态自评：平静 / 焦虑 / 亢奋（____）
- [ ] 今日不操作清单（如果写了就贴这）：____
```

**要点**：开盘前只做「确认」，不做「预测」。如果昨晚没睡好/情绪不稳，直接在「情绪状态」里写下来——**状态异常时，当天最多只执行计划内信号，不开新仓**。

### 2.2 盘中（每笔记录）

每笔交易执行后 1 分钟内完成记录，模板从 [01-交易计划](01-交易计划.md) 的日志模板升级为「对照版」：

```markdown
### 交易 #____
- 时间：____ / 品种：____ / 方向：____
- 进场依据（复制计划原文）：____
- 进场价 / 止损 / 目标：____ / ____ / ____
- 是否符合计划：[ ] 是 [ ] 否（否→为什么：____）
- 平仓价 / 盈亏：____ / ____
- 平仓依据：____（目标/移动**<mark>止盈</mark>**/信号反转/时间止损/____）
- 执行偏差（如有）：____
```

**关键**：盘中只记录「做了什么」和「依据是什么」，**不写「我觉得会涨」这类后验情绪**——情绪留给收盘后的日志写，盘中写情绪只会干扰下一笔。

### 2.3 收盘后（5-10 分钟）

收盘后日志是每日的「小复盘」，只问三个问题：

```markdown
## 收盘后日志
1. 今天执行了几笔？____ 笔；其中符合计划 ____ 笔，违规 ____ 笔
2. 违规的那几笔，卡在哪一步？（没等确认 / 没挂止损 / 加仓 / 情绪冲动 / 其他）
3. 明天要改的一个动作：____（只改一个，改多了等于没改）
4. 今天最该记住的市场事实（非观点）：____
```

**要点**：收盘后日志控制在 5-10 分钟，只输出「一个待改进动作」。**每天改一个动作，一周就是五个可验证的改进项**——比周末一次性「深刻反思」有效得多。

## 三、每周检视清单

每周日花 30-60 分钟，按清单逐项打勾。注意：**周检视的对象是「系统」，不是「这一周赚没赚钱」**。

```markdown
## 每周检视（第__周）
### 执行面
- [ ] 本周共 ____ 笔，符合计划 ____ 笔，执行偏差率 = ____%（目标 < 10%）
- [ ] 偏差集中在：进场时机 / 止损执行 / 仓位 / 提前平仓 / 报复性交易（____）
- [ ] 本周有没有「计划外」交易？____ 笔，原因：____

### 结果面
- [ ] 本周盈亏：____；与执行偏差率是否匹配（偏差高还赚钱=运气，偏差低却亏钱=策略问题）
- [ ] 盈利单/亏损单的平均盈亏比：____（目标：符合策略设计）

### 环境面
- [ ] 本周行情与策略匹配度自评（1-5）：____
- [ ] 是否出现过「策略内连续亏损」？____（如果是，是正常回撤还是策略失效？）

### 输出
- [ ] 下周要做的 1-2 个调整：____
- [ ] 下周最大风险事件/数据：____
```

**周检视的三条纪律**：

1. **先统计后解释**：先把执行偏差率、盈亏比算出来，再谈「为什么」；
2. **区分运气与能力**：单周赚大钱不一定是你厉害，单周亏钱也不一定是策略坏了——看**执行偏差率**这个不依赖结果的指标；
3. **调整要小步**：每次只改参数的一小部分，改完记录「改动 + 预期效果」，下周对照验证。

## 四、月度系统检视

月度检视是「系统级的体检」，可以结合 [05-交易复盘进阶](05-交易复盘进阶.md) 的三层复盘框架：

```markdown
## 月度系统检视（____月）
### 数据
- [ ] 总笔数 / 胜率 / 平均盈亏比 / 最大回撤：____
- [ ] 与上个月对比：胜率 ____，盈亏比 ____，回撤 ____（趋势是变好还是变差？）
- [ ] 按品种/方向/时段拆分的盈亏分布（钱从哪赚来、在哪亏掉）：____

### 规则
- [ ] 本月计划内规则被执行的比例：____%
- [ ] 有没有某条规则「反复不被执行」？____ → 是删掉它，还是换执行方式（如改为自动化提醒）？
- [ ] 有没有某条规则「从未触发」？____ → 是市场没给机会，还是规则本身无效？

### 仓位与风险
- [ ] 单笔最大亏损是否超过预设风险上限？____
- [ ] 月内是否出现过「加仓/扛单」类违规？____

### 输出
- [ ] 下月规则变更清单（明确写「删/改/加」）：____
- [ ] 下月验证目标（用可统计的指标，如执行偏差率降到 X%）：____
```

**月度检视的产出必须是一份「变更清单」**：删掉无效规则、修正失效参数、新增验证项——没有变更的月度复盘，等于这个月白过。

## 五、检视清单的落地工具

| 工具 | 适用 | 说明 |
|---|---|---|
| 纸质/备忘录 | 最简起步 | 每天 3 分钟，先养成「记录」习惯 |
| Excel/表格 | 数据统计 | 适合月度汇总与执行偏差率计算 |
| Notion/飞书多维表格 | 模板化 | 预设好日志/周报/月报模板，手机即可记录 |
| 交易终端内置记录 | 盘中快速记录 | Kline Buty 的仓位/自选记录可作为盘中速记 |
| 自动化提醒 | 防遗忘 | 收盘后定时弹「今天写日志了吗」提醒 |

**起步建议**：不要一上来搭完美的表格系统——**先连续记录 20 笔 + 2 个完整周检视**，再根据实际痛点升级工具。工具是让流程变顺的，不是让流程变重的。

---

## 小结

一个可迭代的交易系统 = **计划（事前）+ 日志（事中）+ 清单（事后）+ 变更（迭代）**。本篇的每日三段式日志解决「事实记录」，每周/每月检视清单解决「纪律核对与系统迭代」。先跑起来，再优化模板——**记录 100 笔之后，你手里的数据就是任何书都给不了的个人化教材**。

> 一句话：**日志是给未来的自己看的证据，清单是给冲动时的自己上的锁——两者缺一，复盘就只是自我安慰。**
