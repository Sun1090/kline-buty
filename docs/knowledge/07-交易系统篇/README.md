# 07 · 交易系统篇

> 前面所有篇章教你「看懂市场」，本篇教你「管好自己」。技术分析解决的是买什么、何时买，交易系统解决的是买多少、何时止损、亏损了怎么办、赚了会不会还回去。**没有系统的交易是赌博，有系统的交易是生意。**

## 各篇简介

### 01 · 交易计划

没有计划的下单就是赌博：凭「感觉要涨」进场、亏了死扛、赚一点就跑，这是 90% 散户的日常。本篇给出**交易计划八要素**（市场/周期/入场/出场/止损/仓位/复盘/心态）和一个可以直接复制填写的完整模板，并教你如何把「感觉要涨」翻译成可执行、可验证、可复盘的条件。最后用期望值公式 EV = 胜率×平均盈利 − 败率×平均亏损 算给你看：**为什么 30% 胜率的策略照样赚钱，50% 胜率的策略照样亏钱。**

### 02 · 风险管理

先想能亏多少，再想能赚多少——这是交易里唯一不能妥协的顺序。本篇讲透仓位管理三件套（固定比例 1%-2% 风险/笔、凯利公式的用法与局限、等值开仓），四种止损法（固定金额/ATR/结构位/时间），以及移动止盈让利润奔跑的方法。数学部分直接用表格推演：**回撤 50% 需要涨 100% 才回本**、5x/10x/20x/50x 杠杆反向多少百分比就爆仓——看完你会明白「控制回撤」不是风格问题，是生死问题。

### 03 · 交易心理

为什么散户永远买在高点、卖在低点？为什么明明知道该止损手却按不下去？为什么连亏三笔之后最容易爆仓？本篇从神经机制讲起（FOMO 与恐慌怎么劫持你的大脑），逐一拆解五大心理偏差（损失厌恶/锚定效应/确认偏差/赌徒谬误/处置效应），每条都带定义、交易场景例子和应对方法。最后回答那个终极问题：**为什么知道做不到**，以及怎么用规则、冷静期和自动化把纪律变成习惯。

## 本篇学习顺序

```
① 交易计划（先定规则：什么时候做、怎么做）
   ↓
② 风险管理（再定死线：最多亏多少、怎么活下来）
   ↓
③ 交易心理（最后修自己：为什么总违反 ①②）
```

- ① 和 ② 可以并行学习，但**必须先于真实资金**：先用模拟盘或纸面交易跑满 20-30 笔，再上小仓位。
- ③ 是终极难点：读完全篇你大概率依然会犯心理错误，区别在于你有清单可以对照、有日志可以复盘。
- 学完本篇后，建议结合 [06-技术分析篇](../06-技术分析篇/README.md) 的知识完成你的第一份完整交易计划，然后进入 [08-入土篇](../08-入土篇/README.md) 看看别人是怎么死掉的。
