# 04 · 股票篇

> 股票是普通人接触最多的资产：A 股、港股、美股，三套市场三套规则。
> 本篇先讲清股票的本质与指数，再分别拆解 A 股与港美股的交易规则，
> 最后给出一套从基本面到估值、再到避坑的分析方法论。

## 各篇简介

### 01 · 股票基础

股票到底是什么、股东有哪些权利、市场上有哪些参与者，以及一家公司从创立到 IPO 上市要走过什么流程。然后认识最重要的指数（上证指数、沪深300、恒生指数、标普500 等），学会区分分红、送股、转增与除权除息，最后用一张表说清股票、期货、现货三者本质差异。**本篇章的地基，全部规则概念都在这里第一次出现。**

### 02 · A 股交易规则

A 股实战手册：几点开盘几点收盘、集合竞价怎么撮合、T+1 到底限制什么（以及怎么用底仓合法变相 T+0）、主板/创业板/科创板/北交所各自的涨跌幅与新股首日规则、100 股一手与零股卖出、佣金印花税过户费每一笔钱花在哪、打新股怎么配市值、融资融券的门槛与玩法、普通/信用/港股通三类账户，以及北向资金是怎么一回事。**买了 A 股前必读。**

### 03 · 港股与美股

想出海投资？先看这套规则：港股的 T+0 回转与 T+2 交收、无涨跌停但有市场波动调节机制、港股通渠道；美股的盘前盘后时段、T+1 结算、熔断机制、零股交易；再到券商怎么选、资金出境有哪些合规渠道、中概股 ADR 是什么。**重点：境内资金出海约束极多，合规永远是第一前提。**

### 04 · 股票分析方法

从宏观到行业再到公司三层拆解基本面，教你怎么读资产负债表、利润表、现金流量表三张报表和 ROE、毛利率、负债率等关键指标；然后讲 PE、PB、PS、股息率、DCF 这些估值工具的适用场景与各自的坑；最后是技术面与消息面的正确打开方式，以及财务造假信号、高位接盘、炒小炒差等散户最常踩的陷阱。**完整读完这一篇，你才配说自己在"研究股票"而非"猜涨跌"。**

### 05 · ADR 与跨境上市

中概股凭什么在美国交易、买 BABA/PDD 到底买的是什么：ADR 的发行机制与存托银行、1 ADR = N 股普通股的兑换逻辑，再到 2000 年门户上市、2014 阿里 IPO、2021 监管风暴（滴滴事件与审计底稿问题）、2023 PCAOB 协议落地的完整历史；然后讲清 ADR 与普通股的折溢价、双重主要上市与二次上市的差异、红筹与 VIE 架构的法律风险，最后给出美股券商/港股通/QDII 三种参与方式的对比与中概股特有风险。**买中概股之前必读，合规永远是第一前提。**

### 06 · 美股期权入门

在期权基础篇之上做美股实操向升级：全球最活跃的期权市场特征、个股（美式）与指数（欧式）期权在行权上的实操差异、期权链的读法；然后带数字手把手算 Covered Call 备兑收租、Protective Put 保险、Cash-Secured Put 卖沽接货、Bull Call Spread 牛市价差四大入门策略；再讲美股独有的权限分级（Tier 1-4）、保证金与税务常识，以及裸卖爆仓、末日轮归零、流动性滑点等常见死法。**卖方风险是重点，看不懂义务就一分钱都不要投。**

### 07 · ETF 组合构建

普通人的全球资产配置实操手册：SPY/VOO/IVV 费率对比、QQQ 低费替代、风格行业/全球/债券商品 ETF 一张清单配齐；然后是三支基金组合（VTI+VXUS+BND）与永久组合（股票+长期国债+黄金+现金）的美股版配比与再平衡数字例子；最后是定投实操（券商、出入金、汇率、30% 分红税预扣）、DCA 与一次性投入的数学对比和组合体检清单。**用最低费率、最大流动性、最省心的方式长期持有，而不是频繁折腾。**
