# 04 · 股票篇

> 股票是普通人接触最多的资产：A 股、港股、美股，三套市场三套规则。
> 本篇先讲清股票的本质与指数，再分别拆解 A 股与港美股的交易规则，
> 最后给出一套从基本面到估值、再到避坑的分析方法论。

## 各篇简介

### 01 · 股票基础

股票到底是什么、股东有哪些权利、市场上有哪些参与者，以及一家公司从创立到 IPO 上市要走过什么流程。然后认识最重要的指数（上证指数、沪深300、恒生指数、标普500 等），学会区分分红、送股、转增与除权除息，最后用一张表说清股票、期货、现货三者本质差异。**本篇章的地基，全部规则概念都在这里第一次出现。**

### 02 · A 股交易规则

A 股实战手册：几点开盘几点收盘、集合竞价怎么撮合、T+1 到底限制什么（以及怎么用底仓合法变相 T+0）、主板/创业板/科创板/北交所各自的涨跌幅与新股首日规则、100 股一手与零股卖出、佣金印花税过户费每一笔钱花在哪、打新股怎么配市值、融资融券的门槛与玩法、普通/信用/港股通三类账户，以及北向资金是怎么一回事。**买了 A 股前必读。**

### 03 · 港股与美股

想出海投资？先看这套规则：港股的 T+0 回转与 T+2 交收、无涨跌停但有市场波动调节机制、港股通渠道；美股的盘前盘后时段、T+1 结算、熔断机制、零股交易；再到券商怎么选、资金出境有哪些合规渠道、中概股 ADR 是什么。**重点：境内资金出海约束极多，合规永远是第一前提。**

### 04 · 股票分析方法

从宏观到行业再到公司三层拆解基本面，教你怎么读资产负债表、利润表、现金流量表三张报表和 ROE、毛利率、负债率等关键指标；然后讲 PE、PB、PS、股息率、DCF 这些估值工具的适用场景与各自的坑；最后是技术面与消息面的正确打开方式，以及财务造假信号、高位接盘、炒小炒差等散户最常踩的陷阱。**完整读完这一篇，你才配说自己在"研究股票"而非"猜涨跌"。**
