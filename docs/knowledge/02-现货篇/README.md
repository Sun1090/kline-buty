# 02 · 现货篇

> 现货是交易世界最简单的形态：一手交钱、一手交货，没有杠杆、没有交割、没有强制平仓。
> 本篇从零讲清现货买卖的底层逻辑，再展开定投、网格、套利等低风险策略，
> 最后单独拿出一篇讲加密货币现货这个"看起来像现货、水却最深"的专题。

## 学习建议

- 先读 [01-现货交易基础.md](01-现货交易基础.md)，把"现货 vs 期货""限价 vs 市价"这些概念弄扎实，它们是后续所有篇章的地基。
- 若目标只是低风险理财，读完 02 中的「定投」即可；想赚超额收益再往后看。
- 加密现货与普通现货差异极大，**没有**其他交易经验时请先读 03 的「风险」部分，再考虑入场。

> 现货虽然风险最低，但仍有归零、市场流动性枯竭、平台风险等隐患。任何一笔买入前，先问自己：这笔钱亏掉能接受吗？
