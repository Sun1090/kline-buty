# 03 · 券商与期货公司选择

> 行情、数据、工具都齐了，最后一道选择题是：**钱放哪、在哪下单。** 这个选择直接决定你的交易成本（佣金、利息、滑点）与资金安全。
>
> 本篇按四类通道展开：A 股券商、期货公司、港美股券商、加密交易所——每类讲清「怎么比、比什么、坑在哪」，最后给出一份**无论开什么账户都适用的安全检查清单**。

### 四类通道一页速览

| 通道 | 选型核心变量 | 成本大头 | 安全核心 |
|---|---|---|---|
| A 股券商 | 佣金（万 1-万 3）、App、两融利率 | 佣金 + 印花税（统一） | 三方存管（资金在银行） |
| 期货公司 | 保证金加收、CTP 通道、交返 | 手续费（双边） | 保证金监控中心存管 |
| 港美股券商 | 牌照、出入金、佣金结构 | 佣金 + 汇率/电汇费 | 牌照与投资者保护计划 |
| 加密交易所 | KYC、法币通道、合规状态 | 手续费 + 资金费率（合约） | 平台信誉 + 自托管备选 |

> ⚠️ 风险提示
>
> 文中佣金、利率、保证金比例、返佣等数值均为行业通行口径，随市场与各家政策动态变化，**一律以各机构最新官方公告为准**。境外券商与加密交易所在中国大陆的合规状态、可访问性各异，开户与入金前请自行确认所在地法规。本文所有平台描述仅为选型框架参考，不代表任何推荐或背书。市场有风险，投资需谨慎；本文不构成投资建议。

## 一、A 股券商怎么选

### 1.1 佣金费率：万 1-万 3 的行情常识

- 行业通行佣金率约在**万 1 到万 3**（万分之 1 ~ 万分之 3）之间，单笔最低 5 元（部分券商有减免政策，以最新公告为准）；
- 佣金由「净佣金（券商收入）+ 规费（监管/交易所收取）」构成，**对比时问清是「全佣」还是「净佣」**，全佣才是一口价；
- 印花税（卖出单边征收）与过户费为国家/交易所统一收取，与券商无关，别被「零佣金」话术误导；
- 谈判要点：开户时直接提「调到万 1.5 或万 2，是否含规费」，多数券商可谈；资金量大可再谈，**费率以最终协议为准**。

### 1.2 App 体验

- 交易软件是否稳定、下单/撤单是否顺畅、是否支持条件单与网格等常用功能；
- 行情延时会否影响你的快速交易（见 [01-行情软件全景](01-行情软件全景.md) 的数据陷阱）；
- **交易通道与看盘软件分离**：开户券商 App 只负责下单，看盘用你自己的工具组合。

### 1.3 融资融券利率

- 开通两融有资金与交易经验门槛（50 万 + 半年经验，以最新规定为准）；
- 融资利率差异很大：行业基准利率之上，头部券商与中小券商差距明显，**可以谈，通常资金越多越便宜**；
- 两融是杠杆工具，利率是成本项不是收益项——先用普通账户把交易做好再说。

### 1.4 开户流程与一人三户规则

- **一人三户**：一个投资者在同一市场最多开立三个证券账户（深圳/上海各按规则管理，以最新规定为准），加挂与销户可线下办理；
- 开户流程：手机 App 视频见证即可完成，多数券商 1-3 个工作日生效；
- 提示：先对比费率与 App 再开户，三户名额用满后更换券商的成本会上升；
- 换券商：转户（同市场内转移持仓）流程已线上化，但涉及在途资金与质押/两融持仓时较繁琐——**先想清楚再开户，避免频繁来回**。

### 1.5 营业部线下服务 vs 互联网券商

| 维度 | 营业部线下服务 | 互联网券商（头部券商线上渠道） |
|---|---|---|
| 特色 | 面对面开户指导、复杂业务（两融、期权、线下销户）方便办理 | 开户快、费率透明、App 迭代快、线上业务全流程化 |
| 适合 | 需要人工服务、有线下业务需求的中老年/高净值用户 | 熟悉线上操作的年轻用户与自学者 |

**结论**：多数个人交易者的核心诉求是「费率低 + App 稳 + 线上业务全」，选头部券商 + 线上渠道即可；营业部网点多的券商在应急与线下业务上更从容。

## 二、期货公司怎么选

### 2.1 保证金比例：加收 3-5 个百分点的行业惯例

- 期货公司会在交易所保证金基础上**加收一定比例**（行业通行为 3-5 个百分点，可协商下调），加收越高资金占用越高；
- 可谈：入金后向客户经理申请「保证金优惠」或按交易所标准执行，**具体比例以期货公司最新政策为准**；
- 注意：保证金下调意味着杠杆上升，是双刃剑——先算清楚自己的风控再谈。

### 2.2 CTP 通道稳定性

- 国内期货主流交易通道是 **CTP**（上期技术），各家期货公司的 CTP 接入质量、行情与交易线路延迟、故障率有差异（原理见 [10-系统对接篇](../10-系统对接篇/README.md)）；
- 高频/程序化交易者应关注：是否有**交易与行情分离的独立通道**、是否支持 **CTP 二席/多通道**、盘中的报单延迟与撤单率；
- 普通手工交易者：通道差异感知有限，选择大公司即可获得基本保障。

### 2.3 手续费与交返（手续费返还）

- 手续费按交易所标准 + 期货公司加收构成；期货公司普遍可在交易所基础上加收很少或协商优惠；
- **交返**：期货公司会按交易所返佣规则把部分手续费返还给交易者（行业通行做法，各公司比例与条件不同，以最新政策为准）——高频/大成交量交易者特别关注，普通交易者影响有限；
- 注意区分：交返是期货公司让利，与「非法配资/代理」不是一回事；任何声称「无条件高返」的渠道都要警惕。

### 2.4 开户门槛与特殊品种权限

| 品种 | 门槛（以最新规定为准） |
|---|---|
| 商品期货（一般品种） | 无资金门槛，本人开户即可 |
| 特定品种/期权（铁矿石、PTA、股指期权等） | 50 万资金验资 + 交易经验 + 知识测试（商品特定品种门槛为 10 万） |
| 股指期货/国债期货 | 50 万资金验资 + 经验 + 测试 |
| 原油期货 | 50 万资金验资 + 经验 + 测试 |

- 门槛以中国证监会与各交易所最新规定为准，期货公司官网均有申请指引；
- 新手路径：先做一般商品期货（如螺纹、豆粕），模拟盘与小额实盘并行，再考虑权限升级。

### 2.5 模拟盘先行

- 大部分期货公司提供免费的 CTP 仿真账户（SimNow 等），真实规则、无真实资金；
- 建议流程：模拟盘跑通「开户 → 出入金 → 下单 → 交割/强平」全流程，再入金，见 [03-期货篇](../03-期货篇/README.md)。

### 2.6 期货公司速选决策表

| 你的情况 | 优先看什么 |
|---|---|
| 手工趋势/波段交易 | 手续费加收是否合理、App 与下单软件体验、客服响应 |
| 日内高频/程序化 | CTP 通道稳定性、交易与行情分离、撤单率与延迟、交返比例 |
| 资金量大 | 保证金优惠、交返比例、专属客户经理服务 |
| 新手刚起步 | 模拟盘体验、投教内容、最低资金门槛友好度 |

## 三、港股美股券商

| 维度 | 盈透证券（IBKR） | 富途 | 老虎证券 |
|---|---|---|---|
| 定位 | 全球综合经纪商，机构级 | 港美股互联网券商 | 港美股互联网券商 |
| 牌照 | 美国/欧洲等多地持牌，监管体系成熟 | 香港/美国等地持牌 | 香港/美国等地持牌 |
| 特色 | 全球多市场覆盖广（美股/港股/期权/期货/债券）、利率透明、API 开放（TWS API） | 中文体验好、社区与资讯强、打新体验佳 | 中文体验好、期权/美股特色功能全 |
| 佣金 | 按股/按笔阶梯式，结构复杂但整体低 | 固定费率，清晰 | 固定费率，清晰 |
| 出入金 | 电汇为主，支持多币种账户 | 电汇 + 部分快捷入金方式 | 电汇 + 部分快捷入金方式 |

**选择要点**：

- **资金安全看牌照**：查监管牌照号（美国 SEC/FINRA、香港 SFC 等）与投资者保护计划（如 SIPC 对证券资产的保险范围、香港投资者赔偿基金），**赔偿范围与上限以各机构官方说明为准**；
- 出入金：境内银行卡 → 境外券商属于**跨境资金流转，涉及外汇管理规定**，务必自行确认合规路径（见 [08-入土篇-03 合规与税务](../08-入土篇/03-合规与税务.md)）；
- 佣金结构：用一张「模拟账单」算清楚——盈透阶梯费率的低费用适合高频/大单，固定费率适合普通散户；
- 有程序化需求者优先考察**官方 API**（IBKR TWS API 对个人开放，富途/老虎亦有开放平台），政策与限频以各公司官方文档为准；
- 额外细节：港美股账户的**股息税、印花税、外汇结算**规则与 A 股不同，成本核算时一并计入（详见 [04-股票篇-03](../04-股票篇/03-港股与美股.md)）。

## 四、加密交易所选择

| 维度 | 币安 Binance | OKX | Bybit | Coinbase |
|---|---|---|---|---|
| 特色 | 全球现货/合约流动性领先 | 合约产品线全、界面专业 | 合约与衍生品特色突出 | 美国合规样板、对新手友好 |
| KYC 政策 | 强制 KYC（认证后才能交易） | 强制 KYC | 强制 KYC | 强制 KYC（更严格，含更细的身份核验） |
| 法币通道 | 支持多法币入金（地区限制明显） | 支持多法币入金 | 支持多法币入金 | 支持美元/欧元等，银行级合规通道 |
| 现货 vs 合约 | 现货 + U 本位/币本位合约 | 现货 + 合约 | 现货 + 合约 | 现货为主，合约针对特定地区用户 |
| 合规状态 | 各地持牌与牌照调整频繁 | 各地区牌照与限制各异 | 各地区牌照与限制各异 | 美国合规运营，多州持牌 |

**选择要点**：

- **先确认你所在地的可访问性与合规状态**：中国大陆用户访问多数境外加密交易所存在限制与政策风险，此为基本原则，开户前自行确认；
- 合约交易选择看：**标记价格机制、资金费率、强平规则、保险基金**是否透明（机制见 [05-加密合约篇](../05-加密合约篇/README.md)）；
- 现货与合约分离：新手先用现货；合约账户务必单独隔离资金，别把现货仓位与合约保证金混在一起；
- 交易所的「理财」「借贷」「双币投资」等衍生品都有各自的条款与风险，见 [05-加密合约篇-03](../05-加密合约篇/03-加密衍生品.md)；
- **平台托管 vs 自托管**：资产放在交易所账户里由平台托管（有平台风险），转入自己的钱包则完全自管（有私钥丢失风险）——仓位越重越要分散，大额资产的学习与配置见 [02-现货篇-03](../02-现货篇/03-加密现货专题.md)。

## 五、选择平台的安全检查清单

无论开哪种账户，逐项过一遍这张清单：

| 检查项 | 怎么做 |
|---|---|
| 牌照查询 | 官网/App 公示的牌照号，去对应监管机构官网（证监会/美国 SEC/FINRA/香港 SFC/持牌交易所官网）核对是否真实有效 |
| 资金托管 | 问清客户资金是否独立托管/存管（A 股券商为三方存管，期货为保证金监控中心，加密为平台自管——托管机制不同，风险也不同） |
| 出入金测试 | 先小额出入金各一次，记录到账时间与手续费，验证通道真实可用 |
| 客户评价 | 查监管处罚记录、投诉案例（监管官网、黑猫投诉类平台），看负面信息的性质：是服务差还是涉及资金安全 |
| 跑路风险识别 | 「高收益、拉人头、返佣高到不合理、资质查不到、App 无法提现」五连中的平台直接拉黑；加密平台看：钱包提现是否长期顺畅、平台新闻是否持续正常更新 |
| 费率白纸黑字 | 佣金/利率/返佣比例写入协议或客服留痕，口头承诺不可靠 |
| 客服响应 | 非工作时间（周末/深夜）试一次客服响应，极端行情时能否找到人 |

## 六、开户到第一笔交易：行动清单

以「开一个 A 股账户」为例的完整路径（期货/港美股/加密的环节类似，按各自流程替换）：

| 步骤 | 动作 | 检查点 |
|---|---|---|
| 1. 选券商 | 按第一节框架对比 2-3 家费率与 App | 佣金问清「全佣还是净佣」，留聊天记录 |
| 2. 开户 | 手机 App 视频见证，绑定银行卡 | 确认一人三户名额空闲 |
| 3. 入金 | 银行转账到三方存管账户 | 小额先入，确认到账时间 |
| 4. 试单 | 买 100 股低价股/场内基金 | 核对成交价、手续费是否符合约定 |
| 5. 验证 | 对照第二节清单查费率与 App 功能 | 条件单、level-2 权限是否按承诺开通 |
| 6. 正式使用 | 熟悉后再放正常仓位 | 不要开完户当天就重仓 |

**常见问题速答**：

| 问题 | 速答 |
|---|---|
| 费率谈不下来怎么办 | 换一家谈，万 2 上下已属正常区间；重点是确认含规费 |
| 开户后多久能用 | A 股一般 1-3 个工作日；港美股/加密按各家流程 |
| 一个人能开几个期货账户 | 期货实行一户一码（期货账户全国通用），换公司是「换期货公司签约」而非新开户，以最新规定为准 |
| 需要办银行卡吗 | 多数券商支持常见银行三方存管，银行卡持卡人须与账户一致 |
| 开户送的东西靠谱吗 | 开户礼（行情工具、费率优惠）正常；「送荐股、送带单、送策略群」一律视为营销 |
| 港美股/加密出入金麻烦吗 | 涉及跨境资金流转与外汇管理，务必先确认合规路径再操作，见 [08-入土篇-03](../08-入土篇/03-合规与税务.md) |
| 换期货公司麻烦吗 | 换期货公司签约即可，持仓与资金迁移按期货公司流程办理，通常快于换券商 |
