# 交易知识库 · 从入门到入土

> 面向 Kline Buty 用户的系统化交易知识库：现货、期货、股票、加密货币全覆盖，从零基础概念讲到进阶策略与避坑生存指南。
>
> **免责声明**：本站全部内容仅用于学习与研究，不构成任何投资建议。市场有风险，投资需谨慎。

## 学习路线图

```
入门基础 → 现货 → 股票 → 期货 → 加密合约 → 市场专题 → 技术分析 → 交易系统 → 入土避坑
   ↓（进阶）实战（把知识变成操作）→ 市场生态（看懂对手盘）→ 金融历史（以史为鉴）→ 理财配置（管好赚到的钱）→ 量化实战（自动化）→ 系统对接（工程师向）
```
