# 交易知识库 · 从入门到入土

> 面向 Kline Buty 用户的系统化交易知识库：现货、期货、股票、加密货币全覆盖，从零基础概念讲到进阶策略与避坑生存指南。
>
> **免责声明**：本站全部内容仅用于学习与研究，不构成任何投资建议。市场有风险，投资需谨慎。

---

## 学习路线图

```
入门基础（看懂市场）→ 现货（最简单）→ 股票 → 期货（杠杆风险）→ 加密合约 → 技术分析 → 交易系统 → 入土避坑
```

| 阶段 | 篇章 | 学完后能干什么 |
|---|---|---|
| 1 | [01-入门基础](01-入门基础/README.md) | 看懂术语、看懂行情软件 |
| 2 | [02-现货篇](02-现货篇/README.md) | 理解现货买卖、低风险策略 |
| 3 | [04-股票篇](04-股票篇/README.md) | 理解股市规则与分析方法 |
| 4 | [03-期货篇](03-期货篇/README.md) | 理解杠杆、保证金、交割，**识别风险** |
| 5 | [05-加密合约篇](05-加密合约篇/README.md) | 理解永续合约、资金费率、爆仓机制 |
| 6 | [06-技术分析篇](06-技术分析篇/README.md) | 看懂 K 线形态、指标与量价 |
| 7 | [07-交易系统篇](07-交易系统篇/README.md) | 建立自己的交易系统与风控 |
| 8 | [08-入土篇](08-入土篇/README.md) | 避开骗局与常见亏损陷阱，学会退出 |

> 推荐顺序：**任何刚接触衍生品（期货/合约）的读者，请务必先读完 [03-期货篇](03-期货篇/README.md) 的保证金与强平部分，再开始交易。**
