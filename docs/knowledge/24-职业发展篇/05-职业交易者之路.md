# 05 · 职业交易者之路

> 前面四篇讲的是「把技能卖给机构/做成产品」，本篇讲最后一种生活方式：**不打工、不创业，靠自己的交易系统全职生活**。这也是幸存者偏差最严重、叙事最煽情、现实最残酷的一条路。
>
> 本篇不是「怎么全职交易」，而是「**全职之前你必须在纸面上回答的问题**」：前提清单、财务数学、收入波动、一天的作息、心理与社交、失败率现实与兼职过渡。

## 全职交易的前提检查清单

辞职全职交易之前，逐条勾选（**缺一条都先别辞**）：

| # | 前提 | 说明 |
|---|---|---|
| ① | 可验证的连续 2 年实盘记录 | 完整对账单/资金曲线，不是截图；含完整交易日志与复盘，可被他人审查 |
| ② | 家庭应急金 ≥ 3 年生活支出 | 全职交易收入不确定，应急金按「最坏情况」而非「平均情况」准备 |
| ③ | 夫妻/家庭共识 | 家人支持是比本金更稀缺的资源；家人反对时强行全职，交易压力与家庭关系会互相引爆 |
| ④ | 明确的退出标准 | 「连续亏损 X 个月/**<mark>回撤</mark>**达 X% 就重新找工作」——写在纸上，到点执行，不靠意志力 |
| ⑤ | 现金流不依赖交易收入 | 至少第一年，家庭开支不靠交易收入支撑；交易收入是「奖金」而不是「工资」 |
| ⑥ | 身体与心理基线健康 | 长期失眠、情绪化、上瘾倾向，是全职交易失败的放大器 |

> 这条清单的残酷之处在于：**① 是硬门槛，而多数人连「可验证的实盘记录」都没有就辞职了。** 先在小资金上把 ① 做到，其他几条只是时间问题。

::: danger 全职交易的第一门槛
**① 是硬门槛，而多数人连「可验证的实盘记录」都没有就辞职了。** 没有连续两年完整对账单与复盘记录的「全职交易」，本质上是用勇气替代数学——而市场只认数学。
:::

### 检查清单使用说明

- 每条都要有**可出示的证据**：① 是券商/交易所可查的记录，② 是银行卡余额，③ 是一次正式的家庭会议，④ 是一张写好的纸。
- 「我准备好了」必须能回答三个追问：**「记录在哪？钱够几年？亏了多久回来？」** 回答不上来的，就是没准备好。
- 清单不是一次性的：每半年复查一遍，②③④ 可能随生活变化（买房、生娃、失业）随时失效。

## 「全职交易 vs 全职工作」的财务数学

### 基本公式

```text
每月生活支出 × 12 = 年度生活支出
年度生活支出 ÷ 预期年化收益率 = 所需本金（静态值）
```

### 数字例子（以实际市场情况为准）

| 月支出 | 目标年化 | 静态所需本金 | 加上 20% 回撤缓冲后的建议本金 |
|---|---|---|---|
| 1 万 | 15% | 80 万 | 约 100 万+ |
| 2 万 | 20% | 120 万 | 约 150 万+ |
| 3 万 | 20% | 180 万 | 约 220 万+ |

- **解读**：月支出 2 万、目标年化 20%，静态需要 120 万本金；但 20% 年化本身已是不低的持续回报（长期超过该水平的个人交易者占比很低），且**资金曲线必然回撤**——按「回撤 20% 后仍能覆盖一年生活支出」的标准，建议本金要到 150 万以上。
- 若目标年化降到 10%（更现实的长期水平），月支出 2 万需要约 240 万本金——**这是大多数人全职交易数学上不成立的原因**。

### 还要算上这些隐性成本

- 数据源、行情授权、软件与硬件成本。
- 交易成本（手续费/**<mark>滑点</mark>**）对**<mark>收益率</mark>**的侵蚀，尤其高频小资金。
- 社保/医保自缴、机会成本（放弃的工资与职业发展）——后者的损失最大且最容易被忽略。

### 动态版本：为什么「静态数学」不够

- 静态公式假设「年化稳定」，但真实资金曲线是**「赚钱的月份集中、不赚钱的月份很长」**——按年化 20% 设计生活，遇到一年 0% 就穿帮。
- 动态做法：**用「连续 12 个月最差收入」替代「期望年化」做预算**；同时按「最差 3 年」而不是「最差 1 年」留应急金。
- **<mark>复利</mark>**陷阱：全职交易是「只取不存」——你每年取走生活开支，本金不再复利；**「收益率要覆盖生活开支 + 通胀 + 交易成本」才是真实的门槛**，通常比直觉需要的本金高出一截。
- 数学不过关就辞职，本质是**用勇气替代数学**——而市场只认数学。

## 交易收入的波动性

- 交易收入**按「均值」规划生活是最典型的错误**：月均 1 万的策略，可能是「连续 8 个月不赚钱 + 2 个月赚 6 万」——按均值规划，前 8 个月就撑不住。
- 参考口径：用**最差连续 12 个月**的收入规划开支，而不是均值；全职第一年按「零交易收入」做财务假设是最稳妥的。
- 盈利年份之间的差异同样巨大：牛市年与震荡年可能差一个数量级；「靠天吃饭」的成分高于多数人的自我认知。
- 收入方差大 → 心理压力大 → 动作变形 → 方差更大：**全职交易的下行螺旋往往从财务焦虑开始**。

## 职业交易者的一天

> 模板仅供参考——规律本身比具体时刻更重要：**固定的作息、固定的流程、固定的复盘仪式，是职业交易者对抗情绪化的第一道防线。**

| 时段 | 内容 |
|---|---|
| 开盘前（提前 30-60 分钟） | 阅读隔夜外盘与消息、确认今日计划（交易什么、条件是什么、**<mark>止损</mark>**在哪）、检查持仓与挂单 |
| 交易时段 | 执行计划内的操作；**大部分时间是在等**，不盯不存在的机会；记录每一笔操作的理由 |
| 盘中间隙 | 处理消息、不长时间离开屏幕、避免情绪化刷屏 |
| 收盘后 | 当日复盘：每一笔对错、规则是否执行、情绪状态记录 |
| 晚上 | 研究与学习：新策略验证、回测、阅读（结合 [20-经典书单篇](../20-经典书单篇/)） |
| 每周 | 周复盘：统计**<mark>胜率</mark>**/**<mark>盈亏比</mark>**/回撤，对照周计划；检查系统是否需要调整 |
| 每月 | 月复盘 + 资金曲线归档 + 健康/作息自检 |

> 一天中最重要的一小时是**开盘前写计划**：没有计划的盯盘叫赌博，有计划的执行叫交易。

### 全天候/多市场交易的作息变体

| 交易市场 | 作息特点 | 注意 |
|---|---|---|
| A 股/国内期货 | 4 小时交易时段，作息最接近上班族 | 时间规律，适合起步 |
| 美股/外盘 | 北京时间夜间为主 | 昼夜颠倒伤身体，需固定作息设计 |
| 加密货币（7×24） | 无休市，最容易失控 | 强烈建议「时段化」：只在设定窗口内交易 |
| 多市场组合 | 早中晚三班倒 | 全职交易者里猝死/失眠高发类型，谨慎 |

> 越是「不关门」的市场，越需要自己「关门」——**职业交易者与赌徒的区别不在盈亏，在作息与流程。**

::: danger 职业与赌博的边界
**职业交易者与赌徒的区别不在盈亏，在作息与流程。** 同样的盈亏记录，有人靠纪律赚来的，有人靠运气赢来的——时间拉长以后，只有前者还在桌上。
:::

## 心理与社交

### 孤独感

- 全职交易是单人办公室：没有同事、没有会议、没有社交结构。多数全职交易者低估这一点。
- 对策：保持交易社群/同行小圈子、固定线下运动、把研究/创作（见 [04-内容创作与知识传播.md](04-内容创作与知识传播.md)）变成与外界的连接点。

### 与「赚钱的朋友」比较

- 你赚的月份朋友赚得更多、你亏损的月份朋友在晒收益——**比较是交易者心态崩坏的日常来源**。
- 对策：只和自己的资金曲线比；屏蔽晒单类信息源（行为金融角度，见 [21-行为金融篇](../21-行为金融篇/)）。

### 失败时怎么面对家人

- 全职交易最大的债务不是金钱，是**辜负了支持你的家人**。
- 对策：把「退出标准」提前同步给家人（预案先于失败存在）；亏损月份主动沟通，而不是躲进屏幕；承认「全职交易只是生活的一种选择，不是人生成败」。

## 「全职交易失败率」的现实

- 公开讨论的常识范围（以实际市场情况为准）：**绝大多数辞职全职交易的人会在两年内回到职场**——原因通常不是「亏光」，而是「收入不稳定 + 心理消耗 + 机会成本」三者的叠加。
- 「我认识的 X 全职交易赚了大钱」全部是幸存者偏差：退出者不会发朋友圈，失败者不会开课程。
- 成功者的共同画像（可对照）：有多年业余验证的实盘记录、本金充足（数学上成立）、家庭支持、以及**清晰的退出预案**——全职交易的成功，恰恰是「随时可以不全职」的人。
- 对「全职交易 = 财务自由」叙事的清醒认知：**全职交易是一种职业选择，不是财富终点；多数人的正确选项是先财务自由，再全职交易，而不是反过来。**

### 全职交易者的个人事务清单（容易忽视的坑）

| 事项 | 说明 |
|---|---|
| 社保/医保 | 辞职后如何续缴、在哪个城市缴，直接影响看病报销与未来养老 |
| 税务 | 交易/投资收益的申报口径、个税起征与申报方式，提前搞清楚（以当地规定为准） |
| 居住与户口 | 离职对落户、购房资格等资格类事务的影响 |
| 保险 | 收入结构变化后的重疾/医疗/寿险配置评估 |
| 协议 | 与配偶的收入分配、应急金账户的独立性——事先说清，避免事后争议 |

> 这些事项多数人辞职前从不考虑，却在辞职后集中爆发。**职业交易者的「办公桌」不仅有行情软件，还有一张个人事务清单。**

### 退出与回归：全职交易失败后的第二幕

- **回归职场不是失败，是预案执行**：清单第 ④ 条「退出标准」存在的意义，就是让「回去上班」变成计划内动作，而不是心理崩溃后的逃窜。
- 回归的重新入场：交易经验（尤其完整对账单与复盘）在求职市场上是加分项——量化岗位、券商营业部、风控岗都认「实战经验」（见 [02-交易职业全景.md](02-交易职业全景.md)）。
- 更常见的回归方式：**半回归**——找一份时间弹性工作（咨询、远程、自由职业），保留业余交易与研究，把「全职」降级回「重点副业」。
- 与自己和解：失败率是行业现实，不是个人污点；**全职交易的退出者可以带走的最宝贵资产，是「被市场真实教育过的交易系统」**——它在新岗位上依然值钱。

## 兼职过渡方案

如果你读到这里觉得条件不成熟，这是最理性的路线：

| 方案 | 做法 | 适合 |
|---|---|---|
| 保住工作 + 业余交易 | 白天上班，晚上/周末复盘与研究；用闲钱小**<mark>仓位</mark>**验证 | 绝大多数人 |
| 量化自动化 | 把策略写成半自动/全自动（见 [15-量化实战篇](../15-量化实战篇/)），程序盯盘，人工复核 | 会写代码的人 |
| 半自动 + 工作并行 | 工作日内用条件单/提醒代替盯盘，收盘后统一处理 | 工作无法摸鱼的人 |
| 工作 → 弹性副业 → 过渡 | 先把内容创作/独立开发（见 03/04 篇）跑出收入，再决定是否全职 | 想逐步脱离职场的人 |
| 与机构合作 | 带业绩找自营/资管合作（见 [02-交易职业全景.md](02-交易职业全景.md)），用别人的钱验证自己 | 业绩过硬但本金不足的人 |

> 兼职过渡的隐藏优势：**有工资兜底时，交易决策更冷静、复盘更充分、失败代价可控**——「慢慢来」在交易这条路上几乎总是最优策略。

### 兼职者的时间预算（以每周计）

| 事项 | 小时 | 说明 |
|---|---|---|
| 交易执行与复盘 | 5-8 | 集中在开盘前计划+收盘后复盘，盘中交给条件单/提醒 |
| 研究与策略迭代 | 3-5 | 周末大块时间做回测与研究 |
| 学习（读书/课程） | 2-3 | 见 [20-经典书单篇](../20-经典书单篇/) |
| 记录与数据维护 | 1-2 | 交易日志、资金曲线更新 |

- 每周 12-18 小时是「保工作 + 业余交易」的合理预算；**超过这个量会影响工作，少于这个量说明还没到全职候选的成熟度**（常识参考）。
- 兼职的进阶信号：**「条件单代替盯盘」且「连续 2 年周复盘不断更」**——两者同时满足时，才值得重新打开清单讨论全职。

### 常见 FAQ

| 问题 | 回答 |
|---|---|
| 本金小能不能全职 | 数学上通常不成立（见财务数学）；先用小资金验证能力，再攒本金，顺序不能反 |
| 模拟盘能算实盘记录吗 | 不能。模拟盘缺少真实心理压力与滑点，只能用于练流程 |
| 全职交易要放弃所有消费吗 | 要的是「支出可控」，不是苦行；清单 ② 的 3 年应急金已按当前生活水平算 |
| 亏损后想回本再退，可以吗 | 不行——「回本再退」是退出标准里最常见的借口，写进纸面的标准不因情绪改变 |
| 家人不支持怎么办 | 先别全职。把记录与计划做给家人看，用时间证明，而不是用辞职证明 |

## 风险提示

> ⚠️ **风险提示**：全职交易是全部职业路线中**本金风险、心理风险与家庭风险三重叠加最高的一条**。财务数学上，多数人的本金根本支撑不了「覆盖生活开支 + 承受回撤」的双重要求；现实中，**绝大多数辞职全职交易者在两年内回归职场**（公开常识范围，以实际市场情况为准）。「可验证的 2 年实盘记录 + 3 年应急金 + 家庭共识 + 退出标准」四条缺一不可，缺任何一条就继续上班。请把全职交易当作「财务与心理都准备好的结果」，而不是「改变命运的起点」。
