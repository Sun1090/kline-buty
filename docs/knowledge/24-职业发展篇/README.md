# 24 · 职业发展篇

> 知识库前面 23 篇解决的是「**怎么懂市场、怎么做交易**」；本篇回答最后一个问题：**学完这些之后，怎么把它变成职业（量化求职）、事业（独立开发/内容创作）与生活方式（职业交易者）**。
>
> 本篇不贩卖「财务自由」神话，也不制造「转行焦虑」。它只做一件事：把「交易/金融技能 → 职业与事业」这条路上真实的选项、门槛、代价与概率摆在你面前，供你对照自己（性格、资金、家庭、时间）做选择。
>
> **免责声明**：本站全部内容仅用于学习与研究，不构成任何投资建议。文中所有薪资、门槛、成功率的表述均为公开常识与大致范围，以实际市场情况为准。市场有风险，投资需谨慎。

---

## 本篇定位：从「会做交易」到「靠交易生活」

```
学完前 23 篇 → 你会做交易、懂市场、能写策略、会看财报
     ↓
本篇回答：「这些技能怎么变成收入？」
     ↓
三条路线 · 三种生活方式
```

- **职业**（01、02 篇）：把技能卖给机构——量化私募/自营/券商/外资，拿薪资与奖金。
- **事业**（03、04 篇）：把技能做成产品与内容——独立工具、课程、社群，收入与影响力挂钩。
- **生活方式**（05 篇）：不打工也不创业，靠自己的交易系统生活——自由与风险同样巨大。

三条路线不互斥：很多人先做量化工程师（职业），业余做内容（事业），攒够本金再考虑职业交易（生活方式）；也有人先当职业交易者失败后回流职场。**本篇建议你把它们看成「组合选项」，而不是「单选题」。**

## 职业选择路线图

| 你的画像 | 推荐路线 | 对应文档 | 关键门槛 |
|---|---|---|---|
| 理工科/编程强、数学好 | 量化（开发/研究）→ 机构 | [01](01-量化求职路径.md) | 算法 + 概率/统计 + 可验证的项目 |
| 金融背景、逻辑强、能抗压 | 卖方/买方研究 → 自营 | [02](02-交易职业全景.md) | 学历/实习简历 + 研究功底 |
| 技术+产品感觉 | 独立开发交易工具 | [03](03-独立开发与创业.md) | 产品能力 + 合规红线 + 长期收入不确定 |
| 表达好、爱分享 | 金融内容创作 | [04](04-内容创作与知识传播.md) | 合规边界 + 持续更新 + 差异化 |
| 资金充足、心理稳定 | 全职交易 | [05](05-职业交易者之路.md) | 2 年实盘记录 + 3 年应急金 + 家庭共识 |
| 以上都不满足 | 先保住本职工作，兼职过渡 | [05](05-职业交易者之路.md) | 见「兼职过渡方案」 |

> 判断原则：**技术型 → 量化/开发；交易型 → 自营/职业交易；内容型 → 创作。** 但请先做「风险排序」：职业（亏的是时间）< 事业（亏的是时间+小钱）< 职业交易（亏的是本金+时间+心理）。越靠后的路线，越要求你先把前面的路走通一点。

## 内容约定

- 所有薪资、门槛、成功率均为**公开常识与大致范围**，会随市场周期变化，标注「以实际市场情况为准」。
- 机构名称仅作行业常识举例，不构成任何推荐；文中不涉及任何内部数据与内部招聘信息。
- 合规相关内容以现行监管规定为准（《证券、期货投资咨询管理暂行办法》等），涉及真实展业前请咨询专业人士。
- 每篇均含「⚠️ 风险提示」：职业选择的风险不在「选错」，而在「信息不足 + 孤注一掷」。

---

> **⚠️ 风险提示**
>
> 把交易/金融技能变成职业，最大的风险不是技能本身，而是**用赌徒心态做职业选择**：看到别人全职交易就辞职、看到别人做课程赚钱就跟风、看到量化年薪高就裸辞转行。本系列每篇都会给你「检查清单」和「失败率现实」——请把它们当成和你现有工作/生活对比的标尺，而不是行动的勇气来源。任何职业路径的成功都有幸存者偏差，先想清楚「最坏结果我能否承受」，再谈「最好结果有多诱人」。
