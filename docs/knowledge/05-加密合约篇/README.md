# 05 · 加密合约篇

> 加密货币衍生品是全球最热、也最残酷的赌场：7×24 小时交易、百倍杠杆、资金费率、插针爆仓……
> 本篇讲清永续合约、资金费率与各类加密衍生品（期权、杠杆代币、双币投资、链上合约）的机制与风险。
> **永续合约风险极高，先读 [03-期货篇](../03-期货篇/README.md) 的保证金与强平部分，再读本篇。**

## 学习建议

```
① 01-永续合约（弄懂合约机制、强平价怎么算）
   ↓
② 02-资金费率（弄懂永续价格为什么贴着现货走）
   ↓
③ 03-加密衍生品（进阶品种逐个认识、逐个避雷）
```

- **先读期货篇再读本篇**：永续合约本质就是「不交割的期货」，杠杆、保证金、强平的原理与期货完全一致。没有打好 02-期货篇 的基础，本篇的强平价公式和仓位管理无从谈起。
- 加密合约 7×24 交易、无涨跌停、无熔断，**杠杆可以开到 100 倍以上**，波动速度远超传统期货。
- 每篇都配有「⚠️ 风险提示」框，**请先读风险框再读正文**。

> 如果把 01-入门基础 比作学驾驶，那么加密合约就是直线赛道上的超跑：
> 踩油门很爽，但刹车失灵时你没有任何缓冲带。
