# 16 · 监管与合规篇

## 各篇简介

### 01 · 中国金融监管体系

从国务院金融委到「一行一局一会」的监管全景：央行管货币政策与宏观审慎，金融监管总局管银行保险，证监会管证券期货。本篇拆解证监会管什么（发行、交易、信披、操纵、内幕交易）、穿透式监管怎么穿透、资管新规如何打破刚兑、投资者适当性如何分级，最后用内幕交易与操纵市场的典型处罚案例说明「罚什么、罚多重」。

### 02 · 美国与全球监管

美国联邦与自律双层监管：证券找 SEC、期货找 CFTC、场外零售靠 FINRA。本篇梳理 1933 证券法/1934 交易法、《多德-弗兰克法案》与 Reg BI 利益冲突规则，再依次过香港 SFC 牌照体系、新加坡 MAS、欧盟 MiFID II，最后用「为什么交易所爱选离岸岛」讲透监管套利。

### 03 · 加密监管

加密资产是全球监管变化最快的领域：中国从 2017「94」到 2021 全面清退，美国 SEC 与 CFTC 争夺定性，香港推出 VASP 发牌，日本以《资金结算法》落地牌照，欧盟 MiCA 登场。本篇还覆盖稳定币立法、各国加密税务态度差异，并给出普通人的合规生存指南——**本篇变化极快，务必以最新规定为准**。

### 04 · 牌照与市场准入

金融牌照是金融公司的护城河，也是普通交易者识别「谁是真的」的标尺。本篇给出中国银行/证券/基金/期货/保险/支付/小贷牌照图谱、券商业务资格细分、公募与私募的准入门槛、香港 1-13 号牌详表与美国 FINRA 系列考试常识，最后落到实操：怎么用官网查询核实一家机构到底有没有牌照。

### 05 · 程序化交易与合规

2023-2025 年，中国程序化交易监管从「自律指引」走向「正式规定」。本篇讲清新规要点：谁要报告、报告什么、什么算高频（报单速率、撤单率）、异常交易监控与差异化收费，并结合美股 Reg NMS/maker-taker、欧盟高频监管的经验，给个人量化开发者一份可直接落地的合规清单。

### 06 · 平台免责与投资者适当性

行情软件底部那行「仅供参考，不构成投资建议」不是摆设。本篇拆解信息与建议的合规分界线、免责声明的法律作用与局限、适当性义务下的风险等级匹配逻辑，以及平台常用自保条款——最后给普通用户一份「怎么读小字」的实操清单。

### 07 · 行情数据与工具类应用合规

面向开发者的一篇：行情数据从哪来、能不能展示给别人、展示时怎么免责。本篇覆盖数据版权与 API 授权、实时行情展示的权限边界、工具类应用与投资建议的界限（MiFID II/MiCA 视角），以及开源 K 线类项目可直接照做的合规检查清单。

### 08 · 反洗钱与交易合规

从洗钱三阶段（放置/分层/整合）与 KYC 讲起：金融机构与 VASP 的 AML 义务（CDD/EDD/持续监控/STR）、FATF 旅行规则与链上监控、普通交易者会遇到的实名/限提/冻结等合规动作、可疑交易特征清单、税务申报要点与处罚案例。**核心立场：资料真实、资金清晰、账户不外借、交易留记录——合规是普通交易者的护身符。**

## 本篇学习顺序

```text
① 中国监管体系（先懂本国：谁在管、管什么、罚什么）
   ↓
② 美国与全球监管（再懂国际：出海交易面对的规则）
   ↓
③ 加密监管（特殊战场：规则未定、变化最快）
   ↓
④ 牌照与市场准入（落地工具：怎么识别正规机构）
   ↓
⑤ 程序化交易与合规（量化向：新规下的开发红线）
   ↓
⑥ 平台免责与投资者适当性（用户向：小字里藏着责任边界）
   ↓
⑦ 行情数据与工具类应用合规（开发者向：数据授权与免责清单）
   ↓
⑧ 反洗钱与交易合规（用户向：KYC/AML 义务、可疑特征与税务申报）
```

- 顺序建议：**先读 01 再读 02**，把中美两大监管骨架搭起来，03-05 都是在这两个骨架上的专题展开。
- 想快速自保，优先读 01 的处罚案例与 04 的持牌机构识别清单。
- 做量化的读者必读 05：程序化交易新规直接影响实盘部署方式。
