# 03 · 外汇自动化（EA）与跟单：圣杯还是绞肉机

> 外汇市场最蛊惑人的叙事有两套：一套叫「EA 自动赚钱」，一套叫「跟单复制大佬」。它们的共同点是：**用「你不需要自己交易」来收你的钱**。本篇讲清 MT4/MT5 与 EA 的技术真相、回测骗局的运作机制、跟单社区的坑、**做市商**对赌模式，最后给出平台选择红线清单与给普通人的结论。

---

## 一、MT4 / MT5 是什么

**MetaTrader 4（MT4）与 MetaTrader 5（MT5）** 是俄罗斯 MetaQuotes 公司开发的外汇/差价合约交易终端，也是**全球零售外汇市场最普及的交易软件**：

| 项目 | MT4 | MT5 |
|---|---|---|
| 定位 | 外汇老牌终端（2005 年发布） | 升级版（2010 年发布），支持更多品种与工具 |
| 编程语言 | **MQL4** | **MQL5** |
| 普及度 | 老牌平台标配，外汇市场占有率最高 | 越来越多平台默认提供 |
| 支持品种 | 外汇、部分 CFD | 外汇、股票、期货、期权、加密货币 CFD 等更广 |

**核心组件：**

- **行情终端**：实时报价、K 线图表、技术指标；
- **下单面板**：市价单/限价单/止损止盈单；
- **EA（Expert Advisor，智能交易程序）**：用 MQL 语言编写的**自动交易程序**，挂载在图表上后可以自动执行整套交易逻辑；
- **策略测试器（Strategy Tester）**：用历史数据回测 EA/策略——**注意：这个功能本身很好，但也是骗局的温床**（见第三节）。

MT4/MT5 本身是**中立工具**：它不创造盈利，只负责执行。**「平台给你免费 EA」「社区共享 EA 包赚」的说法，问题从来不在软件，而在写 EA 的人和卖 EA 的人。**

---

## 二、EA 能做什么

EA 本质是「把交易规则写成代码，由程序自动执行」。它能做的：

### 1. 按规则自动执行策略

以最经典的**双均线 EA** 为例，它的逻辑可以写成几行：

| 步骤 | 逻辑 | 代码语言描述 |
|---|---|---|
| 入场条件 | 快线（如 MA5）上穿慢线（如 MA20）→ 开多；下穿 → 开空 | `if (fastMA > slowMA && prevFastMA <= prevSlowMA) Buy()` |
| 出场条件 | 反向信号、止损、止盈任一触发即平仓 | `if (price <= stopLoss) Close()` |
| 循环 | 每根新 K 线重新计算一次 | `OnTick() / OnBar()` |

### 2. 止损止盈管理

- 开仓后自动挂好止损/止盈/移动止损，**避免人脑在亏损时「再等等」**；
- 这是 EA 最实用、也是**唯一推荐普通用户使用**的功能：把 EA 当「纪律执行器」，而不是「交易大脑」。

### 3. 24 小时盯盘

- 外汇 24 小时连续，人类无法全程盯盘，EA 可以；
- 但「能盯盘」不等于「会交易」——**程序只是把你设定好的规则执行得更勤快而已**。

### 一句话理解 EA

> EA 是「你的交易规则的自动化版本」：**你的规则是亏的，EA 就自动化地亏；你的规则是赚的，EA 就自动化地赚。它不会凭空创造优势。**

::: danger 💀 铁律：你的规则是亏的，EA 就自动化地亏
**你的规则是亏的，EA 就自动化地亏；你的规则是赚的，EA 就自动化地赚。** EA 是"你的交易规则的自动化版本"——它不会凭空创造优势。所以世界上不存在"长期稳定月赚 30%"的公开 EA：如果有，持有者会自己闷声赚钱，而不是 999 美元卖给你。任何 EA 广告都要先问三句话：实盘账户能公开实时观摩吗？随机参数的平均表现如何？稳赚为什么还要卖？
:::

## 三、EA 的真相：「圣杯」骗局

### 「月赚 30% 的 EA」为什么全是骗局

网上卖 EA 的话术高度一致：「稳定月收益 20%-30%」「三年回测曲线完美」「带源码/带安装」。真相拆解：

| 骗局手法 | 机制 | 识别方法 |
|---|---|---|
| **回测美化** | 用策略测试器选「收益最高的参数」展示，实际是万里挑一 | 要求看**随机参数分布**与**实盘成绩**，拒绝一切只给回测截图 |
| **未来函数（Future Function）** | EA 用了「未来」数据回算指标（如用当前 K 线收盘后才有的数据在盘中开仓），回测结果失真 | 检查 EA 是否在当前 K 线未收盘时下单；换时间周期回测是否同样有效 |
| **曲线拟合（Overfitting）** | 参数被调到「精确匹配历史行情」，换个时间段立刻失效 | 换 5-10 个不同年份区间回测，若只有特定区间赚钱就是拟合 |
| **蒙特卡洛缺失** | 只展示一条最优路径，掩盖**<mark>滑点</mark>**/断线/重报价的影响 | 看回测是否考虑了**<mark>点差</mark>**、滑点与网络中断 |
| **样本内/外不分** | 用同一段数据「训练」又「验证」 | 要求「样本外测试」（2005-2020 优化，2021-2024 验证） |

### 真实 EA 的期望

- **与手动交易没有本质区别**：EA 只是执行机器，长期期望取决于策略本身——而策略本身的胜率与盈亏比，和手动研究是一样的；
- 真实 EA 的优势只有三个：**执行纪律、24 小时运行、回测可验证**——而不是「胜率」；
- 世界上不存在「长期稳定月赚 30%」的公开策略：**如果有，持有者会自己闷声赚钱，而不是 999 美元卖给你。**

### 一个简单的证伪测试

任何 EA 广告，问三句话：

1. **「你的实盘账户（非模拟盘）能公开实时观摩吗？」**——不能 = 骗局概率 90%+；
2. **「回测收益最高的参数是唯一选择吗？随机参数的平均表现如何？」**——回避 = 拟合；
3. **「如果稳赚，为什么不自己加**<mark>杠杆</mark>**交易而要卖？**——逻辑自洽是骗局的第一原则。

## 四、「跟单社区」的坑

跟单（Copy Trading）：平台把「明星交易员」的信号复制到你的账户，宣传「跟着大神赚钱」。

### 为什么「他赚你亏」

| 因素 | 机制 |
|---|---|
| **资金规模不同** | 他 100 万美元、你 1 千美元，同样的手数比例你的**<mark>爆仓</mark>**距离远小于他——**他能扛的**<mark>回撤</mark>**，你扛不了** |
| **滑点与执行差异** | 他的信号在你账户执行时有延迟，大行情中滑点不同，结果完全不同 |
| **出金时机不同** | 他在盈利高点截图宣传；你在他回撤期入场——**你看到的是过去，买的是未来** |
| **统计偏差（Survivorship Bias）** | 社区只显示「活下来的明星」：一年前同样多的交易员，亏光的被隐藏了；胜率 80% 的短线「明星」多数是在用高风险换小盈利，随时**<mark>归零</mark>** |
| **收益的波动性** | 「年化 200%」往往来自某一个月 60% 的极端行情，其他月份亏——**平均收益与真实体验是两回事** |

### 外汇喊单群的本质

- 「老师带你做单」的群：喊单→你入金到指定平台→老师拿返佣（平台按你亏损额给带单人分成）——**你的亏损就是老师的工资**；
- 「晒盈利截图」：后台软件可一键生成，且盈利图多数是模拟盘/PS；
- **「喊单+黑平台」是流水线组合**：老师与平台是同一伙人，你赚他们改行情，你亏他们分成。

> 判断跟单/带单是否靠谱的唯一标准：**看长期的完整交易记录（含所有亏损单），而不是任何截图与「胜率」**。没有任何带单者愿意展示完整记录，本身就是答案。

::: danger 💀 铁律：判断跟单靠谱的唯一标准是看完整交易记录
**判断跟单/带单是否靠谱的唯一标准：看长期的完整交易记录（含所有亏损单），而不是任何截图与「胜率」。** 没有任何带单者愿意展示完整记录，本身就是答案——因为完整记录里必然包含亏损最惨的一段，而"幸存者偏差"只展示活下来的明星。所以跟单的第一道防线不是"这个交易员胜率多高"，而是"他敢不敢把全部亏损单都展示给你看"。
:::

## 五、做市商 vs ECN/STP：你的对手是谁

### 三种订单处理模式

| 模式 | 全称 | 机制 | 与客户关系 |
|---|---|---|---|
| **做市商（MM）** | Market Maker | 平台自设盘口、自定报价，客户单子**不对外成交**，平台是客户的直接对手方 | **与客户对赌**：客户亏 = 平台赚（尤其散户亏损比例高的平台） |
| **STP** | Straight Through Processing | 客户订单直接转发给上游流动性提供商，平台只赚点差加价 | 不对赌（或对赌比重小） |
| **ECN** | Electronic Communication Network | 订单进流动性池与银行/机构/其他客户直接撮合，**报价为真实市场价+佣金** | 纯通道，客户之间互为对手 |

### 为什么有的平台与客户对赌

- 做市商模式本身**不违法**（在合规监管下，FCA/ASIC 等允许 MM 模式运营），但它制造了结构性利益冲突：**平台希望你亏**；
- 对赌平台的典型操作：数据行情时**人为滑点/断线/「重新报价」**，让「该赚的订单」变成亏损；
- 判别信号：报价是否与主流市场**持续明显偏离**；数据行情时是否频繁「连接中断」；点差是否「戏剧性」扩大。

### 点差与隔夜利息（Swap）的结构

| 成本项 | 结构 | 谁收 |
|---|---|---|
| **点差（Spread）** | **<mark>买入价</mark>**-**<mark>卖出价</mark>**，做市商自定加价 | 平台/做市商 |
| **佣金** | ECN 模式的显性费用（每手固定金额） | 流动性商/通道 |
| **Swap（隔夜利息）** | 持仓过夜时按利率差收/付：做多高息货币**收** Swap，做空高息货币**付** Swap；**周三（部分平台周四）结算三倍利息** | 平台/做市商 |

**关键认知：点差和 Swap 本身是中性的市场结构，但做市商可以同时是「你的对手」和「你的收费员」**——这就是为什么监管牌照与订单模式必须一并核查。

## 六、平台选择的红线清单

| 红线项 | 具体检查 | 达标标准 |
|---|---|---|
| **监管牌照** | 在监管官网**输入牌照号核实**（不是看对方官网截图）：英国 FCA、澳大利亚 ASIC、塞浦路斯 CySEC 为常见主流监管；美国 CFTC/NFA 监管极严但门槛极高 | 牌照号真实、监管状态「Active/Authorised」 |
| **出金测试** | 先小额入金（如 100-500 美元）→ 立即申请出金 → 记录到账时间 | 3-5 个工作日正常到账，无「手续费」「冻结」借口 |
| **杠杆上限** | 主流监管对散户杠杆有硬上限：欧盟 ESMA 主要货币对 1:30、英国 FCA 1:30、美国 1:50 左右；**提供 1:500+ 的多为离岸监管** | 有牌照的离岸平台≠违法，但风险等级高一个量级 |
| **负面新闻查询** | 搜「平台名 + 出金 / 骗局 / 黑平台」等关键词，查外汇投诉网站与监管罚单记录 | 无大面积出金投诉；监管无处罚记录 |
| **出入金方式** | 是否走银行/持牌支付通道；**私人转账、虚拟币充值、对公账户要求现金 = 直接拉黑** | 全部走正规持牌通道 |
| **客户资金隔离** | 平台是否将客户资金存放于隔离账户（Segregated Account）并由监管要求审计 | 在监管官网/条款中可查证 |

## 七、模拟盘与实盘的真相

「EA 在模拟盘/回测里很赚钱，一上实盘就亏」——这是最常见的真实经历。原因不是 EA 变了，而是**模拟与实盘存在系统性差异**：

| 差异项 | 模拟盘/回测 | 实盘 |
|---|---|---|
| 报价 | 理想价格，成交即时 | 滑点、延迟、重报价（数据行情时严重） |
| 点差 | 固定默认值 | 实时浮动，数据行情瞬间扩大数倍 |
| 资金心态 | 亏损无痛感，EA 可连续加仓 | 真实亏损触发人为干预（手动关 EA、改参数） |
| 服务器 | 本地/测试环境 | 网络断线、平台故障、凌晨维护 |
| 成交确认 | 假设全部成交 | 部分成交、拒绝报价、止损滑点 |

**正确的验证流程（先模拟再实盘）：**

```text
① 样本外回测：用 2015-2020 数据优化参数，再用 2021-2024 数据验证
   ↓
② 模拟盘跑 2-3 个月：检验滑点/断线下的表现是否接近回测
   ↓
③ 微型实盘（0.01 手）跑 1-2 个月：确认执行与心态
   ↓
④ 只有①②③都通过，才考虑按 1%-2% 单笔风险小仓位实盘
```

> 绝大多数付费 EA 在第一步（样本外回测）就原形毕露——因为它们的「完美曲线」只在特定历史区间成立。

## 八、给普通人的结论

### 风险与收益的常识性对比

| 方式 | 长期期望 | 风险 |
|---|---|---|
| 手动交易 | 与能力匹配（多数人负期望） | 高 |
| EA 自动交易 | 与策略匹配（「圣杯 EA」≈ 100% 负期望） | 高 |
| 跟单 | 与明星的「幸存者偏差」强相关（多数人亏损） | 高 |
| 不交易（旁观学习） | 0% | 无 |

### 如果你一定要玩

1. **微型账户 + 低杠杆**：0.01 手起步、杠杆锁在 1:30 以内（不要用平台默认的 1:500）；
2. **只做 EUR/USD**：点差最小、性格最规整（见 [01-外汇交易实操.md](01-外汇交易实操.md)）；
3. **EA 只用「纪律执行」功能**（自动挂止损止盈），**绝不买任何付费 EA**；
4. **跟单只做「自己已理解的策略」的轻仓验证**，且本金设置为「亏光无妨」级别；
5. **任何「稳赚」两个字，等于「请立刻离开」**。

::: tip ✅ 结论：任何"稳赚"两个字，等于"请立刻离开"
**任何「稳赚」两个字，等于「请立刻离开」。** 所以给普通人的结论很简单：手动交易、EA 自动交易、跟单的长期期望都是负数（多数人），不交易（旁观学习）的期望才是 0%——别花真金白银去验证"概率思维"，把学费省下来买书和模拟盘更划算。
:::

## 风险提示

> **⚠️ 风险提示**
>
> 外汇行业存在大量**黑平台与对赌模式**：无牌照或套牌平台可以操纵报价、人为滑点、禁止出金；做市商模式与客户直接对赌，「老师带单」「跟单返佣」「付费 EA」的多数链条最终从散户亏损中分成。购买付费 EA、加入喊单群、跟随「月赚 30%」宣传，大概率导致本金快速归零。本文关于监管、杠杆、平台模式的内容为教学口径，**具体以最新监管规定与平台规则为准**。本文不构成投资建议。
