# 02 · 骗局识别

> 在交易的世界里，最大的风险往往不是行情，而是**人**。你以为在跟市场对赌，其实是在跟一群专门研究人性的骗子对赌——他们有剧本、有分工、有耐心，而你只有一颗想赚钱的心。

> ⚠️ 风险提示
>
> 本文为公开骗局的模式总结，仅用于防骗教育。文中案例均为典型套路的客观描述，不代表任何真实事件。**如已遭遇骗局或资金损失，请第一时间报警（110）并向相关平台投诉，保存好转账记录、聊天记录等证据。** 本文不构成法律意见。

## 写在前面：骗局的共同骨架

别看骗局花样百出，剥开外壳，**所有金融骗局共享同一个骨架**：

```
制造焦虑/贪婪 → 建立信任 → 让你尝到甜头 → 诱导加大投入 → 收网收割 → 失联
```

| 环节 | 套路 | 你的感受 |
|---|---|---|
| 钩子 | 「免费课」「稳赚内幕」「老师带单」 | 好奇、心动 |
| 信任 | 晒盈利截图、群托捧场、伪造资质 | 「他好像是专业的」 |
| 甜头 | 前几单真给你赚点小钱、允许小额提现 | 「这平台是真的！」 |
| 加码 | 诱导充值 VIP、加大仓位、拉人头 | 「机不可失」 |
| 收割 | 行情暴跌/平台跑路/限制提现 | 绝望 |
| 失联 | 群解散、拉黑、换马甲重新开张 | 「没想到是假的」 |

**记住：你能看到的「盈利截图」和「群友」，都是骗局的道具，而不是证据。** 下面按八种常见骗局逐一拆解。

## ① 杀猪盘（荐股群）

### 套路全流程拆解

杀猪盘是「荐股/荐币」类骗局的总称，核心是**把散户当猪养肥了再杀**。完整流程如下：

```
第一步：建群
   → 通过短视频、短信、婚恋社交平台等渠道拉人进群，
     群名通常是「XXX 实战交流」「XXX 内部群」
第二步：晒单
   → 群主每天晒「盈利截图」，多个马甲号（托）互动附和，
     营造「跟老师做就赚钱」的氛围
第三步：免费课
   → 开免费直播/语音课讲技术分析，偶尔推荐的小票真的涨，
     让你相信老师有真本事
第四步：诱导充值
   → 时机成熟后，「老师」私下联系你：
     进入高收益项目/合约/新币/内幕票，诱导转入大额资金，
     或下载「专用 App」入金
第五步：收割
   → 大额资金到账后，行情被控盘暴跌、平台提现异常、
     老师失联、群解散
```

### 识别信号清单

- 群内**禁止私下交流、禁止互加好友**，防的就是「托」被拆穿。
- 盈利截图**永远只截赚不截亏**，且图内金额越来越大（制造焦虑）。
- 推荐标的冷门、小市值、易控盘；推荐理由永远是「内部消息」「主力拉升」。
- 要求**下载非官方渠道的 App** 或**转账到个人账户/私人钱包**。
- 反复催促「名额有限」「今晚截止」，制造稀缺与紧迫感。

### 真实损失案例

王女士被拉入「股票交流群」，群主「陈老师」连续两周免费荐股且准确率高。随后陈老师称有大机构合作，推荐下载「X 泰财富」App 参与「一级市场打新」。王女士先后充值 18 万元，App 内账户一度显示盈利 5 万元。申请提现时客服称「需缴纳 30% 保证金解冻」，王女士再充 5 万元后，App 无法打开，群解散，陈老师失联。**她损失的 23 万元中，超过一半是在「提现失败」后追加的——这是骗局最凶残的一刀：用「已经投进去的钱」逼你继续投。**

## ② 资金盘 / 庞氏骗局

### 特征清单

资金盘的本质是**用后进来的钱支付先来者的收益**，没有真实盈利来源，靠击鼓传花维持，最终必然崩盘。核心特征：

| 特征 | 具体表现 |
|---|---|
| 高收益承诺 | 日息 1%~3%、月化 30%+、年化几百%，远超任何合法理财 |
| 发展下线 | 「邀请好友返佣」「团队奖励」，收益和拉人头绑定 |
| 提现困难 | 前期小额定可出，大额提现开始排队、限时、冻结 |
| 包装高大上 | 区块链、元宇宙、AI、海外牌照、明星站台等概念轮番上 |
| 兑付靠新资金 | 崩盘前常有「加仓活动」「锁仓活动」稳住老用户 |
| 生命周期短 | 大多数撑不过 1~2 年，快的几个月崩盘 |

### 识别信号清单

- 收益高到需要专门解释「为什么合法」——**需要解释的，基本不合法。**
- 官方渠道（搜索引擎、监管机构官网）查不到任何备案与牌照。
- 「静态收益 + 动态收益（拉人头）」双轨模式，动态收益占比越高越危险。
- 不允许向监管机构查询、不允许公开财报、资金去向不明。
- 崩盘前征兆：提现审核突然变慢、客服推诿、频繁改规则。

### 真实损失案例

「XX 互助盘」以「区块链慈善理财」名义承诺月收益 20%，前期参与者确实按月拿到收益，于是口碑相传、规模膨胀。随着拉新放缓，平台突然宣布「系统升级」停止提现，一个月后 App 失联。**晚进入的参与者损失全部本金，而早期参与者中不少人也因为「加仓」把赚的钱赔了回去——击鼓传花的每一棒都在赌自己不是最后一棒。**

## ③ 虚拟币传销币 / 空气币

### 特征

空气币 = 没有实际用途、没有技术、没有生态的项目方凭空发行的代币，靠**包装 + 拉人头 + 控盘**维持价格。传销币则在空气币之上叠加了明确的层级返佣。

### 特征清单

- **白皮书套模板**：技术描述玄乎（「跨链」「共识机制」「万亿生态」），但没有任何可验证的产品。
- **币不上市主流交易所**：只在项目方自己的 App/小所交易，价格完全可控。
- **上线即拉人头**：「直推三代奖励」「小区业绩」「静态+动态」，制度设计与传销如出一辙。
- **高价锁仓/定投计划**：诱导你把币锁进项目方钱包，锁定期间无法卖出。
- **社群打鸡血**：天天喊单「翻百倍」，贬低正规交易所和主流币。
- **查不到创始人**：团队匿名，白皮书里的「顾问」查无此人。

### 识别信号清单

- 问三个问题：**这个币解决了什么问题？代码在哪里？（GitHub）哪个主流交易所上了现货？** 三个都答不上来，就是空气币。
- 在主流行情网站（CoinMarketCap 等）查不到收录或收录信息极度异常。
- 宣传语中出现「保本」「稳赚」「翻百倍」——**正规项目从不承诺收益。**
- 要求把币转入项目方钱包「锁仓理财」——**私钥不在你手里，币就不属于你。**

### 真实损失案例

「XX 挖矿币」宣称「手机挖矿，月收益 50%」，用户通过邀请码注册后可「购买矿机」产出该币。早期用户提币卖出确实赚钱，于是拉上亲戚朋友。半年后平台宣布「挖矿难度调整」产量骤降，随后关停提币通道，服务器迁移到境外后失联。**大量受害者投入的是真金白银，拿回的是钱包里一个归零的符号。**

## ④ 假交易所（黑平台）

### 特征

黑平台是**模仿正规交易所外观的诈骗网站/App**，常见于合约、外汇、贵金属等品种，近期也大量伪装成加密交易所。他们不接入真实市场，价格和交易结果都是后台操纵的。

| 特征 | 具体表现 |
|---|---|
| 域名像正牌 | 如 `binancee.com`、`okx.network` 等仿冒域名，或 xxx.biz/xxx.top 等廉价域名 |
| 资质造假 | 页面底部挂「监管牌照」，但证书是 PS 的，监管机构官网查不到 |
| 无法提现 | 提现时以「风控」「税务」「解冻费」为由拒绝，或要求继续充值 |
| 客服失联 | 出问题后客服消失，网站/App 关停换新马甲 |
| 价格异动 | 行情与正规交易所明显脱节，插针、瞬间爆仓频繁 |

### 识别信号清单

- **域名多一个字母/少一个横杠**：仔细核对官方域名，正牌交易所有官方公告渠道确认网址。
- 在应用商店（App Store / 官方应用市场）搜不到，只能通过网页扫码、链接下载安装包——**绕过官方应用商店的 App，是黑平台最高频的特征。**
- 开户不要求实名认证，或只要求手机号即可「入金」。
- 出入金走个人账户、私人钱包、USDT 场外群——**正规交易所从来不会让你把钱转给个人。**
- 提现永远有「新理由」：系统升级、税务审核、需要「激活账户」……

### 真实损失案例

刘先生通过短视频广告进入一个自称「国际知名」的加密交易所，界面与正牌平台几乎一致。他先小额入金 1 万元并成功提现，随后加仓至 30 万元做合约。行情突然「插针」爆仓归零，客服称「行情波动所致」。刘先生上网搜索才发现该平台早被多人曝光为仿冒站，**而他的 30 万元从未进入过任何真实市场——他交易的是一个后台程序。**

## ⑤ 合约带单群骗局

### 特征

以「老师带你做合约」「跟单社区」「信号源」为卖点，本质是**利用你不想自己研究的懒惰来收割你**。多数与黑平台绑定：带单群 + 假交易所 = 完美闭环（假平台后台直接操纵你的盈亏）。

### 特征清单

- 宣称「胜率 90%+」「月翻倍」——**带单的要是真能稳定翻倍，早自己闷声发大财了。**
- 晒单截图全部盈利，且**从不展示止损单**。
- 要求下载指定 App 跟单、或把 API 密钥交给「托管」——**交出 API 密钥等于交出资金控制权。**
- 群内「客服」同步推送「充值优惠」「跟单活动」，诱导加仓。
- 反向信号：行情与你反着来时，老师永远「刚止损完就反转」。

### 识别信号清单

- 凡涉及**胜率承诺**的一律拉黑（合法资管严禁承诺收益）。
- 要求你「跟单必须用指定平台」——平台大概率是黑平台。
- 要求提供账户密码/API 密钥/助记词——**正规带单不可能需要这些，这是资金控制权。**
- 拒绝提供可查的实盘业绩记录（第三方可验证），只给截图。

### 真实损失案例

赵某加入「合约跟单 VIP 群」缴纳 8888 元会员费，老师在指定 App 内「代操盘」。前三天盈利 15%，赵某追加至 20 万元后，两天内账户连续爆仓归零。老师解释「行情黑天鹅」，随后将其移出群聊。**事后查明该 App 从未连接真实市场，所谓「行情」均由后台控制——赵某的 20 万加上 8888 元会员费，全部进入骗子的口袋。**

## ⑥ 钓鱼网站与钱包骗局

### 特征

不骗你「入场」，直接骗你的**身份或资产**：仿冒官网的钓鱼站、假空投、假转账插件、假客服，目标是你的密码、助记词或私钥。

| 骗局类型 | 手法 |
|---|---|
| 仿冒官网 | 搜索竞价排名/广告位买到正牌站前一位，用户输错地址即中招 |
| 假空投 | 「领取空投需连接钱包授权」——授权后资产被批量转走 |
| 假插件 | 伪装成钱包/行情插件，劫持转账地址 |
| 假客服 | 在官方社群冒充客服：「钱包异常，请提供助记词验证」 |
| 假转账提示 | 屏幕弹「交易失败请重试」，诱导多次签名授权 |

### 识别信号清单

- **助记词、私钥、密码是任何情况下都不该给出去的东西**——官方客服永远不会问你要。
- 任何「免费空投」「免费领币」需要先转账、先授权、先付 gas 的，全是钓鱼。
- 交易签名前逐字核对收款地址；陌生 dApp 的授权请求一律拒绝。
- 只通过官方域名 + 浏览器收藏夹访问交易所/钱包网站，**不要用搜索框现搜现点**。
- 任何要求「验证资产」「解冻账户」并索要私钥的「客服」，立即拉黑并举报。

### 真实损失案例

某用户收到「钱包升级提醒」邮件，点击链接进入仿冒官网，页面要求「重新导入助记词以完成迁移」。他输入助记词后，钱包内全部资产（价值约 15 万元）被自动转走。**整个过程骗子没有使用任何技术漏洞——他们只需要你自己交出钥匙。** 私钥在谁手里，资产就属于谁。

## ⑦ 贷款炒股 / 配资骗局

### 特征

利用「用别人的钱翻身」心理：一是诱导你**贷款/套信用卡入市**，把风险无限放大；二是**场外配资**——用虚假的「5 倍、10 倍杠杆」吸引你，平台随时可以以「穿仓」「违规」为由没收你的本金。

### 特征清单

- 宣传「无抵押、秒到账」的**配资/杠杆资金**，利息低得反常。
- 诱导办理消费贷、网贷投入市场，并称「很快回本还贷」。
- 配资平台账户与真实券商账户**互相隔离**，盈亏与下单都是平台后台数字。
- 行情不利时平台「强制平仓」后，还要你补足「穿仓亏损」。
- 股票配资本身在中国境内属违规行为，正规券商**不存在**民间配资渠道。

### 识别信号清单

- **借钱炒股本身就该是红线**：一旦借来的钱进入市场，你的决策会被还款压力扭曲，几乎必然出错。
- 任何「平台账户」与你的实名证券账户不一致的，都是虚假盘。
- 「利息日结」「杠杆随借随还」等话术背后，是随时暴雷的资金链。
- 记住：**配资公司收着你的利息，赌的是你爆仓——他们不怕你亏，怕你不亏。**

### 真实损失案例

李某听信「配资 5 倍杠杆，一个月翻倍」的广告，向平台转入保证金 10 万元，配资 50 万元炒股。行情回调 8% 即触发平仓，平台称「穿仓 4 万元」要求李某限期补足，否则起诉。**李某一头雾水：账户里的钱被平台强制平仓后「亏穿」了，还要倒贴——这是配资平台最常见的收割方式：平仓线极低、手续费极高，本金亏完后倒欠平台的「穿仓款」。**

## ⑧ 「稳赚不赔」话术清单

以下话术，**只要出现其中任何一句，请立刻离开**——正规金融从业人员受法律约束，不会说出这类承诺：

| 话术 | 真相 |
|---|---|
| 「跟着我稳赚不赔」 | 无人能承诺收益，承诺即诈骗 |
| 「内部消息，只有少数人有」 | 你只是消息链的最后一环（接盘者） |
| 「今天不买明天就封盘」 | 稀缺感是收割前的号角 |
| 「平台活动返利 20%」 | 返利的钱来自你未来的本金 |
| 「前几期用户都提现了」 | 那是养肥你之前给的诱饵 |
| 「出金要交保证金/税费/解冻费」 | **提现还要倒贴钱的，都是骗局** |
| 「保证收益，亏了平台赔」 | 平台跑了谁赔你？ |
| 「我们获得了 XX 国金融牌照」 | 牌照请到监管机构官网核对 |
| 「老师带你，只收一单手续费」 | 手续费只是第一层，后面有整套剧本 |
| 「现在不进场，以后高攀不起」 | 市场永远有机会，骗局不会 |

## 防骗 10 条铁律

1. **承诺收益即诈骗**：任何「稳赚」「保本」「月化 X%」的说法，一律视为骗子。
2. **不在非官方渠道下载 App**：绕过应用商店的安装包，九成是黑平台。
3. **不给陌生人转账/充币**：正规机构不会让你给个人账户、私人钱包转账。
4. **绝不交出私钥/助记词/密码/API 密钥**：交出即交出资产控制权。
5. **提现前不交任何钱**：保证金、税费、解冻费——提现还收费的只有骗子。
6. **不借钱、不加杠杆炒「机会」**：骗局最喜欢收割「最后一笔急钱」。
7. **盈利截图不是证据**：任何截图都可以伪造，查证靠官方渠道。
8. **保持 24 小时冷静期**：凡被催「马上决定」，默认按骗局处理。
9. **只信可验证的东西**：牌照查官网、域名对官网、产品看代码、业绩看第三方。
10. **被骗不丢人，沉默才可怕**：发现被骗立即 110 报警、冻结支付渠道、保存证据，越早越有机会挽回。
