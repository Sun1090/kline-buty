# 08 · 入土篇

> 这是知识库的最后一站，也是最不浪漫的一站：不讲怎么赚钱，讲怎么**不亏钱、不上当、不进去**。
>
> 前面七篇教你认识市场、看懂图表、建立系统——但现实是，绝大多数散户的亏损不是因为「技术不够」，而是因为**踩坑**：亏在没计划、亏在杠杆、亏在骗局、亏在合规红线。本篇就是你的「生存指南」。

## 各篇简介

### 01 · 常见亏损原因

为什么「懂技术」的人还是亏？因为亏损通常不是技术问题，而是**行为问题**。本篇列出散户亏损的九大原因——无计划裸奔交易、过度杠杆、扛单不设止损、频繁交易手续费磨损、追涨杀跌 FOMO、抄底接飞刀、加仓摊平、过度自信重仓、听信内幕荐股——每个都配「真实案例场景 + 心理根源 + 解药」，最后是一份可以逐条自检的「交易者自我诊断清单」。**建议在每次亏损后回来逐条对号入座。**

### 02 · 骗局识别

交易世界里 90% 的「老师」是想吃你的人。本篇拆解八大骗局：杀猪盘荐股群的完整套路流程、资金盘/庞氏骗局的三大特征、传销币与空气币的包装手法、黑平台假交易所的识别清单、合约带单群、钓鱼网站与钱包骗局、贷款炒股与配资陷阱，以及「稳赚不赔」式话术大全。每个骗局都有「识别信号清单 + 真实损失案例」，最后给出**「防骗 10 条铁律」**。**记住：骗局识别不是技巧，是生存技能。**

### 03 · 合规与税务

钱赚到了，还要守得住、出得来、不进局子。本篇梳理合规与税务常识：中国对境内虚拟货币交易的监管脉络（94 事件至今）、期货与股票交易的合规渠道、出入金的合规风险（场外交易、账户冻结）、反洗钱常识，以及中国/美国/日本/德国等主要市场的税务概况与 A 股、港股、美股的税种对比。**法律与税务政策会变化，文末给出「合规生存建议」清单，请以最新法规和专业人士意见为准。**

## 本篇学习顺序

```
① 常见亏损原因（先管住自己，九大坑挨个排雷）
   ↓
② 骗局识别（再管住钱包，识破外部陷阱）
   ↓
③ 合规与税务（最后守住底线，钱要合法进出）
```

- 顺序建议：**先读 01 再看 02**——大多数骗局都是利用 01 里提到的心理弱点设计的，读完 01 再拆骗局会更容易理解「为什么有人会上当」。
- 03 涉及具体政策与税率的数字请务必**核对最新法规**，本篇只提供框架与常识。
- 学完本篇，知识库的主线（入门 → 现货 → 股票 → 期货 → 合约 → 技术 → 系统 → 生存）即告闭环。祝你**永远用不上这里的教训，但永远记得这里的内容。**
