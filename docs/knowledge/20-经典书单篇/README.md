# 20 · 经典书单篇（读书指南）

> 知识库前面 19 篇已经把「方法」讲透了：怎么看 K 线、怎么定交易系统、怎么做风控、怎么读财报。但方法背后是体系，体系不是看文档能看出来的——它需要一本一本好书垫底。
>
> 本篇不推荐「必读 100 本」，只推荐**值得反复读**的书，并告诉你**为什么读、怎么读**。按「入门 → 技术 → 价值 → 量化心理 → 精读方法」五层书单推进，读完一层再进下一层。
>
> **免责声明**：本篇全部内容仅用于学习与研究，不构成任何投资建议。书单中的观点只代表作者立场，请带着批判眼光阅读。市场有风险，投资需谨慎。

---

## 本篇定位：知识库讲了方法，读书帮你建立体系

```
知识库 19 篇文档         →   一本书
  「这是什么、怎么用」         「为什么、背后是什么、什么情况下不成立」
```

- **知识库解决「器」**：术语、规则、公式、清单，查得到、用得上。
- **书解决「道」**：把分散的知识缝合成世界观——为什么止损这么难执行、为什么人多的地方不去、为什么市场长期是称重机。
- **两者缺一不可**：只看书不实操，书会变成「道理都懂」；只刷文档不读书，知识是散的，行情一变就崩。

## 五层书单推进路线

```
第一层 · 入门（01 篇）→ 建立金钱观：先学会「不亏」和「慢慢变富」
    ↓
第二层 · 技术（02 篇）→ 建立看图能力：看懂图表，知道信号从哪来
    ↓
第三层 · 价值（03 篇）→ 建立基本面框架：知道什么值得长期持有
    ↓
第四层 · 量化心理（05 篇）→ 建立心理防线：了解人性弱点与不确定性
    ↓
第五层 · 精读方法（06 篇）→ 学会读书本身：把前四层的书读透、变成自己的体系
```

## 内容约定

- 书目信息（书名、作者、核心观点）均为公开出版物真实信息；书籍评价尽量客观，不吹不黑。
- 每篇均包含「⚠️ 风险提示」——书单本身没有风险，**风险在于「读了书就以为自己会了」**。
- 本系列推荐的只是书单的起点，不是终点。读完一篇后，可以顺着作者与参考文献继续拓展。
- 简体中文版、繁体版、英文原版的书名与翻译版本有差异，不影响阅读，以你能买到/读到的版本为准。

## 风险提示

> ⚠️ **风险提示**：读书不会直接让你赚钱，甚至会让你更谨慎地对待赚钱这件事——这是好事。**真正的风险是「读而不做」：书读了不少，下单时依然凭感觉，那书等于白读；以及「读了就上头」，把某一本书的结论当成放之四海皆准的圣杯。** 任何书都只是某个人在某个时代、某个市场里总结的经验，中国市场、加密货币市场、杠杆交易都可能让书里的结论失效。请把书当成「工具箱」，而不是「说明书」。
