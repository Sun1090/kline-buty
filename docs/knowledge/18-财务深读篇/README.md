## 各篇简介

### 01 · 三张报表精读

读懂财报的第一课：三张报表各管什么、彼此怎么勾稽、哪些科目是重点、哪些科目是雷区。核心心法只有一句——**「利润是观点，现金是事实」**。篇末用一家虚构公司的简化三表，带你从头到尾走一遍完整分析流程。

### 02 · 财务指标实战

把指标从「认识」变成「会用」：ROE 杜邦分解告诉你一家公司到底靠产品、靠效率还是靠杠杆赚钱；各类周转率与偿债指标怎么组合看才不误判；最后点破「单看 ROE 就下结论」这类最常见的指标误用。

### 03 · 财务造假识别

财报能骗人，但造假必有痕迹：虚增收入、虚减成本、藏负债、资产灌水四大手法各有其「阿喀琉斯之踵」。本片复盘已定罪的瑞幸事件，给出一套可操作的识别工具箱，并教你查证监会、交易所问询函这些免费的「分析师」。

### 04 · 现金流分析

现金流是财报里最难造假的数字。利润 1 亿、经营现金流 −5 亿的公司意味着什么？奶牛型/成长型/失血型公司怎么区分？FCF 与 DCF 怎么用、有什么局限？本篇全部讲清。

### 05 · 财报分析实战

把前面四篇拼成一套流水线：10 步读报法、可复制的分析模板、分行业看报重点、财报季的实战节奏，以及散户读报最常见的五个误区。**读完这篇，拿到任何一份财报都能独立完成一次完整的分析。**

## 本篇学习顺序

```
① 三张报表精读（打地基：看懂报表本身）
   ↓
② 财务指标实战（练工具：把数字变成判断）
   ↓
③ 财务造假识别（装雷达：先学会排除）
   ↓
④ 现金流分析（抓本质：现金为王）
   ↓
⑤ 财报分析实战（上流水线：完整读一份财报）
```

- ① 与 ② 是基础，③ ④ 是进阶，⑤ 是综合练习，建议按序阅读。
- 学完本篇，可与 [04-股票篇](../04-股票篇/) 的估值方法配合使用：先排雷、再估值、后决策。
