# 01 · 外汇市场：全球最大的金融战场

> 外汇（FX / Forex）市场是全球**规模最大、流动性最强、交易时间最长**的金融市场。它没有中央交易所、没有涨跌停、周一至周五 24 小时不停转——你买美股要等晚上开盘，而外汇永远有对手盘。
>
> 但规模大不等于容易赚钱：这个市场是**机构的主场**，散户以「高杠杆」入场，多数最终被时间、点差与黑平台吃掉。本篇讲清它的规则与坑。

## 一、这个市场有多大

| 数据项 | 规模 | 备注 |
|---|---|---|
| 日均成交额 | **约 7.5 万亿美元**（2022 年 BIS 三年一度调查） | 远超股票与债券之和 |
| 交易方式 | **场外交易（OTC）** | 无中央交易所，银行间直接撮合 |
| 交易中心 | 伦敦（约 40% 份额）> 纽约 > 新加坡 > 香港 > 东京 | 伦敦是绝对霸主 |
| 交易主体 | 银行占主导（约 45%），其余为对冲基金、央行、企业、散户 | 零售散户占比不足 10% |

> 数字口径：BIS（国际清算银行）每三年发布全球外汇市场调查，上表为最近一次公开数据（2022 年）。**具体规模以最新调查为准。**

为什么是 OTC？因为外汇交易是「银行对银行」的场外协议，没有一张统一的交易所账单。全球数以千计的做市银行同时报价，你的经纪商把订单抛给流动性提供商（通常是银行），而不是某个交易所的撮合引擎。这也是黑平台能伪装「正规经纪商」的原因之一——**没有官方交易所意味着监管只能靠牌照，而牌照可以造假**（见 [11-外汇黑平台警示](#十一外汇黑平台警示)）。

## 二、货币对：谁跟谁兑

外汇交易永远是**成对**的：买一个货币的同时卖出另一个货币。写法是 `基础货币/计价货币`（如 EUR/USD），读作「欧元兑美元」。

### 主要货币对（直盘）

| 货币对 | 中文 | 特点 |
|---|---|---|
| **EUR/USD** | 欧元/美元 | 全球成交占比最大的一对（约 22%），流动性最好、点差最窄 |
| USD/JPY | 美元/日元 | 「避险+利差」双属性，日央行政策影响大 |
| GBP/USD | 英镑/美元 | 波动大、点差略宽，俗称「镑美」 |
| USD/CHF | 美元/瑞郎 | 瑞士法郎是传统避险货币，与金价常同向 |
| USD/CAD | 美元/加元 | 加元与油价高度相关，被称为「石油货币」 |
| AUD/USD | 澳元/美元 | 与铁矿石、中国需求相关，利率敏感 |
| NZD/USD | 纽元/美元 | 与乳制品、澳元联动 |

### 商品货币

**AUD（澳元）/ CAD（加元）/ NZD（纽元）** 被称为「商品货币」——它们的经济高度依赖资源出口，汇率因此与大宗商品价格强相关：

- AUD 看铁矿石、煤炭与澳洲出口
- CAD 看原油（加拿大是产油大国）
- NZD 看乳制品与农产品

> 经验法则：**油价大涨时 CAD 倾向走强，铁矿石强势时 AUD 受益**。这类「商品属性」是可以被散户观察到的联动逻辑。

### 交叉盘

不带美元的货币对叫**交叉盘**，如 EUR/GBP、EUR/JPY、GBP/JPY。交叉盘交易者通常是在「表达两国相对强弱」，而非对美元的方向。GBP/JPY 波动极剧烈，是散户爆仓重灾区。

## 三、美元指数 DXY：全球资产的标尺

**美元指数（US Dollar Index，代码 DXY）** 衡量美元对一篮子主要货币的综合强弱，由 ICE（洲际交易所）编制发布。它本质上是「美元买了多少东西」的定价器——全球大宗商品以美元计价，因此 **DXY 上涨往往压制黄金/原油/非美资产**。

### 篮子构成（权重以最新指数编制规则为准）

| 货币 | 权重（历史参考） |
|---|---|
| 欧元 EUR | 约 57.6% |
| 日元 JPY | 约 13.6% |
| 英镑 GBP | 约 11.9% |
| 加元 CAD | 约 9.1% |
| 瑞典克朗 SEK | 约 4.2% |
| 瑞士法郎 CHF | 约 3.6% |

> 篮子权重于 1973 年布雷顿森林体系瓦解后确立，更新频率低。**具体权重以 ICE 最新编制规则为准。** 注意：人民币尚未纳入 DXY 篮子（有 CNH 指数等其他篮子）。

怎么看它：DXY 涨 = 美元变强，通常对应非美货币（EUR/USD、USD/JPY 反向）走弱；反之亦然。它是跨境投资者、宏观交易者的「方向盘」。

## 四、报价机制：读懂 1.0850 这个数字

以 EUR/USD = 1.0850/1.0852 为例：

- **基准货币（Base）**：EUR——等号左边的「商品」
- **计价货币（Quote）**：USD——标价用的「钱」
- **买入价（Bid）1.0850**：经纪商愿意买入欧元的价格（即你**卖出**的价格）
- **卖出价（Ask）1.0852**：经纪商愿意卖出欧元的价格（即你**买入**的价格）
- **买卖价差（Spread）0.0002**：两者之差，是经纪商的收入之一

**价格含义**：1 EUR 值 1.0850 USD。若你判断欧元升值，就「买入 EUR/USD」；欧元涨到 1.09，你的仓位就赚了。**每一笔交易你都是先以 Ask 买入、以 Bid 卖出，价差是你第一笔成本。**

## 五、Pip 点值计算（含数字例子）

**Pip（Point in Percentage）** 是汇率的最小变动单位：

- 绝大多数货币对报价 5 位小数，**第 4 位小数 = 1 pip**（如 1.0850 → 1.0851 涨了 1 pip）
- USD/JPY 报价 3 位小数，**第 2 位小数 = 1 pip**（如 150.25 → 150.26 涨了 1 pip）

### 例子 1：EUR/USD 标准手

- 1 标准手 = 100,000 基础货币（EUR）
- 汇率变动 1 pip = 0.0001
- 每 pip 价值 = 100,000 × 0.0001 = **10 美元**

### 例子 2：USD/JPY 标准手

- 1 标准手 = 100,000 USD
- 汇率变动 1 pip = 0.01
- 若 USD/JPY = 150.00，每 pip 价值 = 100,000 × 0.01 ÷ 150.00 ≈ **6.67 美元**（以计价货币 JPY 换算回 USD）

### 例子 3：迷你手与爆仓距离

- 迷你手（0.1 手）每 pip = 1 美元；微手（0.01 手）每 pip = 0.1 美元
- 账户 1,000 美元、100:1 杠杆、1 标准手 EUR/USD 保证金 1,000 美元
- 每 pip 盈亏 10 美元 → **反向 100 pips 即爆仓**（还没算点差）。而 EUR/USD 一天波动 100+ pips 稀松平常。

> **这就是外汇散户的数学真相**：高杠杆 + 大波动 + 点差 = 大多数仓位活不过一周。波动率与点差以最新行情为准，上述为教学口径。

## 六、交易时间：四城接力

外汇市场周一（悉尼开盘）至周五（纽约收盘）**24 小时连轴转**，四个主要交易中心依次接力：

| 交易时段 | 时间（北京时间） | 特点 |
|---|---|---|
| 悉尼 | 约 06:00–14:00 | 清淡，点差大 |
| 东京 | 约 08:00–15:30 | 日元活跃，整体仍清淡 |
| 伦敦 | 约 15:30–次日 00:30 | **全球最大中心，波动拉开** |
| 纽约 | 约 20:00–次日 05:00 | 与伦敦重叠时段（约 20:00–00:30）是**全天波动最大窗口** |

> 上表为夏令时（3–10 月）口径；冬令时整体延后 1 小时。**各平台休市/开盘时间以平台公告为准。**

为什么重要：**大部分波动发生在伦敦-纽约重叠时段**，而亚洲散户最容易在「清淡时段」重仓——价差大、突破少，纯给点差打工。

## 七、杠杆：外汇的特色与陷阱

| 市场 | 常见杠杆 | 说明 |
|---|---|---|
| 国内 A 股 | 无（融资融券约 1 倍，即 2 倍上限，门槛 50 万） | 监管严格限制 |
| 国内期货 | 约 6–20 倍（保证金制） | 交易所规定 |
| 海外外汇零售 | **常见 1:100 – 1:500**，部分平台更高 | 经纪商自定，监管不同上限不同 |

- 零售外汇的杠杆远高于国内任何正规市场——**欧美监管普遍限制在 1:30（散户）左右**，而离岸监管平台动辄 1:500、甚至 1:1000。
- 为什么平台敢给 1:500？因为**杠杆越高，散户爆仓越快，平台赚得越多**（点差 + 隔夜利息 + 亏损余额）。这不是福利，是诱饵。
- 对比国内：同样 1 万美元本金，国内期货最多撬动约 20 万名义价值，而 1:500 平台可以撬动 500 万——**一个 0.2% 的反向波动就爆仓。**

> 杠杆比例以最新监管规定与平台规则为准。核心认知：**杠杆放大的是「速度」而非「胜率」**，详见 [08-入土篇/01-常见亏损原因.md](../08-入土篇/01-常见亏损原因.md) 的「过度杠杆」一节。

## 八、参与者：这个市场谁在玩

| 参与者 | 角色 | 交易目的 |
|---|---|---|
| **央行** | 最终大佬 | 汇率政策、外汇储备管理，干预市场 |
| **商业银行** | 做市商 | 为客户提供报价、赚取点差、管理自身敞口 |
| **对冲基金/资管** | 投机主力 | 宏观押注、套利、波动率交易 |
| **跨国企业** | 套保用户 | 收付货款、对冲汇率风险 |
| **散户（你）** | 弱势群体 | 投机——且大多在高杠杆下亏钱 |

关键认知：**散户在信息、速度、成本、资金规模上全面劣势**。银行能看到客户订单流，对冲基金雇着博士团队——散户唯一的优势是「灵活」，而杠杆把这份灵活也变成了劣势。**这个市场里，9 成散户最终亏损不是段子，是数据（各平台公开数据口径不一，此处仅为常识性结论）。**

## 九、核心驱动：什么在推动汇率

汇率短期是「资金的投票」，长期是「经济的反映」。五大驱动：

### 1. 利率差（最重要）

**货币流向高利率的地方**。美元利率高于欧元 → 资金买美元 → 美元走强。各国央行的加息/降息预期是外汇最大的单边力量。这就是著名的 **Carry Trade（套息交易）**：借低息货币（如日元）买高息货币（如美元）。

### 2. 经济数据

| 数据 | 影响 |
|---|---|
| 非农就业（NFP） | 每月第一个周五，最大行情制造机 |
| CPI 通胀 | 直接影响央行利率预期 |
| GDP | 经济基本盘 |
| PMI/零售/失业率 | 次要但频繁 |

### 3. 央行政策

美联储（Fed）、欧央行（ECB）、日央行（BOJ）、英央行（BOE）的**利率决议与官员讲话**是硬催化。市场交易的是「预期差」：数据已反映的利好不算利好，**超预期的才是行情**。

### 4. 风险情绪

「避险」与「risk-on」切换时，资金涌向美元、日元、瑞郎、黄金（避险资产），撤离澳元、纽元、新兴市场货币（风险资产）。地缘冲突升级（如战争、制裁）时美元和黄金同涨是常见画面。

### 5. 地缘与政治

贸易战、制裁、大选、能源危机都能改变货币的长期估值锚。例：俄罗斯被制裁期间卢布剧烈贬值；英国脱欧期间英镑长期承压。

## 十、美元强弱：黄金/原油/加密的联动

美元是全球资产定价的「锚货币」，其强弱直接传导到其他资产：

| 资产 | 联动逻辑 | 常见现象 |
|---|---|---|
| **黄金** | 以美元计价 + 黄金是美元的「替代品」 | **美元强 → 金价承压；美元弱 → 金价走强**（负相关，非绝对） |
| **原油** | 以美元计价，美元升值抬升他国购买成本 | 美元走强 → 油价倾向承压（同时受供需主导） |
| **新兴市场股债** | 美元强 → 美元外债压力大、资本回流美国 | 美元走强常压制新兴市场资产 |
| **加密货币（BTC 等）** | 部分资金视其为「数字黄金」，同时高波动 | 美元流动性宽松（美联储降息）时加密常受益；紧张时承压 |

> 这些都是**统计相关而非因果铁律**——2020-2021 年美元与 BTC 甚至同涨过。实战中应把美元指数当作「背景音乐」而非「唯一信号」。

## 十一、外汇黑平台警示

外汇 OTC 特性 + 高杠杆 + 离岸监管 = **骗局高发区**。典型套路：

- 号称受「美国 NFA / 英国 FCA」监管，实际只是**套牌或已注销的牌照**
- 入金用私人账户、虚拟币充值，出金设置天价手续费或直接消失
- 后台可以**操纵报价**（滑点、断线、改点差），让你「差一点就盈利」
- 「老师」带单群 + 高额返佣的联合收割

**识别与防范请务必阅读：[08-入土篇/02-骗局识别.md](../08-入土篇/02-骗局识别.md)（特别是「④ 假交易所（黑平台）」一节）。**

三条底线：

1. 只使用**受本国/主流司法辖区监管**的持牌经纪商，并到监管官网**核实牌照号**（不是看对方截图）
2. 出金测试：先小额入金 → 立即小额出金 → 成功后再考虑加钱
3. **任何「保证收益/稳赚不赔」的外汇推广，一律按骗局处理**

## 风险提示

> ⚠️ 风险提示
>
> 外汇保证金交易具有**极高杠杆风险**，可能使本金迅速归零甚至欠债（负余额）。全球范围内，**零售外汇投资者中稳定盈利者占比极低**；未经监管的平台欺诈风险远高于正规市场。本页全部数值为教学口径（以 2022 年 BIS 数据与行业常识为参考），**具体以最新行情、最新监管规定与平台规则为准**。本文不构成投资建议。
