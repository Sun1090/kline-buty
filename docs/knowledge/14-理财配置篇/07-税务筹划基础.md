# 07 · 税务筹划基础

> 投资赚到的钱，有一部分天然属于税收——但「该交多少、什么时候交、怎么交」是规则问题，不是道德问题。本篇做的是**知识科普**：把中国个人投资的税务框架讲清楚，顺便划清「合法筹划」与「偷漏税」的边界。所有税目、税率、优惠，均以现行税法及最新法规为准。

---

## 一、中国个税基本框架

### 1.1 三类所得的大致划分（常识口径）

| 所得类别 | 主要内容 | 计税方式（常识） |
|---|---|---|
| 综合所得 | 工资薪金、劳务报酬、稿酬、特许权使用费 | 按年合并，适用 3%-45% 超额累进税率 |
| 经营所得 | 个体工商户、个人独资/合伙企业的利润 | 适用 5%-35% 超额累进税率 |
| 分类所得（利息、股息、财产转让等） | 股息红利、利息、财产租赁、财产转让、偶然所得 | 一般按次或按月，20% 比例税率（有大量优惠政策，见第二部分） |

**关键常识：中国目前没有面向个人的「资本利得税」税种**——股票的买卖价差大多通过单项优惠政策处理（详见第二部分），这与美国等国将资本利得单列一个税种的设计不同。

### 1.2 谁是纳税人

- **居民个人**（有住所，或在一个纳税年度内在中国境内居住累计满 183 天，以现行税法为准）：就**全球所得**纳税。
- **非居民个人**：仅就**境内所得**纳税。
- 居民身份的判定直接影响海外资产收入的申报义务——这也是上一篇 CRS 机制发挥作用的基础。

### 1.3 综合所得的「减税工具箱」（工资族最常接触的部分）

| 工具 | 说明（常识，以最新法规为准） |
|---|---|
| 基本减除费用 | 每月 5000 元（每年 6 万元）的免征额（历史口径） |
| 专项扣除 | 五险一金个人缴纳部分，税前扣除 |
| 专项附加扣除 | 子女教育、继续教育、大病医疗、住房贷款利息/住房租金、赡养老人、3 岁以下婴幼儿照护等（项目与标准按现行政策） |
| 全年一次性奖金优惠 | 年终奖单独计税的过渡政策（政策口径，多次延续，以最新公告为准） |

> **这组工具的意义**：对上班族而言，「合法筹划」的第一课不是折腾投资品，而是**确认自己的专项附加扣除都填对了**——这是零风险、零成本的税前减项，且只靠个税 App 就能完成。

## 二、投资收益怎么征税（知识科普）

### 2.1 A 股：三个最常见的优惠/规则

| 项目 | 规则（历史政策口径，以最新法规为准） |
|---|---|
| 股息红利差异化税率 | 持股 ≤ 1 个月：按 20% 计税；1 个月至 1 年：10%；**持股超过 1 年：暂免征收**（历史政策口径，以财政部/税务总局现行公告为准） |
| 股票转让所得 | **个人买卖 A 股股票差价收入，暂免征收个税**（历史政策口径）；同样适用于 H 股部分情形、新三板等按现行公告执行 |
| 印花税 | 目前**卖出方单边缴纳**，税率 **0.05%**（2023 年 8 月 28 日起减半征收后的口径，以最新法规为准） |

**三个规则联合看**：A 股的个人投资者实际上是「轻税负」群体——持有 1 年以上股息免税 + 价差不征税，是制度设计的结果，也是「长期持股」在税务上的额外奖励。

### 2.2 基金

| 场景 | 规则（常识/政策口径，以最新法规为准） |
|---|---|
| 公募基金分红 | 个人取得的基金分红**暂不征收个税**（历史政策口径） |
| 基金赎回/买卖差价 | 个人买卖公募基金的差价收益**暂不征税**（历史政策口径） |
| 场内 ETF/LOF | 与 A 股股票同口径：分红按持股期差异化税率（多数 ETF 分红极低），买卖差价不征税（政策口径） |
| 私募基金/专户 | 收益分配方式与税负因产品结构而异，需以产品合同与税务规定为准 |

### 2.3 债券

| 券种 | 利息税负（常识，以最新法规为准） |
|---|---|
| 国债、地方政府债券 | 利息收入**免征个税**（政策口径） |
| 企业债、公司债、可转债 | 利息按 **20%** 缴纳个税，通常由发行方/托管机构**代扣代缴** |
| 债券买卖价差 | 现行框架下个人买卖债券差价暂不征收个税（政策口径，以最新法规为准） |

### 2.4 期货 / 加密：灰色地带

| 资产 | 现状（客观描述，以最新法规为准） |
|---|---|
| 境内自然人期货交易 | 商品期货、股指期货的个人交易收益，**现行税法未明确专门税目**，实践口径存在不确定性——「暂未明确征税」不等于「免税」 |
| 加密资产 | 中国大陆对虚拟货币相关业务活动已有明确法律定性（被认定为非法金融活动，历史政策口径）；境外平台的交易收益在国内的税务处理同样**没有明确规则**，且资金进出境本身另有合规问题 |

> **灰色地带的含义**：规则未明确 ≠ 可以忽略。税收上的「没规定」随时可能被新规填补，个人应在合规前提下自行评估，必要时咨询专业人士。

### 2.5 其他常见品种速览

| 品种 | 规则（常识，以最新法规为准） |
|---|---|
| 可转债 | 打新中签与买卖差价暂不征个税（政策口径）；转股后按股票规则计税；利息部分按债券规则 |
| 公募 REITs（境内） | 分红分配、买卖差价按现行基金相关税收口径执行（政策口径，以最新公告为准） |
| 新股中签（A 股） | 中签卖出差价并入股票转让差价口径，暂免个税（政策口径） |
| 保险分红/年金领取 | 一般不属于个税应税范围，但领取的商业养老金按领取时规则计税（以最新法规为准） |
| 港股（港股通） | 差价所得暂免个税（政策口径）；股息按 20% 或差异化口径代扣（港股通股息有特殊扣缴安排，以最新规定为准） |

## 三、房产税与「房地产税试点」动向（概念性常识）

- **房产税（现行）**：依据《房产税暂行条例》，主要针对**经营性房产**（出租、企业自用等），个人住宅一般免征（常识口径）。
- **房地产税（改革试点）**：2011 年重庆、上海试点对部分个人住房征收房产税；2021 年传出扩大试点范围的改革信号后，**试点扩围暂缓**（以最新政策为准）。两者名字相近、税种不同，别混为一谈。
- **对普通人的含义**：个人持有住宅目前几乎不产生持有税（房贷利息也无法抵税，国内与美国的房贷利息抵税设计不同）；将来是否、何时、以什么方式对存量住宅征税，取决于立法进程，**目前没有确定答案**。
- 出租住宅：租金收入属于财产租赁所得，按 10%（个人出租住房的优惠税率，政策口径）或 20% 计税，以最新法规为准。

### 3.1 房产「交易环节」的税（持有税之外的另一半）

| 税种 | 谁交 | 规则（常识，以最新法规为准） |
|---|---|---|
| 契税 | 买方 | 按成交价一定比例缴纳（个人住房 1%-3% 区间，具体按地区与套数政策） |
| 增值税及附加 | 卖方（实际多转嫁） | 个人出售住房，满 2 年/满 5 年等情形下存在减免（政策口径，随政策调整频繁） |
| 个人所得税（转让所得） | 卖方 | 按差额 20% 或核定征收（1% 等常见核定口径），满五唯一等情形可免税（政策口径） |
| 印花税（产权转移书据） | 双方 | 住宅买卖个人暂免（政策口径），以最新规定为准 |

**要点**：国内房产的税负集中在「买卖瞬间」，持有期几乎没有成本——这和「买海外房产每年交物业税/资本利得税」的体验完全不同，是很多人低估跨境房产对比的原因。

## 四、海外投资收益的税务（常识科普）

### 4.1 中国税务居民的「全球所得」申报

- 前面说过：居民个人就全球所得纳税。海外股息、利息、房产租金、资本利得等理论上都需并入申报（以国家税务总局现行规定为准）。
- 海外已缴税款可按税收抵免制度在限额内抵免，避免双重征税。

### 4.2 主要投资地的预扣税常识（以最新税法与双边协定为准）

| 国家/地区 | 对非居民的常见规则（常识） |
|---|---|
| 美国 | 资本利得一般不向非居民征税（美国房地产、实质经营等除外）；股息预扣税默认 **30%**，中美税收协定下通常可降至 **10%**；组合利息一般免税（30% 预扣但有豁免） |
| 加拿大 | 非居民一般不对资本利得征税，但**出售加拿大房地产**有专门规则；股息预扣税协定内常见 15%/25% 层级 |
| 英国 | 非居民资本利得税一般限于英国房地产等特定资产；股息预扣税协定内常见 10%/15% 层级 |
| 香港 | 无资本利得税、无股息税（属地原则），这也是香港账户常见的原因之一 |

**为什么中概股/港股美股账户的股息到账会「缩水」**：券商在派息时先代扣美国预扣税（按协定 10%），这是**已发生但你看不到明细**的隐性成本。

### 4.3 CRS 与申报义务

- CRS 交换的是**账户信息**（余额、利息、股息等），交换本身不是征税；收到信息后税务机关如何核查，取决于其风控安排。
- 海外收入申报的主要形式：年度个人所得税汇算时并入综合所得或分类申报（以现行申报系统与指引为准）。
- **常识结论**：海外资产的「税务隐形」已不存在，合规申报是唯一稳妥选项。

## 五、合法筹划 vs 偷漏税的边界

### 5.1 正当筹划清单（政策本身鼓励的）

| 方式 | 原理 | 备注 |
|---|---|---|
| 长期持股 A 股 | 持股超 1 年股息免税 | 税务与长期投资的激励方向一致 |
| 利用专项附加扣除 | 子女教育、住房贷款利息、赡养老人等 7 项扣除 | 每年在个税 App 如实填报 |
| 个人养老金账户（每年缴费限额 12000 元，历史政策口径） | 缴费税前扣除、投资环节暂不征税、领取时按 3% 缴税（EET 递延模式） | 以现行政策与实施细则为准；钱被锁到退休，不能只当税工具 |
| 税优健康险 | 符合条件的产品保费可税前扣除 | 额度有限（每月 200 元，历史口径），别为省税买不需要的保险 |
| 国债/地方债利息免税 | 免税券种天然税后收益更高 | 直接买国债即可，无需额外操作 |

**合法筹划的统一特征：全部发生在「规则明确允许」的范围内，且无需隐瞒任何信息。**

### 5.2 红线（刑事与行政风险警示）

| 行为 | 风险（常识，以最新法规为准） |
|---|---|
| 虚假申报、隐匿收入 | 税务机关可追缴税款、加收滞纳金并处以 0.5-5 倍罚款（历史口径）；**经税务机关下达追缴通知后仍拒不缴纳，构成逃税罪的，可追究刑事责任** |
| 利用境外账户隐匿资产 | CRS 下信息可被交换；情节严重的可能涉及逃税罪；国家工作人员的境外存款另有专门罪名 |
| 虚构凭证/购买发票 | 可能涉及虚开发票等更重的刑事风险 |
| 将灰色地带收入「主动披露」 | 部分情形下有补税通道，但以税务机关现行政策为准——**不要自行创造「避税方案」** |

> **一句话边界：把「少交税」建立在真实、合规、政策允许的基础之上叫筹划；建立在隐瞒、造假、境外藏匿之上叫偷漏税。中间没有灰色地带，只有你不熟悉的规则。**

## 六、「税务规划」的正确姿势

1. **记录交易流水**：买入卖出日期、价格、数量全部留档（股息差异化税率的计税依据就是持股期限——没有记录就说不清）。
2. **区分「税后收益」比较产品**：免税国债 vs 应税企业债，要换算成税后收益率再比。
3. **关注政策变化**：印花税、股息税率、个人养老金额度都是「历史口径」，调整是常态——每年新规季（年初/年中）主动看一眼财政部与税务总局公告。
4. **重大事项咨询专业人士**：海外资产申报、大额转让、跨境业务，几千元咨询费通常远小于踩错规则的成本。
5. **不买「税务筹划服务」的非法产品**：声称「帮你把境外资产洗白」「内部通道免税」的服务，大概率是骗局或犯罪。

### 6.1 申报实操三件事（常识）

1. **个人所得税 App / 自然人电子税务局**：每年的综合所得汇算在这里完成；系统里能查到的收入记录、扣除项目都以申报为准。
2. **分类所得的申报**：股息、利息、财产转让等收入如无代扣代缴（例如境外分红），需要按税务机关指引自行申报——**不要等通知，主动了解申报期限**。
3. **留存凭证**：境外账户交易记录、完税证明（境外已缴税的抵免需要凭证）、成本依据（转让所得的计税基础），纸质或电子至少留 5 年以上（常识口径）。

### 6.2 常见问题速答

| 问题 | 回答（常识，以最新法规为准） |
|---|---|
| 工资只在一家公司，还要汇算吗？ | 多数人有预扣多缴/少缴的情形，年度汇算「多退少补」，建议每年按时办理 |
| 海外股息没收到中国税务通知，要申报吗？ | 申报义务不以「收到通知」为前提，以现行税法与申报指引为准 |
| 股票被套牢还交税吗？ | 买卖差价暂免个税，与盈亏无关；分红按持股期计税 |
| 用家人账户炒股避税？ | 非本人账户交易涉及资金来源认定与合规风险，不是「筹划」 |
| 企业债利息谁来扣税？ | 通常发行人或托管机构代扣代缴，到你手上已是税后 |
| 个人养老金现在值得交吗？ | 税务上可节税（按边际税率），但资金锁定到退休，先评估流动性再决定 |
| 收到「退税代办」服务电话？ | 个税汇算可自行完成，代办收费+索要密码的多为骗局 |

## 七、速查表

| 问题 | 答案（常识，以最新法规为准） |
|---|---|
| 股息红利怎么征税？ | 持股 1 个月内 20%、1 个月至 1 年 10%、超 1 年免税 |
| A 股买卖差价征税吗？ | 暂免个税；印花税卖出方 0.05%（2023 年 8 月减半后口径） |
| 公募基金分红征税吗？ | 暂不征收 |
| 企业债利息？ | 20% 个税，代扣代缴；国债利息免税 |
| 期货/加密收益？ | 规则未明确（灰色地带） |
| 美国股息预扣税？ | 默认 30%，协定下常见 10%（中概/美股分红常识） |
| 个人养老金？ | 年缴费限额 12000 元，税收递延，领取时按 3% 缴税（历史口径） |
| 偷漏税红线？ | 追缴 + 滞纳金 + 罚款；拒不缴纳可涉刑 |

> **⚠️ 风险提示**
>
> 本文为**知识科普，不构成任何税务意见**。文中所有税目、税率、限额、优惠口径均为「历史政策口径」或「常识介绍」，以「**以最新税法为准**」为前提——税收政策调整频繁，实操前请以国家税务总局、财政部官方文件及持牌税务专业人士的意见为准。故意隐匿收入、虚假申报、利用境外账户逃避税款等行为存在行政与刑事法律风险，请勿模仿任何「避税方案」。涉及个人养老金、税优保险等产品，请结合自身资金规划独立决策。
