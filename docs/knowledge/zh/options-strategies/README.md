# 27 · 期权策略进阶篇

> 期权是**衍生品之王**：非线性收益、精确的风险裁剪、无限的策略组合——是所有金融工具里最「聪明」、也最能体现专业优势的品种。
>
> 但也是**最容易让新手爆仓的品种**：买方被时间价值悄悄清零，卖方一次黑天鹅归零倒欠。99 种死法，每一种都来自「没搞懂定价与风险就开始押注」。
>
> 所以本篇的路线是：**先讲定价与风险（01、02），再讲策略（03），最后落到实战、风控与工具复盘（04、05）**。定价和风险没吃透之前，任何策略都不值得碰。

---

> ⚠️ 风险提示
>
> 本篇全部内容仅用于学习与研究，不构成任何投资建议。文中所有价格、权利金、波动率、希腊字母、盈亏数字均为虚构教学口径，**具体以各交易所最新合约规则与实时行情为准**。期权（尤其卖方与杠杆品种）风险极高，参与前请务必完成券商要求的投资者教育、通过适当性评估，并评估自身风险承受能力。

## 各篇简介

### 01 · 期权定价与波动率

期权价格不是「猜的」，而是**五个输入 + 波动率**算出来的。本篇从「内在价值 + 时间价值」拆解期权价格构成，讲清为什么时间价值本质上是「波动率价值」；用直觉（而非公式）理解 Black-Scholes 的五个输入如何共同决定价格；然后深潜隐含波动率 IV——从期权价格反推的市场预期，理解 IV 为什么是「恐慌指数」，波动率曲面为什么出现微笑与偏斜（尾部风险为什么贵）；最后给出判断 IV 高低的方法与不同市场（股票/商品/加密）的 IV 水平常识。

### 02 · 希腊字母实操

期权交易者看希腊字母，如同飞行员看仪表盘。本篇逐一拆解五个希腊字母的意义与计算直觉：Delta 是方向敏感度、Gamma 是加速度（平值附近最大，是胜负手）、Theta 是每天的时间损耗（期权是「租来的时间」）、Vega 是波动率敏感度、Rho 是利率敏感度（散户多数可忽略）。核心方法论是「希腊字母资产负债表」：把持仓组合看作一组希腊字母敞口，理解 Delta 中性对冲（做多 Gamma + 卖时间的机构核心玩法）、策略与希腊字母的对应关系（买跨式买什么、卖跨式卖什么），最后给出买一张 ATM Call 的希腊字母剖面表。

### 03 · 期权组合策略大全

策略不是越多越好，而是**每一类都有明确的盈亏画像**。本篇按风险收益类型把 16 个主流策略分为四类：方向策略（买入 Call/Put、牛市/熊市价差、比率价差）、波动率策略（跨式、宽跨式、铁鹰、铁蝶、日历、对角）、收入策略（备兑、现金担保沽、领口、合成股票）、对冲策略（保护性 Put、指数 Put 对冲、尾部风险对冲）。每个策略给出组合构成、ASCII 盈亏形态、到期盈亏公式与盈亏平衡点的数字例子，最后给一张「策略与市场环境匹配表」。

### 04 · 期权实战与风控

纸上谈兵和真金白银之间，隔着实战与风控。本篇先讲买方：为什么 90% 的买方期权到期归零（时间衰减 + IV 回落），「买在 IV 低点、卖在 IV 高点」的择时心法，以及末日轮赌博的危险；再讲卖方：权利金收入 vs 保证金占用、「收保险费」的本质、止损与移仓 Roll、极端行情下的爆仓案例常识。然后是组合保证金概念、交易成本、仓位管理、回测难点，最后给一张实战检查清单。

### 05 · 期权工具与复盘

会算不如会看，会看不如会复盘。本篇教你读期权链（行权价网格、IV、希腊字母、持仓量 OI 与成交量），盘点国内外 IV 数据工具与期权策略构建器，给出每笔交易的复盘模板，强调「IV 分位数记录」的长期价值（形成自己的波动率日历），最后规划一条循序渐进的进阶学习路径：先懂定价 → 再玩价差 → 后涉卖方，并用模拟盘练手。
