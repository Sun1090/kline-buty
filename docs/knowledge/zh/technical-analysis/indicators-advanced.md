# 12 · 指标进阶补遗：DMI/ADX、Supertrend、BBW

> 本篇承接[技术指标详解](indicators.md)的常用指标，补上三类进阶工具：<mark>DMI/ADX</mark>（趋势强度滤网）、<mark>Supertrend</mark>（顺势持仓轨道）、<mark>BBW</mark>（布林带宽，波动压缩探测器）。它们的共同点很明确：**都不负责「预测方向」，只负责回答「这个市场现在值不值得做、该拿多久」**——而这恰恰是新手最缺的一环。

::: tip 💡 一句话总纲
一句话总纲：**方向、强度、波动率是三个独立维度，每个维度选一个工具就够。** DMI/ADX 管强度、均线/MACD 管方向、BBW 管波动——把它们当互补滤网，而不是三张互相矛盾的牌。
:::

---

## 1. DMI / ADX：方向与强度的分离

### 1.1 原理：三条线各管各的

DMI（Directional Movement Index，趋向指标）由三条线组成：

| 线 | 含义 | 计算思路 |
|---|---|---|
| **<mark>+DI</mark>** | 多方方向的相对强度 | 上涨波动占全日波动的比例（平滑后） |
| **<mark>−DI</mark>** | 空方方向的相对强度 | 下跌波动占全日波动的比例（平滑后） |
| **<mark>ADX</mark>** | 趋势强度（不带方向） | +DI 与 −DI 差值的移动平均，取值 0~100 |

默认参数：14（常用 14，部分软件用 13/14 组合）。

关键设计在第三条线：**ADX 只回答「趋势强不强」，完全不回答「往哪走」**。+DI 在 −DI 上方但 ADX 掉头向下，说明多头仍占优、但趋势正在衰减——这种「方向与强度分离」是 DMI 独有的视角，MA 和 MACD 都做不到。

### 1.2 核心用法：先判市况，再谈信号

| ADX 读数 | 市场状态 | 操作含义 |
|---|---|---|
| ADX > 25（且上行） | 趋势市 | 趋势类信号（金叉、突破）可信度高，可顺势持仓 |
| ADX 20~25 | 过渡区 | 信号打折，仓位降级 |
| ADX < 20 | 震荡市 | 趋势信号大概率失效，改用区间思路（高抛低吸）或不做 |
| +DI > −DI | 多头占优 | 配合 ADX 上行 = 顺势多头环境 |
| −DI > +DI | 空头占优 | 配合 ADX 上行 = 顺势空头环境 |

典型工作流：**先用 ADX 定「市况滤镜」，再看方向信号**。ADX < 20 时，把均线的金叉死叉、MACD 的突破信号全部调低一档权重——这正好补上[指标详解](indicators.md)里反复出现的「震荡市指标全面失效」问题：ADX 就是那个「告诉你在不在震荡市」的仪表。

### 1.3 典型误用

- **在震荡市用方向信号**：ADX < 20 时把 +DI 上穿 −DI 当买点——这是 DMI 最经典的误用，此时正负 DI 交叉基本是噪音。
- **把 ADX 高点当顶部信号**：ADX 是滞后指标，趋势最猛烈的阶段 ADX 往往还在上行；ADX 回落只说明趋势强度衰减，不说明方向马上反转。
- **只用 ADX 不用 ±DI**：强度高不代表方向多头，两条 DI 线才是方向来源，缺一不可。

## 2. Supertrend：ATR 棘轮轨道

### 2.1 原理与参数

<mark>Supertrend</mark> 是围绕价格的单线轨道指标，核心原料是 [ATR](indicators.md)：

```text
基础轨道 = 中间价（(H+L)/2） ± n × ATR
默认参数：周期 10，倍数 3（即 10/3）
```

**参数 10/3 的含义**：ATR 用最近 10 根 K 线衡量「平均每根走多远」，再把这个平均波动放大 3 倍作为轨道距离。倍数越小轨道越贴价格、翻转越频繁（信号多但假信号也多）；倍数越大轨道越远、越「钝」。

### 2.2 棘轮机制与翻转

Supertrend 的精髓是<mark>棘轮</mark>式的单边跟踪：

- **多头状态**：轨道在价格下方，且**只会向上抬、不会向下退**——价格上涨时止损跟着上移，价格回调只要不触及轨道，多头状态就延续。
- **空头状态**：轨道在价格上方，只会向下压。
- **翻转**：价格收盘穿越轨道 = 状态翻转，旧状态止损、新状态开启。翻转点天然就是**<mark>移动止损</mark>参考位**。

```text
多头状态示意（轨道只升不降）：
价格   ╱ ╲  ╱╱ ╲
        ╲    ╱       ← 回调未触及轨道，状态延续
轨道  ＿＿＿＿／‾‾   ← 跟随上移（棘轮）
```

### 2.3 正确定位：持仓工具，不是预测工具

Supertrend 不预测顶底——它一定「卖在趋势走坏之后」，这是设计使然而非缺陷。它的价值是把「顺势拿住单子」这件新手最难做到的事变成机械规则：**轨道在下方就拿住，翻转就走**。用它抄底摸顶 = 用错了工具。

::: warning 🔄 震荡市照样打脸
Supertrend 与 SAR 同病：横盘期轨道会上下反复翻转，连续小额止损。它不是「无脑跟着翻转开单」的指标，正确用法是「有趋势时用它管持仓」——市况过滤仍要交给 ADX 这类强度仪表。
:::

## 3. BBW 布林带宽：波动的呼吸

### 3.1 定义与挤压逻辑

<mark>BBW</mark>（Bollinger Bands Width，布林带宽）把布林带两条轨道的距离数值化：

```text
BBW = (上轨 − 下轨) / 中轨 × 100%
```

它回答一个单一问题：「当前波动相对均值是大还是小？」由此得到一条明确的周期规律——**<mark>波动挤压</mark>（Squeeze）与扩张交替出现**：

```text
挤压 → 变盘临近 → 扩张（趋势启动）→ 波动回落 → 再挤压 → …
```

波动不会永远压缩，也不会永远扩张——低波动之后是高波动，这就是 BBW 想抓住的「呼吸节律」。布林带「收口必变盘」的口诀，BBW 就是它的数值版：不用肉眼估带宽，看曲线是否压到历史低区即可。

### 3.2 用法与铁律

| 状态 | BBW 表现 | 含义 |
|---|---|---|
| 深度挤压 | 带宽处于近 N 根的极低分位 | 突破前哨：变盘能量在积聚，等待方向 |
| 突破启动 | 带宽快速放大 + 价格脱离中轨 | 扩张开始，顺势方向入场 |
| 扩张末期 | 带宽处于历史高位后回落 | 行情趋于衰竭，不宜追 |

**铁律：BBW 只告诉你「要动」，不告诉你「往哪动」。** 挤压之后可以向上突破也可以向下破位——必须等方向确认（收盘突破挤压区间、配合量能）再入场。在挤压区间内提前「押方向」，本质是赌。

## 4. 三者的组合定位

### 4.1 三维各选其一

把常用指标按维度归位后，组合原则变得非常清晰——**同一维度不叠加，跨维度做滤网**：

| 维度 | 候选工具 | 本篇对应 |
|---|---|---|
| 方向 | MA / EMA / MACD | [指标详解](indicators.md) |
| **强度** | **ADX** | 本篇 |
| **波动率** | **ATR / BBW** | 本篇（ATR 管止损距离，BBW 管变盘前哨） |
| 持仓管理 | SAR / Supertrend | 本篇 |

**示例组合**：EMA50 定方向 → ADX > 25 确认趋势市 → BBW 深度挤压后突破入场 → Supertrend 轨道作为移动止损。四个角色各司其职，没有一个工具在做重复工作。

### 4.2 反面清单

| 错误组合 | 为什么错 |
|---|---|
| MACD 金叉 + +DI 上穿 −DI 同时当买点 | 两者都在描述「方向/动量」，是伪双重确认 |
| Supertrend 翻转 + SAR 反转叠加 | 两个同类持仓工具，信号重复、止损位却不同，徒增混乱 |
| BBW 挤压 + ADX < 20 就直接做多 | 只确认了「要动」，没有等方向确认 |

::: tip 💡 回顾[指标组合原则](indicators.md)
「同一维度只留一个，不同维度互补验证」在进阶工具上同样成立，而且更严格——进阶工具描述的维度更抽象（强度、波动），叠加同维工具造成的混乱也更隐蔽。
:::

::: warning ⚠️ 风险提示
DMI/ADX、Supertrend、BBW 均基于历史价格计算，天然滞后；ADX 阈值（25/20）与 Supertrend 参数（10/3）只是常见默认值而非最优解，跨品种、跨周期表现差异很大。任何过滤条件都可能在特定行情下连续失效，参数优化极易过拟合，务必先用回测与小仓验证。
:::
