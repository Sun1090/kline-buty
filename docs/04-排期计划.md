## 详细排期（W1–W5）

### W1 · 数据地基（数据源打通）

| 天数 | 任务 | 产出 |
|---|---|---|
| D1 | 项目脚手架（Vite+React+TS），目录按 03-技术方案 落地 | 可运行骨架 |
| D2 | `data/binance/rest.ts`：klines 分页拉取 + symbols + 字段映射 | 历史数据 ✅ |
| D3 | `data/binance/ws.ts`：订阅/心跳/指数退避重连/断线补数 | 实时数据 ✅ |
| D4 | `data/market.ts`：缓存去重合并；Vite proxy 打通 `/api` `/ws` | 数据链路 ✅ |
| D5 | 控制台冒烟：Node 侧脚本验证全链路 + 验收用例 | 冒烟报告 |

**验收**：脚本可拉 1000 根 1m 历史并持续接收 WS 推送、断线 5s 后自动补齐。

### W2 · 图表 MVP（首次可见 demo）

| 天数 | 任务 | 产出 |
|---|---|---|
| D1 | lightweight-charts v5 接入，`chart/adapter.ts` 隔离层 | 渲染隔离 ✅ |
| D2 | 蜡烛图 + 成交量副图（联动时间轴） | MVP 图表 ✅ |
| D3 | WS 实时：最新 K 线跳动 + 收盘追加 | 实时图表 ✅ |
| D4 | 周期切换（1m/5m/15m/1H/4H/1D/1W） | 周期化 ✅ |
| D5 | demo 打磨：布局、涨绿跌红、深色主题、加载态 | **可演示版本** ✅ |

**验收**：浏览器打开即见 BTCUSDT 实时 K 线跳动，切周期流畅无闪烁。

### W3 · 指标与交互

| 天数 | 任务 | 产出 |
|---|---|---|
| D1–D2 | 指标引擎：MA/EMA/BOLL/VOL/MACD/KDJ/RSI 纯函数 + 单测 | 指标库 ✅ |
| D3 | 主图指标叠加 + 副图指标切换（VOL/MACD/KDJ/RSI） | 指标联动 ✅ |
| D4 | 十字光标信息窗（OHLC + 指标值） | 光标交互 ✅ |
| D5 | 历史向左分页加载（滚动到左缘自动补数据） | 分页 ✅ |

**验收**：指标数值与 TradingView 同品种同周期比对一致（±0.1%）。

### W4 · 体验补全

- 交易对切换 + 自选列表（P0-10）
- 指标参数自定义面板（P1-5）
- 图表类型切换：蜡烛/折线/面积（P1-1）
- 全屏模式 + 布局持久化（localStorage）（P1-8/9）
- 迷你图 sparkline（P1-4，列表页）

**验收**：连续使用 30 分钟无卡顿、无内存增长异常。

### W5 · 打磨与交付

- 性能：大数据量（2 万根）滚动压测，窗口裁剪优化
- 稳定性：WS 断线/恢复补数压测，网络切换场景
- 单测补齐（指标算法、数据去重合并、补数逻辑）
- README、部署说明、demo 环境一键启动脚本

## 里程碑口径

- **M2 结束** = 可向他人演示的实时 K 线 demo（对应本次排期的直接目标）
- **M3 结束** = 功能对齐主流交易所 K 线页 80%（指标+交互）
- **M5 结束** = 一期发布候选
