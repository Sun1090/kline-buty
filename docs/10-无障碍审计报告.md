**主要交互控件均已具备可访问名称，面板语义覆盖达标**，未发现阻断性缺口。

## 检查明细

### 1. 面板区域语义（role="region" + aria-label）

| 面板 | 语义 |
|---|---|
| AlertPanel / DepthChart / DrawingLayers / IndicatorSettings / PositionPanel / ReplayBar / StatsBar / TradeHistoryPanel / VolumeProfileChart / SentimentPanel / MarketList | `role="region"` + `aria-label` |
| OrderBook | `role="region"` + `aria-label`（含盘口行价格朗读） |

### 2. 交互控件可访问名称

- 桌面/移动 header 全部菜单按钮：`title` + 可见文本（typeLabel/mainLabel/subLabel/drawLabel ▾）
- 图层面板行内操作：`rowBtn()` 统一带 `title` + `aria-label` + `aria-pressed`
- 撤销/重做/复制/粘贴/模板按钮：`aria-label` + 禁用态 `aria-disabled`
- TradeHistoryPanel：导出/重置/关闭均带标签；重置含两步确认语义
- 图表十字光标信息窗：`pointerEvents:none` 供屏读器按文档序读取

### 3. 键盘可达（E10 链接）

- 快捷键系统（src/shortcuts.ts）覆盖导航/回放/指标/布局/删除/复制粘贴，`?` 面板可查全部
- SymbolPicker / MarketList / DrawingLayers 列表均实现方向键漫游 + `aria-activedescendant`
