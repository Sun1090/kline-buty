## 执行顺序建议

1. **第一优先级（A 阶段数据正确性 + B/C 关键交互）**：A1–A4（周期边界/锚定/补洞/同步）→ B1/B2（光标取值/信号打点）→ C1（导出）。
2. **工程收尾（G 阶段）**：G1（O11 收尾）→ G2（O10 视觉回归）→ G3/G4（性能）。
3. **账户与提醒（D/E）**：D1/D2 → E1/E2。
4. **可访问性与 UI（F）**：F1/F2 键盘 → F3–F8 a11y。
5. **生态与新特性（H/I）**：H1/H2 离线与搜索 → I1/I2。
