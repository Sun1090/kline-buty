# 02 · 需求清单：K 线产品功能分层（P0 / P1 / P2）

> 依据 01-调研报告 竞品盘点，按「没有它就不成产品 / 追上主流体验 / 差异化」三层划分。
> 一期 Web（React + lightweight-charts）范围 = P0 + P1；P2 视排期与产品定位分阶段。
>
> **需求演进**：P0–P2 落地清单见 `06-开发任务清单.md`；P3/P4 深化需求（100 项，行情/指标/画线/交易/UI/工程）见 `07-P3P4-任务清单.md`，完成状态见 `11-P3P4-完成状态盘点.md`。

---

## P0 · 基础核心（一期必做，MVP）

| # | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| P0-1 | 蜡烛图渲染 | Canvas 高性能绘制，非 DOM | 1000 根 K 线 60fps |
| P0-2 | 周期切换 | 1m/5m/15m/1H/4H/1D/1W 七档 | 切换即加载对应周期数据 |
| P0-3 | 历史数据分页 | 最新在右，向左滚动自动加载更早 | 连续滚动无感补数、无重复 |
| P0-4 | 主图指标 | MA(5/10/20/60)、EMA、BOLL | 算法与币安/TradingView 结果一致 |
| P0-5 | 副图指标 | VOL（含 MA 均量）、MACD、KDJ、RSI | 与主图同步缩放联动 |
| P0-6 | 十字光标 | 悬停/移动显示 OHLC + 指标值信息窗 | 精确到 K 线粒度 |
| P0-7 | 交互手势 | 滚轮缩放、拖拽平移 | 缩放以光标为中心 |
| P0-8 | 实时行情 | WebSocket 推送：最新 K 线跳动 + 收盘追加 | 断线自动重连并补数 |
| P0-9 | 视觉 | 涨绿跌红、深色主题、价格轴/时间轴 | 与主流交易所观感一致 |
| P0-10 | 多币种 | 交易对切换（BTCUSDT 等）+ 自选列表 | 切换保留当前周期 |

## P1 · 主流体验（一期可选，二期默认）

| # | 功能 | 说明 |
|---|---|---|
| P1-1 | 图表类型 | 蜡烛 / 折线 / 面积 / 空心 K 线 |
| P1-2 | 画线工具 | 趋势线、水平线、斐波那契回撤、平行通道、文字标注 |
| P1-3 | 盘口深度图 | 订单簿聚合曲线，随盘口实时刷新 |
| P1-4 | 迷你图 | 列表页 sparkline（历史收盘价折线） |
| P1-5 | 指标参数自定义 | 如 MA 周期 5/10/20/60 可改，副图周期可调 |
| P1-6 | 秒级 K 线 | 1s 周期 + 更大周期（1M/3M/1Y） |
| P1-7 | 图表分享 | 截图导出、分享链接（携带品种+周期） |
| P1-8 | 全屏模式 | 图表沉浸式全屏 |
| P1-9 | 布局持久化 | 指标/周期/画线配置本地存储 |

## P2 · 差异化进阶（三期望）

| # | 功能 | 说明 |
|---|---|---|
| P2-1 | 订单叠加 | 开仓/止盈/止损线拖拽标注在图上（对齐 Bybit） |
| P2-2 | 多图表联动 | 2/4 图表同屏，共享品种/周期/时间轴 |
| P2-3 | 市场回放 | 历史逐根重放（对齐 Bybit Market Replay） |
| P2-4 | 加密专属数据层 | 资金费率、未平仓合约、清算热力图、多空比 |
| P2-5 | 价格提醒 | K 线价格触发通知（Web Push） |
| P2-6 | 移动端 | WebView 套壳 → 渐进增强 → 原生图表复刻 |

---

## 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 图表交互 60fps；首屏 K 线 ≤ 1s 可交互 |
| 稳定性 | WS 断线 ≤3s 自动重连，重连后自动补齐缺口 |
| 兼容 | Chrome/Safari/Edge 最新两个大版本；移动端 Safari/Chrome |
| 可维护 | 渲染层 adapter 隔离，数据层与 UI 解耦 |
| 可测试 | 指标算法纯函数化，单测覆盖 |

## 明确不做（一期）

- 交易下单（仅展示行情，不做账户/订单）
- 用户系统与多端账号体系
- 自研 Canvas 渲染引擎（生产路径；学习用途可另开实验页）
