# 01 · 调研报告：主流交易所 K 线功能盘点与数据源选型

> 调研对象：欧易 OKX、币安 Binance、Bybit（含底层 TradingView）
> 调研日期：2026-08-15
> 结论摘要：竞品 K 线功能可归纳为「图表核心 P0 / 主流体验 P1 / 差异化 P2」三层；
> 数据源选型为**币安公开 API（REST + WebSocket）**，本机网络实测直连可达。

---

## 一、竞品功能盘点

### 1.1 欧易 OKX

| 模块 | 实现 |
|---|---|
| Web 端图表 | TradingView 驱动（完整专业图表） |
| App 端图表 | **自研原生图表**（非 TradingView） |
| 周期 | 1s / 1m / 3m / 5m / 15m / 30m / 1H / 2H / 4H / 6H / 12H / 1D / 1W / 1M |
| 主图指标 | MA / EMA / BOLL / SAR |
| 副图指标 | VOL / MACD / KDJ / RSI / WR / DMI / CCI / ATR / OBV / PSY |
| 画线工具 | 趋势线 / 水平线 / 斐波那契回撤·扩展 / 平行通道 / 文字标注 |
| 加密特色 | 持仓均价线、开仓价标记、强平价提示、资金费率线 |
| 其他 | 盘口深度图（聚合曲线）、买卖盘口、最新成交、十字光标 OHLC 窗、双指缩放、全屏、截图分享 |

### 1.2 币安 Binance

| 模块 | 实现 |
|---|---|
| Web 端图表 | TradingView 驱动 |
| App 端图表 | 自研原生图表 |
| 周期 | 全市场最全：1s + 1m/3m/5m/15m/30m/1h/2h/4h/6h/8h/12h/1d/3d/1w/1M |
| 图表类型 | 蜡烛图 / 折线 / 面积 |
| 指标 | 同 OKX 基础上再含 VWAP、STOCH；移动端支持指标参数自定义 |
| 特色 | 列表页迷你 K 线（sparkline）、价格提醒、订单标记直接叠加在 K 线上 |
| 其他 | 深度可视化、盘口、实时成交、暗色/亮色主题 |

### 1.3 Bybit

| 模块 | 实现 |
|---|---|
| 图表 | 全部 TradingView（最接近专业图表软件） |
| 特色 | 多图联动（2/4 图表同屏）、市场回放 Market Replay、一键下单面板与图表同屏、持仓止盈止损线直接画在图上、Pine Script 策略 |
| 其他 | 指标/画线能力同 TradingView 全量 |

### 1.4 三者共性（= 大众化标配）

- 周期切换（分/时/日/周/月）
- 十字光标 + OHLC 信息窗
- 主图指标 MA/EMA/BOLL，副图 VOL/MACD/KDJ/RSI
- 盘口深度图、买卖盘口、最新成交
- WebSocket 实时行情推送（K 线跳动 + 追加）
- 涨绿跌红（加密市场默认）、深色主题
- 历史数据右侧最新、向左分页加载

### 1.5 关键技术事实

- **移动端无成熟的 JS 级 K 线库**，这是 OKX/币安 App 自研图表的核心原因；Web 端全部走 TradingView。
- 自研渲染工作量分布：蜡烛绘制约 20%，交互/坐标/指标/数据流约 80%。

## 二、数据源调研与实测

### 2.1 候选数据源对比

| 数据源 | 免费 | 需 Key | 数据深度 | 国内可达 | 备注 |
|---|---|---|---|---|---|
| 币安 REST+WS | ✅ | ❌ | 极全（1s~1M 全周期） | 本机实测直连 ✅ | 首选，生态标准 |
| OKX REST+WS | ✅ | ❌ | 全周期 | 受限，需代理 | 文档中文，备选 |
| Bybit REST+WS | ✅ | ❌ | 全周期 | 受限，需代理 | 备选 |
| CoinGecko | ✅ | 限流 | 浅（无 1m） | 一般 | 仅兜底/研究用 |

### 2.2 币安 API 规格（本 demo 使用）

- 历史 K 线（REST）：`GET https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1m&limit=1000`
  - 备选域名 `https://data-api.binance.vision`（实测同样可达，更稳）
  - 返回 `[openTime, open, high, low, close, volume, closeTime, ...]`
  - 单次上限 1000 根，支持 `startTime/endTime` 游标翻页
- 实时 K 线（WS）：`wss://stream.binance.com:443/ws/btcusdt@kline_1m`
  - 帧：`{"e":"kline","k":{"t":openTime,"o","h","l","c","v","x":是否收盘,...}}`
  - 单流订阅一个品种+周期；支持组合流
- 限流：REST 6000 次/分钟（按 IP），完全够用

### 2.3 本机实测记录（2026-08-15）

| 通道 | 结果 |
|---|---|
| `api.binance.com/api/v3/klines` | ✅ 返回 BTCUSDT 1m 实时数据 |
| `data-api.binance.vision/api/v3/klines` | ✅ 同 |
| `stream.binance.com:443/ws/btcusdt@kline_1m` | ✅ 秒级收到未收盘 K 线推送 |

**结论**：开发环境可直连，无需代理；代理层仅在产品部署到受限网络时启用（见 03-技术方案）。

## 三、选型结论

1. **Web 优先，移动端二期**（一期 React + TS；二期 WebView 套壳或原生复刻）
2. **渲染层用 lightweight-charts**（TradingView 官方开源，17k star，Apache-2.0，v5 API，Canvas 渲染）
3. **不自研渲染库**，但数据层/指标层/WS 客户端自建，渲染层通过 adapter 隔离，保留替换能力
4. **数据源用币安公开 API**，主备域名双保险，代理层按需启用
