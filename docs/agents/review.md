# 审查清单

## 需求与范围

- [ ] 是否只包含一个逻辑主题？
- [ ] 是否有无关格式化、生成物、知识库批量改动被误带入？
- [ ] 是否遵守当前产品决策：顶栏折叠、移动端换行、README 分语言、外链新标签？
- [ ] 是否读过相关源码而不是只看文件名？

## 正确性

- [ ] K 线时间序是否保持升序？
- [ ] 实时帧、REST 补数、周期切换是否会重复或丢数据？
- [ ] 重连后是否能补洞并恢复订阅？
- [ ] 指标首尾空值、除零、空数组、单根 K 线是否安全？
- [ ] 画线坐标在 resize、缩放、平移、周期切换后是否仍正确？

## 交互与视觉

- [ ] 桌面 1280px 和窄窗口都检查过吗？
- [ ] 移动 320 / 390px 是否没有横向滚动？
- [ ] 关键数据、OHLC、日期轴、底部按钮是否完整可见？
- [ ] 浮层贴边时是否翻转或钳制？
- [ ] 触屏长按、拖拽、双指缩放是否互不冲突？
- [ ] 折叠菜单展开 / 收起状态是否正确持久化？

## 可维护性

- [ ] 计算逻辑能否抽出为纯函数？
- [ ] 是否复制了已有 indicator / depth / drawing / market 逻辑？
- [ ] 命名是否表达业务含义，而不是 `data2`、`handleClick2`？
- [ ] 是否新增了不必要的依赖？

## 测试充分性

- [ ] 新算法是否有正例、反例、边界值？
- [ ] UI 行为是否有 Rendering / user-event 测试？
- [ ] 移动端关键路径是否有 Playwright 场景？
- [ ] 修 bug 的测试是否先证明旧实现会失败？

## 文档与发布

- [ ] README 能力、测试数、预览地址是否仍然真实？
- [ ] 知识库统计（章节数、篇数）是否同步？
- [ ] 外链是否新标签页且集中分组？
- [ ] 锚点是否对应生成页面的真实标题 ID？
- [ ] CI / Pages / Vercel 是否真的通过？
